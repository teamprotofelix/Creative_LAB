# 당신이라는 우주 · The Universe Called You

> 당신이 바라보는 곳에 하나의 세계가 열립니다.

사용자 제공 원본의 7개 장(부재, 시간, 반복, 관찰, 마음, 타인, 침묵)을 보존하고, 상호작용·정확성·모바일·접근성·성능을 개선한 **순수 HTML/CSS/JavaScript 정적 사이트**입니다.

## 실행

압축을 풀어 `index.html`을 더블클릭하면 실행됩니다. 외부 서버, 빌드 도구, API 키, CDN, 외부 웹폰트가 필요하지 않습니다. 오프라인 환경에서도 실행할 수 있습니다.

GitHub Pages 배포:

1. ZIP을 해제하고 **`index.html`, `style.css`, `main.js`, `README.md`** 및 나머지 문서를 GitHub 저장소의 루트에 업로드합니다. ZIP 파일 자체를 업로드하는 것이 아닙니다.
2. 저장소 → Settings → Pages → Source: Deploy from a branch → `main` / `/(root)` → Save.
3. 해당 저장소의 Pages 주소로 접속합니다. 프로젝트 저장소 하위 경로에서도 동작하도록 상대 경로를 사용합니다.

## 7개의 장

| 장 | 경험 | 조작 |
|---|---|---|
| I 부재 | 어둠을 열면 별무리가 나타남 | 마우스, 터치, `빛 한 조각 발견하기`, 초기화 |
| II 시간 | 체험하는 동안 흘러간 시간과 근사치 | 자동 갱신, 비활성 탭에서 체험 시간 정지 |
| III 반복 | 테세우스의 배를 이루는 24장의 판자 교체 | 버튼 또는 3장 내부 스크롤, 원본 되돌리기 |
| IV 관찰 | 파형이 빛의 지점에 모이는 시각적 은유 | 커서, 터치, 관찰 버튼 |
| V 마음 | 움직임을 따라 점이 생기고 선이 이어짐 | 마우스, 터치, 생각 만들기, 초기화 |
| VI 타인 | 다른 마음을 상징하는 일곱 개의 빛 | 인물 선택, 연결 버튼 |
| VII 침묵 | 현재 체험으로 만든 편지 | PNG 저장, 텍스트 복사, 다시 시작 |

상단의 I~VII 항목으로 장면을 바로 선택할 수 있고, 모바일에서는 터치와 각 장의 버튼을 사용합니다. `Tab` 키로도 링크와 버튼을 조작할 수 있습니다. 우측 상단의 `정적인 우주` 버튼 또는 운영체제의 `동작 줄이기` 설정으로 움직임을 줄일 수 있습니다.

## 과학적 숫자에 관한 정정

- **지구 공전 거리:** 평균 공전 속도 `29.78 km/s` × 이 페이지가 보였던 시간(초). [NASA Earth Fact Sheet](https://nssdc.gsfc.nasa.gov/planetary/factsheet/earthfact.html)
- **우주 팽창 예시:** 허블 법칙 `v = H₀ × d`, `H₀ ≈ 70 km/s/Mpc`, `d = 1 Mpc (약 326만 광년)` 가정으로 계산한 **두 지점 사이 거리의 증가량 예시**. 우주 전체의 직경이 매초 70km 증가한다는 뜻이 아닙니다. [OpenStax University Physics](https://openstax.org/books/university-physics-volume-3/pages/11-6-the-big-bang)
- **심박과 세계 출생:** 각각 분당 70회, 초당 4.2명이라는 교육적 **가상 평균값**입니다. 실제 사용자의 심박을 측정하거나 외부 통계를 받아오지 않습니다.
- **IV장 양자 연출:** 물리적 파동함수 붕괴 실험이 아니라 사용자의 주의 집중을 표현한 애니메이션입니다. 의식이 물리적 상태를 결정한다는 인과관계의 증명이 아닙니다.

## 개인정보 / 기록

- 네트워크 요청이 없고, 분석 스크립트·추적기·쿠키·API 호출이 없습니다.
- `localStorage` 키 `ucy-visit-v2`에 **이 브라우저의 방문 횟수와 직전 방문 시각**만 저장합니다. 접속자가 전 세계에서 몇 번째인지 알 수 없습니다.
- 커서 궤적, 교체한 부품, 점, 연결 횟수, 편지 내용은 **메모리에만 존재**하며 새로고침 시 초기화됩니다.
- 마지막 장의 `이 브라우저의 방문 기록 지우기` 버튼으로 방문 정보를 삭제합니다.
- 브라우저 저장소가 비활성화되거나 접근이 거부되면 저장을 건너뛰고 체험은 정상 진행됩니다.
- PNG 이미지 다운로드 및 복사는 사용자 버튼을 눌렀을 때만 실행됩니다.

## 원본 대비 주요 수정

1. `localStorage.setItem()` 실패로 전체 스크립트가 중단되는 위험 수정.
2. 거리에 대한 기준 없이 제시되었던 `우주 초당 100km 팽창` 문구 제거.
3. 단순 원형 점무늬를 실제 24개 판자로 구성한 배의 선체로 변경.
4. 방문 횟수를 전체 사이트 이용자 순위처럼 표시하지 않도록 정정.
5. 드로잉을 현재 화면 위주로 수행하도록 개선하고, 배경탭과 저동작 환경에서 비용 축소.
6. 캔버스 DPR(레티나) 대응 및 리사이즈 시 흔적 좌표 복원.
7. 모바일에서 사용할 수 있는 명시적 버튼 조작 추가.
8. 새로고침 없이 동작 설명·저장 범위·삭제 방법을 확인할 수 있도록 안내.
9. 최종 장면에서 기다림 없이 실제 세션 기록을 읽고 이미지를 내려받을 수 있도록 변경.

## 파일 구성

```text
index.html       화면 및 접근성 구조
style.css        반응형 스타일 및 저동작 설정
main.js          실험, 애니메이션, 사용자 조작 및 이미지 내보내기
README.md        설명과 GitHub Pages 배포 안내
TEST_REPORT.md   코드/브라우저 검증 항목
```

사이트는 외부 서비스를 호출하지 않기 때문에 파일을 그대로 공개 배포할 수 있습니다. 원본 사용자 제공 자료에 명시된 MIT 허용 취지를 존중하여 자유롭게 수정할 수 있도록 구성했습니다.
