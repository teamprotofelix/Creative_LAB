## 검증 환경

- 정적 소스: `index.html`, `style.css`, `main.js`
- JavaScript: Node.js `--check` 문법 검사 통과
- 브라우저: Chromium(Playwright), 데스크톱 1365×850 / 모바일 390×844, 모바일 터치 에뮬레이션
