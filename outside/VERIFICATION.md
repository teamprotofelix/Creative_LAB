# 검증 기록

검증 대상: THE OUTSIDE 정적 사이트 (브라우저 전용)

## 소스 점검
- JavaScript 구문 검사: renderer.js / app.js / audio.js → 모두 통과 (Node.js `--check`)
- HTML의 모든 로컬 스크립트·스타일·아이콘 경로 → 파일 존재 확인
- 외부 API 호출, `fetch`, `XMLHttpRequest`, 외부 라이브러리 요청 → 없음
- API 키·토큰·비밀번호로 보이는 값 → 발견되지 않음
- 사용자의 법칙 입력 → 브라우저 `localStorage`만 사용

## 렌더링 점검
- GLSL ES 3.00 정점/프래그먼트 셰이더 → Mesa OpenGL ES 3.2 환경에서 컴파일 성공
- 셰이더 프로그램 링크 성공, 장면 01~06 각각 실제 픽셀 렌더 성공
- WebGL2 사용 불가 시 Canvas 2D 대체 화면 제공
- WebGL 초기화 실패 또는 컨텍스트 손실 시 Canvas 2D로 전환하도록 처리
- 높은 해상도에서 최대 픽셀 수를 제한하고, 프레임 저하 시 해상도 자동 조정

## UI 동작 점검
- 1440×900 데스크톱 및 390×844 모바일 레이아웃 테스트
- 시작하기 → 세계 진입 → 02/03/04/05 이동 → 06 비밀 공간 해제 확인
- 물리 법칙 텍스트 입력 → 고유 8자리 시드 반영 확인
- 균열(R), 사진(P) 기능의 이벤트·상태 확인
- 브라우저 콘솔/페이지 예외: 테스트 중 발생하지 않음

참고: 자동화 브라우저의 테스트 정책상 WebGL 실행이 차단되어 브라우저 UI 테스트는 2D 대체 경로로 진행했습니다. GPU 셰이더 자체는 별도 OpenGL ES 3.2 컨텍스트에서 컴파일·렌더링 검증했습니다. 실제 GPU 성능과 모바일 기기별 프레임 속도는 다를 수 있습니다.
