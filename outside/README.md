# THE OUTSIDE — 인지의 바깥

> 생각의 바깥을 감각하는, 설치가 필요 없는 인터랙티브 생성형 우주.

**100% 클라이언트 사이드 · 외부 의존성 0개 · API 키 불필요**

## 어떤 경험인가요?

THE OUTSIDE는 일반 웹사이트나 배경 동영상이 아닙니다. 브라우저가 GLSL 셰이더로 **매 프레임 새로운 우주를 계산**합니다. 동일한 동영상을 재생하지 않습니다.

- **01 기원 / THE ORIGIN** — 실시간 광채·반사로 만들어지는 다차원 원환 구조
- **02 접힘 / THE FOLD** — 유클리드 공간의 직관을 깨뜨리는 대칭 터널
- **03 기억 / THE MEMORY** — 커서 가까이에서 반응하는 별자리 신경망
- **04 재귀 / THE RECURSION** — 반복되는 수식에서 탄생하는 복소 평면의 무한 프랙털
- **05 경계 / THE HORIZON** — 사건의 지평선을 형상화한 중력적 공간

**숨겨진 06 관찰자 / THE OBSERVER** — 다섯 세계를 모두 방문해야 처음으로 생성되는 여섯 번째 차원. 이동하며 기록한 시선의 궤적이 그 공간의 고유 별자리로 다시 나타납니다.

관찰자의 시선, 드래그, 커스텀 문장(시드)에 따라 세계가 달라집니다. 사운드는 브라우저가 직접 합성하며, 소리 파일도 필요 없습니다.

## GitHub Pages로 배포

1. 이 ZIP을 **압축 해제**하세요.
2. 저장소의 루트에 `index.html`, `style.css`, `renderer.js`, `app.js`, `audio.js`, `assets/`를 올리세요. `OUTSIDE_THE_MIND` 폴더 자체를 올리기보다 **그 안의 내용물**을 올리는 것이 편리합니다.
3. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택하세요.
4. **Branch: main / Folder: /(root)**를 선택해 저장하세요.
5. 배포된 `https://<username>.github.io/<repo>/`에 접속하세요.

> 다른 빌드 도구, Node.js, npm, 서버리스 함수, 환경변수, API 키가 모두 필요 없습니다.

### 로컬 미리보기

`index.html`을 더블 클릭해도 작동하도록 외부 데이터 요청을 사용하지 않았습니다. 문제가 있다면 Python으로 로컬 정적 서버를 실행하세요.

```bash
python -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000/`을 여세요.

## 조작법

| 입력 | 기능 |
|---|---|
| 커서 이동 | 실시간 공간 왜곡·별자리 응답 |
| 마우스 드래그 | 카메라·패턴 회전 |
| 마우스 휠, ← → | 5개 세계 이동 |
| 숫자 1–6 (06은 해금 후) | 해당 세계 바로 이동 |
| R 또는 Space | 현실 균열 / 화면 왜곡 |
| M | 생성형 사운드 ON/OFF (기본 OFF) |
| L | 자신만의 우주 법칙 쓰기 |
| F | 전체화면 |
| P | 현재 세계를 PNG로 저장 |
| ? | 조작법 도움말 |
| 모바일 | 탭하고 옆으로 쓸어 세계 전환 |

### 커스텀 물리 법칙

법칙 입력창에 원하는 문장을 입력해 보세요. 문자열을 FNV-1a 해시로 변환한 후 32비트 시드로 사용합니다. **같은 문장은 같은 시드**를 만듭니다. 법칙은 `localStorage`에만 저장되며 외부로 전송되지 않습니다.

## 기술과 호환성

- WebGL 2.0 + GLSL ES 3.00: 실제 시간에 계산하는 셰이더
- Canvas 2D: WebGL 2.0을 사용할 수 없는 환경의 대체 화면
- Web Audio API: 사용자 제스처로 켜는 합성 사운드
- HTML / CSS / Vanilla JavaScript / SVG
- 반응형 레이아웃, 축소된 모션 선호 설정 지원, 모바일 제스처
- 화면 성능에 따라 실시간 렌더링 해상도 자동 조정
- 웹 분석, 트래커, 광고, 외부 API, 토큰, 암호, 사용자 정보 포함하지 않음

**참고:** GPU 하드웨어/브라우저 성능에 따라 프레임 속도가 다를 수 있습니다. 최신 Chrome, Edge, Firefox 또는 Safari 권장. WebGL이 비활성화된 경우 간략한 Canvas 2D 공간으로 표시됩니다. 사운드는 명시적으로 활성화할 때만 재생됩니다.
