# ANIMA — 살아있는 페이지 (로컬·GitHub Pages 호환 수정본)

신경망을 가진 개체들이 실시간으로 진화하는 정적 웹사이트입니다.

## 실행 방법

- **로컬 실행**: ZIP을 압축 해제하고 `index.html`을 더블클릭하세요. 서버·설치가 필요 없습니다.
- **GitHub Pages**: `index.html`, `css/`, `js/`를 폴더 구조 그대로 저장소의 루트에 올리고 Pages를 활성화하세요.
- `깨우기` 버튼으로 시작합니다. 화면을 길게 누르거나 클릭한 상태로 먹이를 줄 수 있습니다.
- 단축키: `Space` 일시정지/재개, `S` 음소거 전환, `R` 다시 시작.
- 인터넷 연결이 없다면 웹 폰트 대신 시스템 글꼴로 표시되며, 시뮬레이션은 계속 작동합니다.
- 오디오가 제한된 브라우저에서도 시뮬레이션은 소리 없이 시작합니다.

## 원본에서 수정한 내용

1. `type="module"` 및 `import/export` 사용을 고전 스크립트의 `defer` 순서 로딩으로 교체해 `file://` 직접 실행을 지원합니다.
2. 실행 시작을 Web Audio 초기화 성공 여부와 분리했습니다.
3. 오디오 초기화 실패를 잡아 콘솔 경고만 출력하고 화면은 계속 진행하도록 했습니다.
