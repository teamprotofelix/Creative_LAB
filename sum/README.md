# 숨 · SUM — a breathing room for the mind

**외부 라이브러리 없이 `index.html` 한 파일로 실행되는 생성형 인터랙티브 사이트**입니다. 마우스 또는 손가락으로 공기를 흔들고, 스크롤로 공간의 빛을 바꾸고, 하나의 호흡을 경험해보세요.

## 실행 / GitHub Pages 배포

1. ZIP을 압축 해제합니다.
2. `index.html`을 브라우저에서 실행합니다. 추가 설치나 빌드가 필요하지 않습니다.
3. GitHub 저장소를 생성하고 **ZIP 자체가 아니라 압축 해제한 `index.html`과 `README.md`**를 저장소 최상위에 업로드합니다.
4. 저장소 `Settings → Pages → Build and deployment`에서 `Deploy from a branch` / `main` / `/(root)`를 선택합니다.
5. 게시된 GitHub Pages 주소로 접속합니다. 프로젝트 저장소라면 `https://사용자명.github.io/저장소명/` 형태입니다.

> GitHub Pages를 쓰려면 `index.html`이 저장소 최상위 또는 선택한 Pages 배포 경로에 있어야 합니다. ZIP을 업로드만 하면 자동으로 풀리지 않습니다.

## 조작

| 조작 | 결과 |
|---|---|
| 마우스 움직이기 / 화면 터치 후 이동 | 입자 흐름이 움직임에 반응합니다. |
| 배경 클릭 / 탭 | 파동이 입자 사이로 퍼집니다. |
| 페이지 스크롤 | 호박 → 보라 → 청록으로 색상이 바뀝니다. |
| `SOUND OFF` 클릭 | 사용자 조작 후 생성형 오디오를 켜거나 끕니다. 기본값은 무음입니다. |
| **한 번 숨 고르기** | 4초 들이쉬고 5초 내쉬는 한 번의 시각적 호흡을 시작합니다. |
| 키보드에서 `sum` 순서대로 입력 | 숨은 메시지와 파티클 반응이 나타납니다. |
| **기억 지우기** | `sum` 이스터에그를 실행한 후 저장된 기억 표시를 지웁니다. |

## 이번 수정 내용

- 정적인 대체 화면 없이 애니메이션 전체가 꺼지는 `prefers-reduced-motion` 오류 보완.
- 첫 마우스 움직임의 비정상적인 이동 속도, 무제한 물결 누적 방지.
- 원본 설명과 달랐던 스크롤 색상 변경 보정.
- 모바일 파티클 수, Canvas 픽셀 비율, 프레임레이트 조절(기본 데스크톱 약 48fps / 모바일 약 30fps).
- 페이지가 백그라운드로 이동하면 렌더링을 멈추고 돌아오면 재개.
- 오디오 미지원/재개 실패 시 사이트 자체는 정상 동작하도록 안전 처리.
- 클릭/터치 입력을 Pointer Events 하나로 통일.
- 텍스트 스크램블과 키보드 접근성 개선, 클릭 가능한 요소의 포커스 표시.
- 실제로 기억하지 않던 이스터에그를 로컬 저장과 기억 삭제로 연결.
- **새로운 ‘한 번 숨 고르기’** 인터랙션 추가.

## 개인정보 및 보안

- 서버, API 키, 로그인, 분석 도구, 쿠키, 추적 요청이 없습니다.
- `sum` 이스터에그를 실행하면 `localStorage`에 **기억 여부를 나타내는 값 `1`**만 저장합니다. 이름, 입력 내용, 이동 궤적은 저장하지 않습니다.
- 브라우저에서 `localStorage`가 차단되어도 나머지 효과는 동작합니다.
- 외부 글꼴·이미지·오디오 파일을 로딩하지 않습니다.

## 호환성 / 문제 해결

- 최신 Chromium, Chrome, Edge, Firefox, Safari의 Canvas 2D 및 Web Audio API를 사용합니다.
- 음향은 클릭한 이후에만 작동합니다. 소리가 나오지 않아도 기본 연출은 계속됩니다.
- 브라우저가 Canvas 2D를 지원하지 않으면 화면은 정적 배경으로 대신 표시됩니다.
- `prefers-reduced-motion`이 설정되면 입자 애니메이션 대신 정지된 별빛을 보여줍니다.
- 문제가 발생하면 브라우저 개발자도구(F12)의 Console 탭을 확인하세요.
- 브라우저 자동화 점검은 보안 정책상 URL 접근 대신 **브라우저에 HTML 원문을 직접 주입하는 방식**으로 이루어졌습니다. 실제 배포 URL의 네트워크 환경은 별도 확인이 필요합니다.
