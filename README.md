# NOEMA — THE UNBOUND ATLAS

**Creative LAB · 38개의 세계, 하나의 감각.**

Creative LAB 저장소의 루트에 배치할 **정적 포털**입니다. 2026-11-14 기준 `teamprotofelix/Creative_LAB`의 `main` 브랜치에 존재하는 38개 폴더와 각 폴더의 `index.html`을 확인하고 연결했습니다.

## 저장소 루트에 설치하기

1. `NOEMA_Creative_LAB_Portal_v2_38worlds.zip`을 압축 해제합니다.
2. 압축 해제한 **내용물**인 `index.html`, `favicon.svg`, `assets/`, `README.md`, `.nojekyll`을 기존 `Creative_LAB` 저장소의 **루트**에 업로드합니다. ZIP 파일 자체를 올리거나 `NOEMA_PORTAL` 등의 상위 폴더를 만들지 마세요.
3. 기존 38개 작품 폴더는 수정·삭제하지 마세요. 포털 링크는 같은 저장소 안의 `./폴더명/index.html`을 가리킵니다.
4. 이미 존재하는 `CNAME` 파일은 **그대로 유지**하세요. GitHub 저장소에서 확인한 값은 `creative-lab.moip.ai.kr`입니다. 이 ZIP에는 `CNAME`을 넣지 않았습니다.
5. GitHub Pages가 `main` / `/(root)`에서 배포되도록 설정되어 있는지 확인합니다. 새 커밋이 배포되면 https://creative-lab.moip.ai.kr/ 에서 포털을 볼 수 있습니다. DNS 전파·Pages 배포는 GitHub의 실제 설정에 따릅니다.

로컬에서는 `index.html`을 더블 클릭해 화면과 컨트롤을 확인할 수 있습니다. **단독 ZIP에는 작품 폴더가 들어 있지 않으므로 작품 링크는 연결한 저장소에서만 정상적으로 열립니다.** 완전한 로컬 점검을 원한다면 기존 38개 폴더가 있는 저장소 루트에 이 파일을 복사하세요.

## 포털에서 할 수 있는 일

- **실시간 입자 우주**: 첨부된 MINDSCAPE 스타일의 3D 입자 구체를 바탕으로 새로 만든 38개 궤도형 네비게이터입니다. 빛나는 점을 클릭하면 오른쪽(모바일은 아래쪽)의 작품 상세 정보가 갱신됩니다.
- **입자 단어 형상화**: 원하는 단어를 입력해 입자 구체를 글자로 잠시 변화시킵니다. `파동`과 `정지 / 재생` 버튼이 동작합니다.
- **작품 입장**: 선택한 작품의 `이 세계로 입장하기`, 또는 아틀라스의 개별 카드를 클릭하면 해당 작품의 `index.html`로 직접 이동합니다.
- **무작위 세계 입장**: 두 개의 무작위 버튼이 현재 선택된 작품을 제외한 37개 중 하나로 바로 이동합니다.
- **5개 분야**: 인지·감각, 생명·진화, 기억·흔적, 발상·창조, 우주·차원. 분야 필터와 검색을 함께 사용할 수 있습니다.
- **선택형 사운드**: 기본적으로 꺼져 있으며, 사용자 클릭 후에만 브라우저 안에서 합성한 소리를 냅니다.
- **키보드**: 작품 영역에서 `←`, `→`는 이전·다음 세계, `B`는 파동, `/`는 검색창 포커스입니다. 키보드 사용자는 첫 번째 스킵 링크로 세계 목록에 바로 이동할 수 있습니다.
- **접근성과 저사양 대응**: 모바일 입자 수 축소, 고 DPI 픽셀 제한, 숨겨진 탭에서 프레임 일시 중지, `prefers-reduced-motion` 반영, Canvas 불가 시 일반 카드 링크 유지.

## 개발자가 알아둘 점

- 포털의 작품 데이터는 `index.html` 하단 `script#worldData`에 있습니다. 각 작품 카드는 HTML로 미리 기록되어 있으므로 **자바스크립트가 실행되지 않아도 카드 링크는 작동**합니다. 작품을 추가·제거하려면 데이터와 해당 카드를 모두 수정해야 합니다.
- 모든 링크는 `./폴더명/index.html`의 상대 경로입니다. GitHub Pages 사용자 지정 도메인뿐 아니라 프로젝트 하위 경로에서도 작동합니다.
- `.webp` 38장은 각 작품의 실제 캡처가 아니라 **포털 전용으로 생성한 추상 시각화**입니다. 사진·스크린샷으로 오해하지 않도록 제작했습니다.
- 루트에서 새로 만드는 파일만 포함합니다. 이미 존재하는 사이트의 HTML/CSS/JS는 번들에 넣지 않습니다.
- 외부 JS/CSS/CDN, 원격 API, 외부 글꼴, 쿠키, 추적기, 비밀키, 계정 정보, 빌드 단계가 없습니다. 외부 사이트로 이동하는 링크는 GitHub 저장소 링크뿐입니다.
- 로컬 사용자 입력(검색어·형상화 단어)은 사이트 내에서만 쓰이며 서버로 전송하지 않습니다. 오디오 재생은 명시적으로 선택해야 시작합니다.

## 검증

- GitHub 연결을 통해 저장소 내 38개 폴더에 각각 `index.html`이 있는지 확인했습니다.
- Chromium(HTML/CSS/JS 인라인 주입 시험)에서 데스크톱(1440×900), 모바일 세로(390×844), 모바일 가로(844×390)의 기본 기능과 주요 조작을 점검했습니다.
- 점검 항목: JS 예외 0개, 38개 카드, 이전/다음 선택, 입자 단어 형상화, 검색, 분야 필터 및 가로 화면의 넘침 여부. 실제 작품 진입은 배포 후 최종 확인이 필요합니다.
- 시험 환경의 브라우저는 로컬 HTTP 접속이 정책상 차단되어 있었으므로 **실제 GitHub Pages 게시 후의 CDN/DNS/정적 파일 서빙은 아직 검증하지 않았습니다.** 실제 배포에서 링크를 한 번씩 확인하세요.
