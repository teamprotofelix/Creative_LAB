# SENTIO — 당신을 기억하는 풍경

> 시간이 움직이고, 생명이 변하며, 마음이 그려지고, 인식이 따라옵니다.

사용자가 제공한 **SENTIO — 당신을 기억하는 사이트**의 개선판입니다. 순수 HTML/CSS/JavaScript 기반의 인터랙티브 명상 웹사이트로, 별도 빌드 도구, 서버 API, 외부 폰트 및 CDN이 필요하지 않습니다.

## 바로 실행하기

`index.html`을 크롬·엣지 등 최신 브라우저에서 열거나, 파일 전체를 GitHub Pages에 배포하세요. 상대 경로만 사용하므로 저장소 하위 경로에도 대응합니다.

## 네 개의 방

| 방 | 표현 | 조작 |
| --- | --- | --- |
| **01 시간** | 여러 개의 시간 물결 | 화면을 누르면 새로운 물결 생성 |
| **02 생명** | 콘웨이 생명 게임(세포 자동자) | 화면을 눌러 세포 군집 추가 |
| **03 마음** | 움직임에 반응하는 만다라 | 커서로 무늬를 변형하고 눌러 형태 조정 |
| **04 인식** | 즉각적인 점과 지연·반전된 점 | 마우스 또는 터치로 두 점 비교 |

방의 오른쪽 위 **나가기** 버튼 또는 `Esc`로 되돌아옵니다. 각 방의 **다시 그리기**를 누르면 그 방의 시뮬레이션을 새로 시작합니다. 일반 화면에서는 단축키 `1`, `2`, `3`, `4`로 각 방을 열 수 있습니다(버튼 등의 요소에 포커스가 있지 않을 때).

## 기억과 개인 정보

- 원본의 `sentio_visits_v1`, `sentio_last_v1` 저장 키를 **유지**하여 기존 방문 기록을 읽을 수 있습니다.
- `sentio_first_v2`는 새로 추가한 첫 방문 시각입니다. 기존 데이터에 없으면 이 버전을 처음 연 날부터 기록합니다.
- 방문 기록은 `localStorage`에만 보관됩니다. 별도의 전송이나 계정 연동이 **없습니다**.
- 오른쪽 상단 **기억** 메뉴에서 방문 횟수/최초 방문/직전 방문을 확인하거나, 확인 단계를 거쳐 지울 수 있습니다.
- 브라우저 저장소가 막혀도 페이지는 열리며, 방문 기록은 페이지 세션만 반영합니다.
- 방문 횟수는 **해당 브라우저에 저장된 기록**이지, 전체 이용자 순위나 사용자의 고유 식별자가 아닙니다.

## 사운드

오른쪽 상단 `♪`로 사용자가 직접 켤 수 있습니다. Web Audio API를 지원하는 브라우저에서 사인/삼각파 드론을 합성합니다. 기본값은 음소거이며 버튼을 반복해 눌러도 오실레이터를 계속 생성하지 않도록 구성했습니다. 탭이 보이지 않을 때 출력은 자동으로 줄어듭니다.

## 접근성/성능

- 포인터와 터치 조작을 동일한 이벤트 모델로 처리합니다.
- 키보드 초점 복구, `Esc`, 대화상자 포커스 순환 및 버튼 레이블을 지원합니다.
- 운영체제의 `prefers-reduced-motion` 환경에서는 움직임 강도를 줄이고 프레임 갱신 간격을 늘립니다.
- 캔버스 고해상도를 화면 크기에 맞춰 제한하며, 하나의 렌더링 루프만 유지합니다.
- 양자 관찰·마음·인식 등 표현은 철학적 **은유**이며 실제 의식/뇌/물리 현상의 측정이나 재현은 아닙니다.

## GitHub Pages 배포

1. 이 폴더의 내용을 압축 해제한 뒤, **내용물 자체**(`index.html`, `style.css`, `main.js`, `favicon.svg`, `.nojekyll` 등)를 저장소 루트에 업로드합니다.
2. GitHub 저장소의 **Settings → Pages**를 엽니다.
3. **Build and deployment → Source: Deploy from a branch → Branch: main / (root)**를 선택하고 저장합니다.
4. Pages가 표시하는 주소로 방문합니다.

개인 서버, API 키, Node/npm 설치는 필요하지 않습니다.
