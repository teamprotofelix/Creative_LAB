# SENTIO 개선판 검증 기록

## 원본에서 발견한 문제 및 수정

| 원본 문제 | 해결 |
| --- | --- |
| 저장소 접근이 차단되면 앱 전체가 초기화되지 않음 | 읽기·쓰기·삭제 전부 예외 처리 |
| 시간대 팔레트가 최초 한 번만 적용되고 삼항 조건 순서가 잘못됨 | 5개 시간대별 팔레트 명시, 30초마다 시간대 갱신 |
| 방을 연속 호출하면 중복 렌더 루프 생성 가능 | 단일 중앙 렌더 루프로 전환 |
| 모바일의 조작 범위·좌표·화면 너비 취약 | 포인터 이벤트 통합, CSS 픽셀 기준 좌표, 반응형 UI |
| 방을 열면 키보드 포커스 이동/복구 없음 | `role=dialog`, 포커스 이동/순환·복귀·Escape |
| 오디오 반복 ON/OFF 시 오실레이터 누적 가능 | 재생 노드 1회 초기화, Gain 토글·스케줄 취소 |
| 움직임 감소 환경 지원 없음 | reduce-motion에서 전환/배경 효과 완화, 프레임 감소 |
| 방문 삭제 기능 없음 | 2단계 확인 후 브라우저 기록 삭제 |

## 브라우저 자동 확인

Python Playwright + Chromium 렌더링 엔진으로 **35개 시나리오 통과 (35/35)**.

- 데스크톱 첫 화면/캔버스/첫 방문 카운트
- 네 방 각각 열기, 캔버스 생성, 클릭, 다시 그리기, 닫기
- 방 반복 열고 닫기 5회/JS 예외 확인
- Escape 및 포커스 복귀
- 기억 패널/삭제 확인/취소/최종 삭제
- 사운드 on/off의 버튼 상태 변경
- 21번째 방문 기록 표현
- 모바일 화면 가로 넘침 없음/터치 조작/닫기
- 저장소 접근 금지 시 앱 생존
- 동작 줄이기 환경에서 화면 표시
- 브라우저 실행 오류 없음

**시험 환경의 제한:** 자동 브라우저가 파일/localhost 탐색을 차단하여 소스를 테스트 페이지에 직접 주입해 실행했습니다. 파일 자체에 대한 일반 브라우저 탐색, 실제 GitHub Pages 배포, 실제 음향 출력 및 장시간 부하·모든 기기의 동작을 검증한 것은 아닙니다. 오디오 테스트는 UI 상태 변경과 JavaScript 오류 유무 중심입니다.

## 정적 파일 검사

- JavaScript: `node --check main.js` 문법 검사
- 내부 의존 파일: HTML/CSS/JS/로컬 SVG 파비콘만 사용
- 데이터 전송, API 키 및 외부 호스트 호출 로직 없음
