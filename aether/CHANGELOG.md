# AETHER 개선 내역

## v2.0 — 안정화와 인터랙션 확장

### 원본 검토에서 발견한 문제

1. `touchstart`와 `click`을 동시에 등록하여 모바일의 한 번 탭이 두 번 처리될 수 있었습니다.
2. `mousemove`가 HTML 버튼과 관계없이 창 전체에 걸려, 컨트롤을 조작할 때도 장면 입력이 발생했습니다.
3. 입자 가속도·감쇠·위치 갱신이 프레임 단위여서 30 / 60 / 120 Hz 환경마다 움직임이 달라졌습니다.
4. `resize()` 이후 `initParticles()`를 재호출해 입자의 애니메이션을 처음부터 다시 시작했습니다.
5. 고해상도 대형 모니터에서도 DPR 2까지 캔버스 전체를 확대해 렌더링 부담이 커질 수 있었습니다.
6. 탭이 숨겨진 동안에도 다음 애니메이션 프레임을 계속 요청했습니다.
7. 운영체제의 움직임 감소 선호와 키보드 조작을 반영하지 않았습니다.
8. 사운드가 기본 켜짐 상태이고 브라우저 정책상 초기 오디오 생성에 실패할 수 있는 상황을 세심하게 안내하지 않았습니다.

### 수정

- 포인터 입력 통일, 터치 캡처, 터치 더블 탭 인식
- 물리 연산을 고정 1/60초 스텝으로 분리
- 화면 크기 변경 시 위치 비율 조정 및 형태 좌표 재계산
- 모바일 입자/프레임 제한, 렌더링 픽셀 예산 제한
- 화면 비가시 시 애니메이션 프레임 취소 및 재개
- Sound OFF 기본값, Web Audio 예외 처리
- 움직임 감소 선호, 일시정지/재생, 키보드 및 ARIA 접근성
- 빛의 개화/궤도/호흡 3개 모드, 순간 형태 변화, 초신성 효과
- CSS/JS 분리, 외부 의존성 제거, GitHub Pages 구성
