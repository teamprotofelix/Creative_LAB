# AETHER — 생명의 언어

빛 입자들이 3차원으로 움직이며 호흡하는 **정적 인터랙티브 아트 웹사이트**입니다.

## 바로 시작하기

- `index.html`을 더블클릭하거나 정적 서버에서 엽니다.
- 온라인 라이브러리, API 키, 외부 이미지, 서버, 계정이 **필요 없습니다**.
- PC와 모바일의 Chrome, Edge, Safari, Firefox 계열 최신 브라우저를 대상으로 설계했습니다.

## 조작

| 조작 | 효과 |
| --- | --- |
| 마우스 이동 / 손가락 드래그 | 입자 반발과 유기적인 상호작용 |
| 클릭 / 터치 | 충격파와 시적 메시지, 사운드(켜져 있을 때) |
| 더블클릭 / 두 번 탭 | 초신성 이스터에그 |
| 호흡 / 개화 / 궤도 버튼 | 세 가지 3D 입자 형태 전환 |
| 스피커 버튼 / `M` | 사운드 켜기·끄기 (기본 꺼짐) |
| 일시정지 버튼 / `P` | 움직임 정지·재개 |
| 재생성 버튼 / `R` | 입자 재탄생 |
| 숫자 `1` / `2` / `3` | 형태 직접 선택 |
| `Space` | 화면 중앙에 충격파 |

> 운영체제에서 **움직임 감소**를 설정한 경우에는 처음부터 애니메이션을 일시정지한 상태로 표시합니다. 움직임 버튼을 누르면 실행됩니다.

## GitHub Pages 배포

1. ZIP을 풀어 파일 `index.html`, `assets/`, `README.md`, `.nojekyll`을 **저장소 루트**에 업로드합니다.
2. GitHub 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, `main`, `/(root)`를 선택하고 저장합니다.
3. 배포가 완료되면 `https://<username>.github.io/<repository>/`를 방문합니다.

`aether-site.zip`의 최상위에 `index.html`이 있으므로, GitHub 업로드 시 전체 ZIP을 파일 하나로 업로드하지 말고 **압축을 풀어 내용물을 업로드**하세요.

## 구성

```text

```

## 구현·운영 고려사항

- HTML / CSS / JavaScript / Canvas 2D / Web Audio API만 사용합니다.
- 서버 연동 및 데이터 전송, 추적기, 외부 폰트, CDN, API 키가 없습니다.
- 터치/마우스 입력을 Pointer Events로 통합해 모바일 중복 발화를 막습니다.
- 60 Hz 고정 시뮬레이션과 프레임 스킵을 사용합니다. 모바일은 최대 30 fps를 목표로 합니다.
- 고해상도 렌더링 픽셀 수를 제한하고, 환경에 따라 입자 수를 줄입니다.
- 숨겨진 탭에서는 애니메이션을 멈추고 복귀 시 시간을 다시 동기화합니다.
- 화면 크기를 바꿔도 기존 입자의 상태를 유지합니다.
- 오디오 재생은 사용자 조작으로 활성화해야 합니다. 브라우저 정책에 따라 처음 조작에서 바로 소리가 들리지 않을 수도 있습니다.
