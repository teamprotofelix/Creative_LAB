# 「관찰자 · The Observer」 코드 검토 및 개선 보고서

## 1. 검토 대상

사용자가 제공한 「관찰자 (The Observer) — 우주가 스스로를 바라보는 방식」 원본 텍스트의 `index.html`(단일 파일), `README.md`, `.nojekyll` 작성 예시를 기준으로 검토했습니다. 원본의 7장면 구조, 방문자의 움직임→별자리, 과거 방문의 흔적, 3분 후 비밀이라는 핵심 기획을 유지했습니다.

## 2. 발견한 주요 문제와 수정

| 중요도 | 원본에서 확인한 문제 | 개선 내용 |
|---|---|---|
| 높음 | `resize()`에서 `portrait.width`와 `portrait.height`를 다시 지정하면 별자리 그리기가 초기화됨 | 궤적을 정규화 좌표로 저장하고, 프레임마다 화면 크기에 맞춰 다시 그림. 화면 크기 변경 후에도 유지 |
| 높음 | 이전 방문의 별자리를 화면 **픽셀 좌표 그대로** 저장해 다른 크기의 화면에서 어긋남 | `v2` 정규화 좌표 저장, 값·개수 검증, 레거시 데이터 근사 변환 |
| 높음 | 8초 후 사용자 입력과 무관하게 다음 장면으로 넘어감. "당신이 없으면 우주도 없다"와 구현이 모순됨 | 첫 번째 움직임 또는 클릭·터치·키보드 버튼 입력이 있을 때까지 시작 장면에서 대기 |
| 높음 | 움직이지 않았을 때 임의의 40개 좌표를 생성해 사용자의 별자리인 것처럼 표시함 | 가상의 사용자 흔적 제거. 기록이 없으면 기록이 없음을 명확히 표시 |
| 중간 | 장면이 전부 자동 전환되어 되돌아가기, 멈춤, 다시 시작 기능이 없음 | 7장면 네비게이션, 일시정지·재생, 재시작, 키보드 단축키 구현 |
| 중간 | `performance.now()`를 기준으로 장면 진행하여 비활성 탭에서 돌아온 뒤 장면이 갑자기 바뀔 수 있음 | `requestAnimationFrame`의 실제 활성 시간만 누적. 숨긴 탭·일시정지 시간은 장면과 3분 비밀에 반영하지 않음 |
| 중간 | `setInterval`로 입자를 계속 생성하고 캔버스를 프레임마다 그림. 고해상도·모바일 배터리 부담 | 최대 입자 수와 해상도 제한, 줄어든 움직임 지원, 배경 탭 처리, 프레임별 시간에 따른 생성 |
| 중간 | 모든 화면에 `cursor:none`, 전체화면 `touchmove.preventDefault()` 적용. 도움말·터치 없는 사용자의 접근성 부족 | 기본 커서 유지, 클릭 가능한 표면 제공, 화면 버튼과 키보드 조작, `dialog` 모달, 라벨·포커스 표시 |
| 중간 | 저장된 값을 검증 없이 읽어 과도한·손상된 값이 잘못 그려질 수 있음 | 길이 제한 및 좌표 형식·범위 검사, 저장 실패 무해화, 저장 옵션과 삭제 UI 제공 |
| 중간 | 이전 기록을 사용자가 직접 저장·삭제하거나 외부에 내보낼 방법 없음 | 이미지 PNG 저장, 기억 미리보기, 저장 켜기/끄기, 이전 방문 기록 삭제 |
| 낮음 | 외부 Google Fonts 로딩으로 외부 연결과 글꼴 의존성이 생김 | 외부 글꼴 호출 없이 시스템 글꼴 사용, HTML/CSS/JS 외부 의존성 0개 |
| 낮음 | 낮은 대비의 안내 텍스트, 고정된 데스크톱 UI | 대비·터치 영역 조정, 모바일(390×844)·PC(1440×900) 반응형 검토 |

## 3. 기능 강화

- 7막의 핵심 화면을 유지하면서 빛의 중심, 배경 별, 성운, 궤도, 입자 네트워크와 사용자 별자리 연출을 재구성했습니다.
- 3분 비밀에는 새로운 메시지뿐 아니라 특별한 황금색 궤도 연출을 추가했습니다.
- 별자리 이미지 다운로드는 **1600×1000 PNG 포스터**로 작성합니다.
- 브라우저 내부 기록인지 명시하고, 저장 공간이 막혀도 앱이 동작하도록 처리했습니다.
- 모든 리소스 파일 경로를 상대경로로 연결해 GitHub Pages의 저장소 하위 경로에서도 이용하도록 설계했습니다.

## 4. 검증

- `node --check app.js`: **통과**.
- Chromium의 DOM에 동일 HTML/CSS/JS를 삽입하는 방식으로 PC **1440×900** 및 모바일 **390×844** 상호작용 시험: **통과**. 시험 중 JavaScript 예외 **0건**.
- 마우스 이동·클릭/모바일 터치 → 별자리 기록: **통과**.
- 장면 이동 → 계시 화면 → 브라우저 저장 → 기억 보관소 → 이미지 PNG 다운로드: **통과**.
- 일시정지·재생, 움직임 줄이기, 재시작: **통과**.
- 화면 크기 변경 뒤 좌표 값이 `0~1`로 유지됨: **통과**.
- 첫 입력 전에는 인트로 진행을 멈추고 가짜 움직임을 만들지 않음: **통과**.
- 키보드 좌우 장면 이동 및 스페이스 일시정지: **통과**.
- 실제 3분 대신 시험 전용으로 판정 시간을 축소해 비밀 잠금·해제 논리 검증: **통과**. 정식 배포 코드의 해제 기준은 **180초**입니다.
- `localStorage`를 사용할 수 없는 환경의 화면·입력 기능: **통과**.

### 검증 범위의 한계

실행 환경의 Chromium 관리 정책이 `file://` 및 `http://localhost` 페이지 내비게이션을 차단하여, **외부 CSS·JS 파일을 실제 URL로 요청하는 통합 검증은 수행하지 못했습니다**. 대신 브라우저 DOM에 HTML과 동일한 CSS·JS를 삽입한 테스트를 수행하고 정적 파일 경로를 별도 확인했습니다. 실제 GitHub Pages에 업로드한 뒤 배포 URL로 한 번 더 확인하는 것을 권장합니다.
