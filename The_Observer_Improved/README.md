# 관찰자 · THE OBSERVER

> 당신이 바라보는 순간, 우주는 자신을 기억합니다.

방문자의 마우스·터치·키보드 입력이 빛과 궤적이 되는 **7막의 몰입형 정적 웹사이트**입니다. 이전 방문의 별자리를 같은 브라우저에서 다시 볼 수 있습니다. HTML/CSS/JavaScript만 사용하며 빌드, API 키, 회원가입, 외부 이미지 및 외부 라이브러리가 필요 없습니다.

## 시작하기

1. ZIP을 압축 해제합니다.
2. `index.html`, `styles.css`, `app.js`, `favicon.svg`, `.nojekyll` 등을 **같은 폴더**에 둡니다.
3. `index.html`을 브라우저로 열어 미리 확인합니다. 저장 관련 기능은 웹 서버에서 더 일관되게 동작합니다.
4. GitHub 저장소의 **루트**에 파일들을 업로드합니다. `the_observer_improved` 폴더 자체를 업로드하는 것이 아니라 **그 안의 파일들**을 올립니다.
5. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**를 선택합니다.
6. 게시된 GitHub Pages 주소에 접속합니다. 저장소 하위 경로에서도 상대 경로를 사용하므로 작동하도록 구성했습니다.

로컬 서버로 확인하려면 압축을 푼 폴더에서 다음을 실행할 수 있습니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`에 접속합니다. Python은 **로컬 미리보기에만** 사용하며 GitHub Pages에는 필요 없습니다.

## 체험 흐름

| 막 | 이름 | 자동 재생 시간 | 관찰 |
| --- | --- | ---: | --- |
| 01 | 시작 · Threshold | 8초 | 관측의 시작. 첫 움직임이 있기 전까지 다음 장면으로 넘어가지 않음 |
| 02 | 각성 · Awakening | 9초 | 움직임과 터치가 빛을 만들어 냄 |
| 03 | 출현 · Emergence | 14초 | 입자가 생겨나 궤도로 모임 |
| 04 | 생명 · Life | 14초 | 입자 사이에 관계망이 나타남 |
| 05 | 회귀 · Return | 11초 | 입자가 중심으로 돌아감 |
| 06 | 계시 · Revelation | 25초 | 지금 방문의 별자리와 과거 방문의 흔적이 겹침 |
| 07 | 소멸과 지속 · Afterglow | 무제한 | 별자리가 서서히 희미해지고, 활성 체험 3분 후 특별한 메시지와 시각 효과 발생 |

자동 재생은 첫 입력 이후 **약 81초**이며, 시작 단계에서 움직임을 기다린 시간은 추가될 수 있습니다. 화면 하단 7개 장면을 누르면 자유롭게 건너뛸 수 있습니다. 장면을 건너뛰어도 3분의 비밀은 실제 활성 관측 시간이 충족되어야 열립니다.

## 조작법

- **마우스 이동 / 터치 드래그**: 움직임의 궤적을 별로 기록합니다.
- **클릭 / 탭**: 한 번의 입력도 하나의 별로 기록합니다.
- **화면의 '화면을 움직이거나 터치하세요' 버튼**: 키보드만 쓰는 사용자도 별 하나를 만들 수 있습니다.
- **← / →**: 앞·뒤 장면 이동. 화면 하단의 7개 장면 버튼도 사용 가능합니다.
- **Space / 하단 일시정지**: 재생 일시정지 / 계속하기.
- **↺ 다시 시작**: 새로운 관측 시작. 저장이 켜져 있으면 이전 관측이 기억으로 남을 수 있습니다.
- **상단 '움직임'**: 애니메이션을 줄입니다. OS의 움직임 줄이기 설정도 기본 반영합니다.
- **상단 '기억 보관소'**: 현재·이전 흔적 미리보기, 저장 설정, 이전 방문 기록 삭제, 별자리 PNG 다운로드.
- **상단 '안내'**: 사용 설명. `Esc` 키로 도움말을 닫을 수 있습니다.

## 개인정보·저장 방식

이 사이트는 **마이크, 카메라, 위치, 계정, 쿠키, 원격 데이터베이스, 네트워크 API 호출**을 사용하지 않습니다. 움직임은 현재 브라우저의 캔버스에만 표시됩니다.

- 사용자가 저장 기능을 켠 경우, 최대 300개까지의 **정규화된 화면 좌표**(`0~1`)가 `localStorage`에 저장될 수 있습니다.
- 계시 장면에 도달하거나 페이지를 떠날 때 저장하며, 다음 방문에서는 지난 흔적을 희미한 별자리로 보여 줍니다.
- 상단 '기억 보관소'에서 자동 저장을 끄면 **이전에 저장된 데이터도 삭제**됩니다.
- '이전 방문 기록 삭제'는 브라우저에 저장된 이전 기록을 지우지만, 현재 열린 체험의 흔적은 그대로 유지합니다. 자동 저장을 켜둔 상태에서 현재 체험을 떠나면 다시 기록이 저장될 수 있습니다.
- 브라우저가 저장 기능을 차단해도 시각 체험과 PNG 다운로드는 가능합니다. `file://` 접근에서 저장 정책은 브라우저마다 다를 수 있습니다.
- 원본의 `observer_constellation` 데이터는 화면 크기 정보를 포함하지 않아 정확히 복원할 수 없습니다. 가능한 경우 현재 화면 비율에 맞춰 **근사치로** 불러옵니다. 새로 기록하는 좌표는 화면 비율 변화에 대응합니다.
- **PNG 다운로드는 브라우저에서만 생성**하며 서버에 이미지를 업로드하지 않습니다.

## 참고

이 작품은 의식과 우주를 묘사하는 **시적·예술적 인터랙션**이며, 실제로 사용자의 생각이나 신경 활동을 측정하거나 분석하지 않습니다. HTML의 메타데이터는 추가했지만 소셜 공유 미리보기 이미지는 포함하지 않았습니다.
