# LIMEN — 존재의 가장자리

> 정답이 아니라 경험으로 사유하는, 여섯 개의 살아 있는 정원.

## 바로 실행하기

`index.html`을 더블클릭해 Chrome, Edge, Safari, Firefox 등의 최신 브라우저에서 여세요. 별도의 서버, 빌드, 설치, API 키가 필요하지 않습니다.

## GitHub Pages 배포

1. 이 ZIP의 내용물(`index.html`, `styles.css`, `app.js`, `favicon.svg`, `README.md`)을 GitHub 저장소 **루트**에 업로드합니다. 폴더 `limen-garden` 자체를 올리기보다 그 안의 파일을 올리세요.
2. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
3. Branch를 **main**, Folder를 **/(root)**로 지정하고 **Save**합니다.
4. 제공된 `https://<계정>.github.io/<저장소>/` 주소에서 접속하세요. GitHub Pages는 처음 게시될 때 약간의 시간이 걸릴 수 있습니다.

이미 다른 사이트가 해당 저장소 루트에서 작동 중이라면, 별도 리포지토리를 만들거나 하위 디렉터리에 이 파일들을 올려 `https://.../<저장소>/<하위디렉터리>/`로 접속하세요.

## 정원 사용법

- **숨:** 호흡의 원을 바라보세요. 호흡 길이와 안내를 조절할 수 있습니다.
- **시간:** 슬라이더 또는 화면 터치로 시간의 색과 지형을 바꿉니다.
- **마음:** 한마디를 적고 호수에 놓으면 빛과 파문이 생깁니다. 입력은 전송하거나 저장하지 않습니다.
- **생명:** 화면에 씨앗을 심고 계절을 바꿔보세요. 매번 다른 생성 규칙으로 나무가 자랍니다.
- **인식:** 마우스/손가락을 움직여 또 하나의 현실을 보세요. 누르면 안과 밖이 뒤바뀝니다.
- **관계:** 빛을 터치하면 무리의 움직임이 달라집니다. 빛 하나를 남길 수도 있습니다.
- 여섯 정원을 모두 방문하면 **나의 문장 보기**가 열립니다. **멈춤의 방**도 방문할 수 있습니다.

키보드: `1`~`6` 정원 선택, `←`/`→` 이전·다음, `Space` 현재 정원과 상호작용, `Esc` 안내 닫기.

오른쪽 위의 소리 버튼은 **기본 꺼짐**입니다. 소리는 사용자가 직접 켤 때만 Web Audio로 생성됩니다. **순간 저장** 버튼은 현재 장면을 PNG 이미지로 내보냅니다(화면 너비가 충분한 환경에서 제공).

## 구현과 개인정보

- HTML + CSS + 바닐라 JavaScript + Canvas 2D + 선택적 Web Audio.
- 의존성, CDN, 외부 API 호출, 분석 스크립트, 쿠키, 로그인, 추적 코드가 없습니다.
- 사용자가 마음의 호수에 쓴 문장은 메모리에서만 사용되며 브라우저를 새로고침하면 사라집니다.
- 저사양/모바일을 위해 Canvas 해상도와 입자 수를 조절하며, OS `prefers-reduced-motion` 설정을 존중합니다.
- 외부 이미지나 폰트를 다운로드하지 않아 인터넷 연결 없이도 실행됩니다.
- 모든 경로는 상대 경로로 작성되어 GitHub Pages의 하위 경로에서도 동작합니다.

## 수정하기

- 정원의 문구는 `app.js` 상단 `scenes` 배열에서 변경합니다.
- 색상과 레이아웃은 `styles.css`에서 변경합니다.
- 시각 효과는 `app.js`의 `drawThreshold`, `drawBreath`, `drawTime`, `drawLake`, `drawLife`, `drawPerception`, `drawRelation`, `drawStillness` 함수에서 편집합니다.

오픈 웹 표준만을 사용하는 독립형 창작물입니다.
