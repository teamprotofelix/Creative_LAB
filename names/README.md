# 이름의 우주 · Universe of Names

**하나의 이름, 하나의 작은 우주.** 이름을 시드로 별과 성운을 생성하고, 각 글자를 누르면 별자리가 반응합니다. 우주의 시간을 탄생에서 소멸까지 이동시킬 수 있습니다.

## 바로 사용하기

압축을 푼 뒤 `index.html`을 더블클릭해 열 수 있습니다. 외부 패키지·서버·빌드·API 키가 필요 없습니다. Chrome, Edge, Firefox 등 최신 브라우저 사용을 권장합니다.

1. 이름을 입력하고 **우주를 탄생시키기**를 누릅니다.
2. 화면의 글자 별을 클릭/터치하면 반짝이는 입자가 나타납니다. 오른쪽 위 **♪**를 켜면 별마다 음이 납니다. 자동 재생 제한에 맞춰 기본값은 무음입니다.
3. 하단 슬라이더를 움직여 우주의 시간을 조절합니다.
4. **✳**는 빅뱅 다시 보기, **⧉**는 주소 복사, **↶**는 다른 이름으로 돌아가기입니다.
5. 키보드로 별을 선택하려면 캔버스에 포커스를 준 뒤 좌/우 화살표와 Enter 또는 Space를 사용합니다.

## GitHub Pages 배포

1. GitHub에서 빈 저장소를 생성합니다.
2. ZIP 파일을 압축 해제합니다. 폴더 **안에 있는 파일**(`index.html`, `style.css`, `script.js`, `favicon.svg`, `README.md`)을 저장소 최상위(root)에 올립니다. ZIP 자체를 올리면 페이지가 실행되지 않습니다.
3. 저장소의 **Settings → Pages → Build and deployment → Source: Deploy from a branch → main / (root) → Save**를 선택합니다.
4. 게시된 `https://사용자명.github.io/저장소명/` 페이지에서 동작을 확인합니다.

이 사이트는 상대 경로만 사용하므로 GitHub Pages의 프로젝트 하위 경로에서도 작동합니다.

## 공유 · 이름 · 개인정보

- 동일한 **정규화된 이름**에 대해 별들의 기본 배치, 성운, 별자리 구조, 음계가 결정론적으로 생성됩니다. 실시간 별빛의 깜박임과 애니메이션 시점까지 항상 같다는 의미는 아닙니다.
- 공유 버튼은 주소의 `?name=`에 이름을 담아 복사합니다. 이 주소를 공유하면 **이름이 공유 상대, 브라우저 방문 기록 또는 링크 로그에 노출될 수 있습니다.** 실명이나 민감한 정보를 입력할 필요는 없습니다.
- 마지막으로 입력한 이름은 이용 중인 브라우저의 `localStorage`에만 저장합니다. 이름으로 만든 장면은 외부 서버로 전송하거나 저장하지 않으며, 분석 도구·광고·원격 API 요청을 사용하지 않습니다.
- `file://`로 직접 열었을 때 복사·방문 기록 정책은 브라우저마다 다를 수 있습니다. 다른 기기와 공유하려면 **GitHub Pages로 배포된 URL**을 복사하세요.
- 32비트 이름 해시는 시각적 생성용으로, 암호학적 고유 식별자나 보안 기능이 아닙니다.

## 원본 대비 주요 수정

- 공유 URL 초기화에서 나머지 이벤트 리스너가 등록되지 않던 문제 수정
- `destroy()` 미구현으로 이전 우주의 `requestAnimationFrame`, resize, pointer 리스너가 남는 문제 수정
- UI 재진입 시 슬라이더 초기값(50)과 실제 시뮬레이션 시간이 불일치하던 문제 수정
- 별자리의 시드 구조를 상대 좌표로 생성해 화면 크기가 달라도 구조 유지
- 한글 자모 조합 등 동등한 이름은 NFC로 정규화, 이모지 등은 가능한 한 글자 단위(grapheme) 처리
- 자동 오디오 시도 제거, 명시적인 사운드 ON/OFF 및 실패 처리
- 클립보드 권한 실패 시 안내, 로컬 저장소 차단 시 오류 없이 계속 사용
- 작은 화면 터치 판정 확대, 키보드 포커스와 상태 안내 추가
- 성운 텍스처 메모리 크기 제한, 화면 비표시 때 렌더링 일시 정지
- 외부 폰트·프레임워크 없이 동작하도록 구성

## 검증 범위

- `node --check script.js` JavaScript 구문 검사
- Chromium의 DOM/CSS/JS 직접 주입 테스트: 이름 제출, 빅뱅, 사운드 토글, 별 선택, 슬라이더, 초기화, 모바일 터치, 동작 최소화, NFC 정규화, 시드 일치, 여러 번 재진입
- 공유 URL 초기화는 `URLSearchParams`를 모의한 테스트로 확인
- 캔버스 2D / WebAudio / localStorage 가용성이 제한된 가상 환경에서 예외 없이 기본 조작이 가능한지 확인

**검증의 한계:** 시험 환경에서 브라우저의 HTTP 및 `file://` 직접 탐색이 차단되어, 실제 GitHub Pages 배포 또는 직접 파일 열기 자체는 검증하지 않았습니다. 출시 전 실제 게시 URL에서 공유 링크와 복사 동작을 한 번 확인하는 것이 좋습니다.

## 프로젝트 구성

```text
index.html   페이지 구조와 조작 UI
style.css    화면 연출과 반응형 스타일
script.js    시드 기반 생성, 캔버스 렌더링, 오디오, UI 로직
favicon.svg  사이트 아이콘
README.md    설치·사용·검증 안내
```
