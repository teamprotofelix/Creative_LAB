# 관측소 · The Observatory — 개선판

6개의 장을 따라 내려가며 우주, 생명, 마음, 질문을 마주하는 **완전한 정적 웹사이트**입니다.

## 사용하기

1. ZIP을 압축 해제합니다.
2. `index.html`, `styles.css`, `app.js`, `favicon.svg`를 **같은 위치**에 둡니다.
3. `index.html`을 더블 클릭하면 로컬에서 작동합니다.
4. GitHub Pages에 배포할 때는 **ZIP 자체가 아니라 압축을 푼 파일 4개**를 저장소 게시 경로(예: 루트)에 업로드합니다.
5. GitHub 저장소 `Settings → Pages`에서 `Deploy from a branch`를 선택하고 `main` / `/(root)`로 지정합니다. 기존 포털 아래 하위 폴더에 넣어도 상대 경로로 정상 실행됩니다.

외부 라이브러리, CDN, 웹폰트, API 키, 서버, 빌드 과정, 회원가입이 필요 없습니다.

## 개선된 사항

- **질문과 답변의 정합성**: 원본은 같은 질문에 같은 문장이 나오지만 '다시 물으면 다른 답'이라고 표시했습니다. 지금은 첫 관점을 질문 해시로 결정하고, 별도 '다른 관점 보기' 버튼으로 새로운 관점을 순차 제공하도록 고쳤습니다.
- **정직한 안내**: 질문 답변은 AI나 과학적 사실을 단정하는 답이 아니라, 주제별 문장과 관점이 조합되는 **브라우저 내부의 시적 성찰 장치**라고 명시했습니다.
- **실제 상호작용**: 생명게임을 클릭해 새 세포를 심을 수 있고, 다시 씨앗을 뿌릴 수 있습니다. 다른 장에서도 클릭/터치 파문을 표시합니다.
- **장 전환 안정성**: 두 장이 함께 보일 때 `IntersectionObserver` 이벤트 순서에 따라 엉뚱한 장이 선택될 수 있던 문제를 화면 중심점 기준의 단일 장 선택 방식으로 수정했습니다.
- **성능 개선**: 보이지 않는 탭에서는 렌더링 중지, 현재 장 이외의 계산 최소화, 화면 면적에 따른 픽셀 비율 제한, 모바일의 입자 수 감소, 시간 기반 애니메이션으로 개선했습니다.
- **접근성**: 키보드 이동, 포커스 표시, 입력 라벨, 별도 제출 버튼, 건너뛰기 링크, 화면 읽기용 결과, 충분한 텍스트 대비 및 운영체제의 `prefers-reduced-motion` 반영을 추가했습니다.
- **편의 기능**: 장별 바로가기, 스크롤 진행률, 움직임 정지/재생, 관측 안내, 질문 글자 수, 답변 복사/텍스트 저장을 추가했습니다.
- **개인정보**: 질문은 전송되지 않으며 자동 저장하지 않습니다. 관측자 코드는 단순 장식용으로 방문 시 임시 생성하며 추적에 쓰이지 않습니다.

## 조작법

- 스크롤 또는 화면 오른쪽 장 번호: 각 장 이동
- ↑ / ↓ 키: 이전/다음 장 (텍스트 입력 중은 제외)
- 빈 화면 클릭/터치: 시각적 파문
- '생명' 장 빈 화면 클릭/터치: 세포 생성
- '질문' 장: 질문 입력 → Enter 또는 오른쪽 ↗ 버튼
- 상단 Ⅱ/▶: 움직임 일시정지 또는 재생

## 파일 목록

- `index.html`: 시맨틱 구조와 6개 장, 입력 및 컨트롤
- `styles.css`: 반응형 화면, 다크 테마, 접근성 스타일
- `app.js`: 캔버스 애니메이션, 상호작용, 생명게임, 로컬 성찰 문장 엔진
- `favicon.svg`: 로컬 아이콘

### 주의

'생명' 장의 격자는 콘웨이의 생명게임을 시각화한 **수학적 모형**입니다. 우주의 기원, 의식의 생성 과정이나 실제 생명 현상을 과학적으로 재현한 콘텐츠는 아닙니다. 질문의 답변 역시 독립적 조언이나 진단으로 사용해서는 안 됩니다.
