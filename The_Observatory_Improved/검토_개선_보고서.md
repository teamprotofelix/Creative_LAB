# 관측소 · The Observatory — 코드 검토 및 개선 보고서

## 검토 대상

사용자가 제공한 `index.html` 단일 파일 코드(첨부 텍스트에 포함)를 검토했습니다. 원래 컨셉(문턱 → 가능성 → 생명 → 마음 → 우주 → 질문)은 유지하면서 브라우저 동작과 사용자 경험을 중심으로 개선했습니다.

## 확인된 주요 문제

| 분류 | 원본의 구체적인 문제 | 개선 내용 |
|---|---|---|
| 정합성 | 동일 문자열은 동일 해시와 답변 인덱스로 계산하지만 `다시 물으면 다른 답이 나옵니다`라고 표시 | 첫 관점은 동일 질문에 일관되게 제시. `다른 관점 보기`로 명시적으로 변경 |
| 설명 정확성 | 텍스트 해시로 일반 문장을 고르는 방식인데 실제 질문에 대한 구체적 해답/우주의 답처럼 느껴질 수 있음 | 질문 주제별 성찰 문장 + 별도 관점을 구성하되, AI 답변 또는 과학적 해설이 아님을 표기 |
| 사용자 상호작용 | 원본 생명게임은 마우스 근처 셀의 밝기만 달라지며, 설명한 '세포들이 살아납니다'는 구현되지 않음 | 클릭/터치로 글라이더 및 R-펜토미노를 심고, 초기화 버튼을 제공 |
| 내비게이션 | IntersectionObserver 콜백에 여러 장이 동시에 들어오면 콜백 실행 순서가 마지막 모드를 결정할 수 있음 | 현재 화면 중심에 걸쳐 있는 장을 우선하여 단일 모드 선정 |
| 성능 | 메인 루프의 requestAnimationFrame이 탭을 떠나도 계속 예약되며, 화면 새로고침률에 따라 시뮬레이션 속도가 달라짐 | 탭이 숨겨지면 렌더링 정지, `dt` 기반 갱신, 오프스크린 시뮬레이션 계산 최소화 |
| 성능 | 모바일에서도 320 입자 + 900 별 + 90 뉴런 및 전체 DPR 2의 그래픽 연산 | 화면 크기에 따른 입자/별/뉴런 상한, 캔버스 최대 렌더링 면적 제한 |
| 접근성 | 질문 입력란의 시각적 라벨/제출 버튼 부족. 엔터 안내 외 대체 조작 부족 | 입력 라벨, 제출 버튼, 키보드 장 이동, 명확한 포커스, 스킵 링크, 도움말 제공 |
| 움직임 | 운영체제의 애니메이션 감소 설정과 수동 일시정지 미지원 | reduced-motion 자동 반영 + 상단 재생/정지 버튼 |
| 정적 호스팅 | 단일 코드 내 유지보수가 어렵고 문서화가 부족 | 상대 경로로 참조하는 4개 소스 파일 + README. GitHub Pages 하위 경로에서도 동작하도록 구성 |
| 장애 내성 | JS가 실패하면 텍스트 노출 애니메이션만 있는 구조로 일부 내용이 보이지 않을 수 있음 | JS가 없어도 본문 텍스트가 보이는 점진적 향상 구조 |

## 추가 기능

- 여섯 장의 탐색 메뉴·진행 막대·현재 장 표시
- 질문 180자 제한, 질문 사유 내용 복사 및 UTF-8 BOM 포함 `.txt` 저장
- 가입, 쿠키, 외부 API, CDN, 외부 추적 없이 동작
- 관측자 코드는 별도 저장되지 않는 임시 장식 요소

## 테스트 결과

- JavaScript 문법 검사: `node --check app.js` 통과
- Chromium 헤드리스 브라우저 화면/상호작용 테스트: **PC 1440×900**, **모바일 390×844** 통과
- 확인 항목: 첫 장 표시, 캔버스 생성, 도움말 열기·닫기, 생명 장 이동 및 새 씨앗, 질문 장 이동, 제출, 다른 관점에 따른 내용 변화, 텍스트 다운로드, 같은 질문 재제출 시 첫 관점 재현, 움직임 토글
- 모바일 환경에서 시스템 '애니메이션 줄이기' 사용 시 기본 일시정지 확인
- 두 화면 모두 문서 가로 넘침이 없음을 확인
- 테스트 시 JavaScript 예외 및 브라우저 콘솔 오류 미발생

**검증 범위**: Chromium에서 문서·스타일·스크립트를 묶어 주입하여 실제 화면 동작을 테스트했습니다. GitHub Pages에 직접 업로드하여 실서버 배포한 것은 아니며, 다른 브라우저·OS·고주사율 장치에서 모든 동작을 확인한 것은 아닙니다.

## 배포

ZIP을 풀고 `index.html`, `styles.css`, `app.js`, `favicon.svg`를 GitHub 저장소의 게시 폴더에 **동일 계층**으로 올립니다. `README.md`와 이 보고서는 선택적으로 함께 올릴 수 있습니다.
