| 원본의 문제 또는 위험 | 개선판에서 한 작업 |
|---|---|
| 여러 Canvas·커서·호흡의 상시 애니메이션 루프로 CPU/GPU 자원 사용 위험 | 통합 애니메이션 루프, 화면 밖 효과 정지, 숨김 탭 정지, 최대 픽셀 비율·파티클 수 제한 |

| 이름이 입력창의 change 이벤트 이후에만 별빛으로 반영 | input 이벤트와 짧은 디바운스로 입력 중 즉시 반영, 한글 글리프 픽셀 마스크 개선 |
| 생명체를 계속 추가할 수 있고 각 점을 매 프레임 다수 반복 그려 성능 악화 | 동시에 표시되는 생명 수 제한(휴대폰 11 / PC 18), 사전 계산한 곡선의 일부만 그림, 자동 소멸 |
| 키보드/터치 사용과 움직임 민감성에 대한 배려 부족 | 키보드 버튼, 장별 링크, 선명한 포커스, 원래 커서 유지, 모션 제한 버튼·OS 설정 연동 |
| 화면을 떠나도 앰비언트 사운드를 계속 처리할 가능성 | 기본 OFF, 명시적인 클릭으로 활성화, 백그라운드 탭일 때 suspend |
| 기억과 개인정보 관리가 구현되지 않은 채 ‘기억’ 표현 | 방문·호흡·씨앗 횟수와 동의한 단어만 저장, 삭제 기능 제공, 생년월일·이름은 저장하지 않음 |
| Google Fonts 외부 네트워크 요청 필요 | 시스템 글꼴 폴백으로 대체, 모든 파일 로컬 실행 가능 구조 |
| 6개 장면을 탐색할 수단이 스크롤뿐임 | 6장 내비게이션, 장면별 바로가기, 진행률 표시, 다시 시작 연결 |

## 수행한 검증

- `node --check main.js` 통과
- HTML의 ID 중복 없음, 내부 앵커 누락 없음, SVG XML 파싱 통과
- 실제 Chromium 브라우저에 동일한 HTML·CSS·JavaScript 내용을 삽입해 데스크톱(1440px), 모바일(390px) 동작 검사
- 호흡 시작·일시정지·초기화와 10초 주기 카운트 검사
- 날짜 입력, 미래 날짜 차단, 날짜 초기화 검사
- 빛의 씨앗 심기, 한글 텍스트 별빛 형성·흩뜨리기, PNG 이미지 다운로드 확인
- 단어 저장·재방문 복원·기록 삭제, 모션 제한 토글 확인
- 화면 너비 320·375·390·768·1024·1440·1920px에서 가로 넘침 및 JavaScript 예외 없음

## 검증의 범위

검사 환경의 관리자 보안 정책이 `file://` 및 로컬 HTTP 주소로 **직접 이동하는 테스트**를 차단하므로, 실제 파일 URL 접속 대신 동일 코드의 브라우저 삽입 방식을 이용했습니다. GitHub Pages 실배포 도메인에서의 라이브 테스트는 수행하지 않았습니다. 브라우저·단말 전체 조합과 장시간 성능을 100% 보증하는 결과는 아닙니다.
