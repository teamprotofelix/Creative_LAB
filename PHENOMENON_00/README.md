# 당신이라는 현상 · PHENOMENON

> 우주는 당신에게 설명을 요구하지 않습니다. 지금, 여기에 있다는 사실로 충분합니다.

외부 라이브러리·폰트·CDN·API·빌드 과정 없이 실행되는 GitHub Pages용 순수 HTML/CSS/JavaScript 인터랙티브 명상 사이트입니다.

## 여섯 장의 체험

1. **들어가며** — 한 점의 빛, 겹치는 궤도, 천천히 열리는 초대
2. **호흡** — 사용자가 시작·일시정지하는 4초 들숨 / 6초 날숨 안내; 주기 완료 횟수 집계
3. **시간** — 날짜 입력 후 달력일·박동·호흡·공전 기간의 *가정에 기반한 추정값*을 계산
4. **생명** — 클릭·터치·버튼으로 최대 11~18개의 빛나는 새싹을 생성하고 소멸
5. **우주** — 입력 즉시 별빛을 글자 형태로 배열, 초기화·예시·PNG 저장 지원
6. **지금** — 마음에 남길 단어를 **명시적으로** 로컬 저장, 기록 삭제 및 처음으로 돌아가기

## 실행 및 GitHub Pages 배포

ZIP을 풀고 `index.html`을 Chrome/Edge 등 브라우저에서 열면 됩니다. 로컬 파일(`file://`) 환경에서도 정상 작동하도록 설계했습니다.

GitHub Pages: 압축 해제한 **파일 내용물**(`index.html`, `style.css`, `main.js`, `favicon.svg`, `README.md`)을 저장소 루트에 업로드합니다. GitHub의 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save**를 선택하세요. `index.html`이 최상위에 있어야 합니다. 빌드 및 API 키는 필요하지 않습니다.

## 개인정보 및 저장

- **저장:** 방문 횟수, 체험한 호흡 완료 횟수, 심은 씨앗 횟수, 사용자가 명시적으로 저장한 단어. `localStorage`의 키 `phenomenon.memory.v2`를 사용합니다.
- **저장하지 않음:** 생년월일과 별빛에 입력한 이름/단어. 페이지를 벗어나면 사라집니다.
- **설정:** 움직임 제한 선택은 `phenomenon.motion.off`에 저장되며, 사이트의 **내 기록 모두 지우기** 버튼으로 함께 지울 수 있습니다.
- 외부 서버로 내용을 전송하지 않으며, 서드파티 코드·추적 스크립트·네트워크 호출이 없습니다.
- 저장 기능을 사용할 수 없는 브라우저에서도 기본 체험이 동작하고, 저장 제한 상태를 화면에 알려줍니다.

## 정확성 및 접근성

- **시간 계산은 건강·의료 데이터가 아닙니다.** 심장 박동(분당 72회), 호흡(분당 16회)을 평생 일정하다고 가정한 단순 추정입니다. 지구 공전 주기는 365.2425일로 근사합니다. 실제 측정값처럼 해석하면 안 됩니다.
- 생년월일은 브라우저 현지 날짜 기준으로 파싱해 미래 날짜·잘못된 날짜를 거부합니다.
- 앰비언트 사운드는 기본 OFF이며 사용자가 눌러야만 시작됩니다. 숨 안내는 의료용 호흡법이 아닙니다.
- 원래 커서를 숨기지 않고, 키보드 탐색/초점 표시·`prefers-reduced-motion` 및 움직임 제한 버튼을 지원합니다.
- 애니메이션은 화면에 나타나는 주요 장면만 계산하며 백그라운드 탭에서는 정지합니다.

## 파일

- `index.html`: 여섯 장의 페이지 구조
- `style.css`: PC/모바일/움직임 제한 디자인
- `main.js`: 모든 상호작용·애니메이션·로컬 저장
- `favicon.svg`: 자체 제작 벡터 아이콘
- `README.md`: 이 문서

## 제한 사항

Canvas 2D 및 JavaScript를 지원하는 최신 브라우저에서 동작합니다. 구형 브라우저, 특수 접근성 환경, 실제 배포 도메인의 환경 설정은 별도 점검할 수 있습니다. 데이터는 해당 브라우저·해당 사이트(origin)에서만 유지되며 기기 간 동기화되지 않습니다.
