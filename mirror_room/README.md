# 거울 · MIRROR 2.0

> 당신이 보는 것은, 당신이 만드는 것입니다.

**순수 HTML / CSS / JavaScript로 만든 GitHub Pages용 정적 사이트입니다.** 반응-확산 패턴이 손끝을 따라 피어나고, 9초의 고요함 뒤에는 화면에 남긴 움직임이 거울처럼 드러납니다. 서버·로그인·API 키·CDN·외부 폰트를 사용하지 않습니다.

## 체험하기

1. `index.html`을 Chrome, Edge 등 브라우저로 열거나 GitHub Pages에 게시합니다.
2. 화면을 마우스로 움직이거나 손가락으로 누르고 드래그하면 청록색 패턴이 나타납니다.
3. 이야기를 따라가며 시간에 관한 예시 숫자를 보고, **정지** 장면에서 9초간 움직이지 않습니다.
4. **거울** 장면에서 그동안 남긴 궤적을 확인합니다.
5. **이미지 저장**을 누르면 현재 화면을 PNG로 저장합니다. 전체 체험은 대략 2분 전후이며 움직임을 기다리는 시간에 따라 달라집니다.

### 조작

- **일시정지:** 스페이스바 또는 하단 `Ⅱ` 버튼
- **다음 장면:** `N` 또는 하단 `↗` 버튼 (현재 장의 나머지 대사를 건너뛰고 다음 장으로 이동)
- **키보드로 움직임 만들기:** 방향키 ↑ ↓ ← →
- **다시 시작:** 하단 `↺` 버튼 (방문 횟수는 증가하지 않음)
- **PNG 저장:** 하단 `↓` 버튼
- **안내·기록 삭제:** 하단 `?` 버튼, 닫기는 `Esc`

이야기 중에 화면을 움직이지 않았다면 선을 만들어 내지 않습니다. 저장된 경로가 없을 때는 거울 장면에 그 사실을 정직하게 알립니다.

## GitHub Pages 배포

압축파일을 풀어 다음 파일을 **저장소의 루트**에 직접 업로드하세요.

```text
index.html
styles.css
app.js
favicon.svg
.nojekyll
README.md
검토_개선_보고서.md
```

GitHub 저장소에서 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)**를 선택하세요. `index.html`과 나머지 정적 리소스를 같은 폴더에 둬야 합니다.

빌드, npm, Node.js, 패키지 설치가 필요하지 않습니다. 로컬에서도 `index.html`을 더블클릭해 체험할 수 있습니다. 다만 일부 브라우저는 `file://` 주소에서 로컬 저장소를 막을 수 있어 그 경우 방문 횟수가 저장되지 않고 나머지 기능은 동작하도록 설계했습니다.

## 개인정보와 추정 수치

- **외부 네트워크 요청이 없습니다.** 접속 기록, 마우스·터치 궤적, 신체 정보는 서버로 전송하지 않습니다.
- **방문 횟수만** 이 브라우저의 `localStorage`에 보관합니다. `?` → `이 브라우저 방문 기록 삭제`로 지울 수 있습니다.
- 마우스/터치 경로는 탭이 열려 있는 동안 **메모리에서만** 유지합니다. PNG 저장은 사용자 버튼을 눌렀을 때만 이루어집니다.
- **심박수 72회/분은 가정값**이며 사용자의 실제 심박수를 읽지 않습니다. 공전 속도 29.78km/s, 광속 299,792.458km/s도 시간에 곱한 설명용 계산입니다. 개인의 세포 사멸량은 측정하지 않으며 그럴듯한 숫자로 대체하지 않습니다.

## 기술 설명

원본의 Gray–Scott 반응-확산 모델(반응식 및 9점 이산 라플라시안)을 기반으로 합니다. 사용자가 입력한 위치의 화학물질 B 농도를 높여 패턴을 생성합니다. 일정 시간 입력이 없으면 B 농도를 추가로 감소시키는 **연출용 감쇠**를 적용하여 '주의가 사라지면 서서히 희미해진다'는 경험을 구현했습니다. 이 효과를 과학적 생명 현상의 증명으로 해석하면 안 됩니다.

뷰포트 크기가 달라져도 화학장 패턴은 새 그리드로 재표본화하고 사용자 궤적은 정규화 좌표로 유지합니다. 페이지가 숨겨지거나 수동 일시정지되면 애니메이션과 이야기 시간이 멈춥니다. 낮은 성능의 모바일·동작 줄이기 환경에서는 업데이트 빈도를 낮춥니다.

## 파일 구성

- `index.html` — 문서 구조, 조작 버튼, 도움말
- `styles.css` — 테마, 반응형 레이아웃, 접근성 스타일
- `app.js` — 이야기 엔진, 반응-확산, 궤적, 저장, 키보드/터치 지원
- `favicon.svg` — 사이트 아이콘
- `.nojekyll` — GitHub Pages가 Jekyll 전처리를 건너뜀
- `검토_개선_보고서.md` — 원본 점검 결과 및 테스트

**검증 환경:** 헤드리스 Chromium의 PC 1440×900, 모바일 390×844, 가로형 844×390. Canvas 실행, 장면 탐색, 정지 타이머, 키보드 입력, PNG 출력 등 확인. 실제 GitHub Pages 운영 주소는 사용자가 배포한 후 별도 점검이 필요합니다.
