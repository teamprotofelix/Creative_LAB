## 유지한 원작의 핵심

- **Gray–Scott 반응-확산 모델**의 화학물질 A/B 상호작용 및 화면에서 직접 패턴을 만드는 입력 경험
- '움직이면 만들어지고, 가만히 있으면 약해진다'는 미학적 서사
- **9초의 고요함**과 그 후에 드러나는 사용자 이동 궤적
- 시간, 몸, 지구, 빛을 연결하는 사유 장면
- 이름·계정 없이 같은 브라우저의 방문 횟수만 간직하는 결말

**테스트 범위의 제한:** 보안 정책상 자동화 브라우저가 로컬 HTTP 및 `file://` 이동을 차단하여, 테스트에서는 동일한 HTML/CSS/JavaScript를 한 페이지에 주입해 브라우저 동작을 확인했습니다. 이 때문에 실제 GitHub Pages 서버의 응답 헤더, CDN 캐시, 사이트 주소와 관련된 배포 환경은 검증한 것으로 주장하지 않습니다. 자동화 테스트가 실행된 임시 페이지에서는 `localStorage` 접근이 제한되어, 방문 횟수 지속 저장의 실제 성공 여부는 Pages 배포 후 확인할 필요가 있습니다.

## 배포 안내

별도 빌드가 없는 정적 사이트입니다. ZIP의 파일을 **압축을 풀어** GitHub Pages 저장소 루트에 올리면 됩니다. `index.html`은 상대 경로 `styles.css`, `app.js`, `favicon.svg`를 참조합니다. 외부 폰트, API 키, 계정, 비밀번호, 광고/분석 스크립트가 없습니다.
