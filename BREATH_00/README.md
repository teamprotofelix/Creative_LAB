# 숨 · BREATH — 관찰될 때 피어나는 세계

> 당신이 바라보는 동안 세계는 숨을 쉽니다.

[기존 '숨 (Breath) — 관찰될 때 존재하는 페이지'를 기반으로 만든 안정화·확장 개선판]

## 체험 방법

- **움직임**: 화면 위에서 마우스 또는 손가락을 움직여 작은 생각 입자를 남깁니다.
- **머무름**: 한 곳에 잠시 머무르면 빛의 뿌리가 자랍니다. 모바일에서도 가능합니다.
- **별 심기**: 빈 공간을 클릭/터치하거나 하단 **별 하나 심기**를 누르면 영구 별이 추가됩니다.
- **기억**: 최대 80개의 별과 재방문 횟수가 이 브라우저의 `localStorage`에 저장됩니다. 오른쪽 위 **기억**에서 PNG로 내보내거나 별과 방문 횟수를 초기화할 수 있습니다.
- **시**: **나의 시**를 누르면 방문 중 움직임·별·시간으로 만든 시를 읽고 다시 생성하거나 복사할 수 있습니다. 원본의 50초 후 공개 알림도 유지했습니다.
- **고요 모드**: 과도한 움직임이나 빛을 줄입니다. 기기의 `prefers-reduced-motion` 설정도 존중합니다.

이 작품에서 '관찰자 효과'는 *관계와 인식에 대한 예술적 은유*입니다. 양자역학 실험이나 실제 관찰자 효과를 시뮬레이션하지 않습니다. 시는 데이터로 엮은 창작물이지 심리 진단이 아닙니다.

## GitHub Pages 배포

1. ZIP을 압축 해제합니다.
2. `index.html`, `style.css`, `main.js`, `favicon.svg`, `README.md`, `QA_REPORT.md` 파일들을 저장소의 **루트**에 올립니다. (전체 폴더를 한 겹 더 넣지 마세요.)
3. 저장소 → **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save**.
4. `https://<GitHub 사용자명>.github.io/<저장소명>/` 주소로 접속합니다. 커스텀 DNS를 사용하는 경우 설정이 다를 수 있습니다.

빌드, npm 설치, 외부 API, CDN, Google Fonts, 계정, 개인정보 입력이 필요 없습니다. `index.html` 파일을 직접 열어도 동작하도록 제작했습니다.

## 저장 데이터 및 이관

원본 로컬 저장 키인 `breath_visits`와 `breath_stars`를 **그대로 사용**합니다. 따라서 같은 오리진(도메인·프로토콜·포트)에서 기존 사이트를 교체하면 이전 별과 방문 횟수를 가져옵니다. 다른 도메인으로 이동하면 브라우저의 저장소가 분리되므로 자동 이관되지 않습니다.

추가 저장 키는 `breath_last_visit_v2`, `breath_reduced_motion_v2`입니다. 망가진 JSON, 지원하지 않는 저장소, 오래된/잘못된 좌표에 대비한 검증·예외 처리가 들어 있습니다. 저장 데이터는 이 브라우저에서만 관리하며 네트워크로 전송하지 않습니다. 브라우저 데이터 삭제 또는 시크릿 모드 종료 시 기록이 사라질 수 있습니다.

## 개선 이력

- 모바일의 `touchstart` + 합성 `click` 중복 별 심기 방지: `pointerdown` 하나로 입력 통일
- 별 80개 초과 시 화면 표시와 실제 저장 배열의 불일치 해결
- 손상된 localStorage 값, 저장 권한 제한, 비정상 좌표 등 처리
- 마우스가 잠시 멈춘 순간에도 뿌리가 성장하도록 수정
- 배경 탭 렌더링 정지, FPS 제한, 고해상도 캔버스 상한, 입자/뿌리 개수 제한
- 화면 크기 변경 시 영구 별 좌표 유지, 시간대 팔레트 변경 반영
- 50초 고정 대기에 갇히지 않도록 시 즉시 열기 및 재생성 기능
- 키보드·모바일에서도 사용할 수 있는 버튼, 접근 가능한 대화창, 움직임 줄이기
- 전부 로컬 실행, 외부 폰트/라이브러리/추적 제거

자세한 검증 기록은 `QA_REPORT.md`를 참조하세요.
