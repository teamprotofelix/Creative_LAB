# 숨 · BREATH — 개선 및 검증 보고서

## 1. 원본 소스 검토

검토 대상: 사용자가 첨부한 `붙여넣은 텍스트(1)(20261114-104629).txt`의 `index.html` 및 `README.md`.

| 항목 | 원본의 위험 또는 한계 | 개선 방식 |
|---|---|---|
| 터치 중복 | `touchstart`에서 별을 저장하고 합성 `click`에서도 저장 → 모바일에서 별 두 개 가능 | `pointerdown` 단일 경로 + 독립적인 별 심기 버튼 |
| 별 개수 불일치 | 저장 배열만 80개로 자르고 렌더링 배열은 계속 증가 | 화면·저장소에서 동일한 최근 80개로 제한 |
| 로컬 저장 파손 | `JSON.parse` 및 `localStorage` 읽기/쓰기 예외 처리 미흡 | 데이터 검증, 좌표 정규화 검사, 예외 시 세션만 동작 |
| 뿌리 감지 | `mousemove`가 일어날 때만 새 뿌리 생성 → 완전히 멈추면 생성 불가 | 포인터 정지 중에도 실시간으로 뿌리 생성 (수량 제한) |
| 50초 대기 | 정해진 시간이 지나야 에필로그 등장 | 체험을 시작하자마자 시를 볼 수 있게 하고 50초 후 알림은 유지 |
| 메모리·성능 | 입자 수, 캔버스 렌더링, 숨은 탭 연산에 최적화 여지 | 개체 수 상한, DPR 및 FPS 상한, 비활성 탭 렌더링 정지 |
| 데스크톱 전용 UI | 포인터 중심으로만 조작 가능하며 키보드/모바일 접근성이 낮음 | 명시적 버튼, 접근 가능한 대화창, 모바일 대응, 움직임 제한 |
| 시간대 팔레트 | 접속 시에만 팔레트 선택 | 세션 동안 시간대 변경 시 팔레트 갱신 |
| 외부 의존성 | Google Fonts 의존 | 외부 폰트·라이브러리·데이터 전송 없는 로컬 구동 |
| 표현 정확성 | 관찰자 효과가 곧바로 양자역학 현상인 듯 오해 가능 | 관찰과 존재에 대한 예술적 은유임을 명시 |

## 2. 직접 실행한 검사

- `node --check main.js` : 통과
- Chromium Headless 브라우저에서 CSS·JavaScript를 HTML에 인라인 삽입해 기능 테스트(테스트 환경의 브라우저 정책 때문에 `file://` 직접 방문은 차단됨)
- 화면 너비 **320 / 390 / 400 / 1280 / 1440 / 1920px**: 가로 넘침 없음
- 데스크톱 별 심기 버튼: 1회 클릭당 1개 추가 확인
- 모바일 터치: 1회 터치당 1개 추가 확인 (중복 반응 없음)
- 시 모달: 표시·재생성·닫기 통과
- 기억 모달: 방문 횟수·별 개수 표시, 초기화 확인/취소/실행 통과
- 별자리 PNG 다운로드: 파일명 `breath-constellation.png` 생성 확인
- 고요 모드: 버튼으로 켜고 끄기 및 OS `prefers-reduced-motion` 우선 적용 확인
- 손상된 JSON 값: 오류 없이 빈 별 0개로 초기화 확인
- 기존 형식 `breath_visits` 값 6과 별 배열 91개: 7번째 방문, 최근 80개로 적재 확인
- 별 80개 추가 상한: 화면 80개·저장소 80개 일치
- 화면 크기 변경: 별의 정규화 좌표 불변 확인
- 위 브라우저 검증에서 JavaScript 실행 예외 발견되지 않음

## 3. 검증 범위의 한계

테스트용 Chromium에서 로컬 파일 및 임의 로컬 도메인에 직접 접근하려고 할 때 관리 정책에 의해 `ERR_BLOCKED_BY_ADMINISTRATOR`가 반환됐습니다. 따라서 기능 테스트는 **같은 HTML·CSS·JavaScript 내용을 한 문서로 합친 페이지**에서 진행했고, 저장소 테스트는 **API 호환 로컬 저장소 대역**을 사용했습니다. 이 방식으로 로직과 UI 동작을 검증했지만, 실제 `file://` 실행·네이티브 `localStorage`·GitHub Pages 운영 배포의 네트워크 환경까지 직접 검증한 것은 아닙니다. 배포 후 브라우저에서 실제 저장/재방문 기능을 추가 확인하는 것이 좋습니다.

이 프로젝트는 정적 파일만 사용하며 네트워크 API 요청·외부 폰트·인증 키를 포함하지 않습니다.
