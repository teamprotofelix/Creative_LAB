# THE THRESHOLD — 뚫는 자의 기록

스크롤에 따라 벽의 균열과 빛이 나타나는 인터랙티브 아트 웹사이트입니다. 외부 JavaScript 라이브러리, API 키, 빌드 도구, 서버가 필요하지 않습니다.

## 실행

1. 압축을 해제합니다.
2. 폴더의 `index.html`을 더블클릭해 실행할 수 있습니다.
3. 첫 화면에서 **여정 시작**을 클릭하거나 아래로 스크롤합니다.
4. **03 / 균열** 장면에서 **여기에 균열을 내다** 버튼을 누르면 반응합니다.
5. 화면 클릭 시 작은 균열과 입자가 발생합니다. `break`를 연달아 입력하면 숨겨진 효과가 작동합니다.
6. 우측 상단의 `♪ OFF` 버튼으로 배경음을 직접 켜거나 끕니다. 기본값은 무음입니다.

## GitHub Pages 배포

1. GitHub 저장소를 새로 만들거나 기존 저장소를 엽니다.
2. 이 ZIP 파일 안의 `index.html`, `style.css`, `main.js`, `favicon.svg`, `README.md`를 **저장소 최상위 경로**에 업로드합니다. ZIP 파일 자체를 올리지 마세요.
3. 저장소 **Settings → Pages**에서 **Deploy from a branch**를 선택한 후 `main` 브랜치의 `/ (root)`를 저장합니다.
4. Pages URL에서 사이트를 확인합니다. 저장소 이름이 무엇이든 상대 경로로 리소스를 읽습니다.

## 호환성·안전성

- HTML/CSS/JavaScript만 사용하며 빌드나 npm 설치가 필요 없습니다.
- WebGL 사용 불가·셰이더 컴파일 오류 시 Canvas 2D 또는 CSS 배경으로 강등됩니다. 페이지 흐름은 별도로 동작합니다.
- Web Audio가 없거나 사용자에게 차단돼도 스크롤과 그래픽은 계속 실행됩니다.
- 스마트폰 터치, 키보드 내비게이션, `prefers-reduced-motion`을 지원합니다.
- **외부 네트워크 요청이 전혀 없습니다.** 시스템 글꼴(바탕, Consolas 등)을 사용합니다. 외부 스크립트/API/추적/쿠키가 없습니다.
- 비밀키, 개인 정보 또는 서버 비밀번호가 포함되지 않습니다.

## 파일

- `index.html`: 6개 장면과 UI
- `style.css`: 연출과 반응형 레이아웃
- `main.js`: WebGL, 2D 폴백, 균열, 입자, 입력, 음향 제어
- `favicon.svg`: 자체 제작 아이콘

## 원본 대비 수정

- 원본: WebGL 미지원 시 `gl.createShader()` 등에서 오류 발생 → 전체 초기화 중단.
  수정: WebGL 생성·컴파일·링크 실패 감지 및 Canvas/CSS 폴백.
- 원본: 스크롤 패럴랙스가 `.scene.visible .content`의 `transform`을 덮어씀.
  수정: CSS 사용자 정의 속성 `--float-y`를 통해 등장 애니메이션과 공존.
- 원본: '벽의 균열' 콘셉트 설명만 있고 실제 균열 묘사가 없음.
  수정: 진행률에 따라 열리는 발광 균열, 클릭 균열, 별도 체험 버튼 추가.
- 원본: 사운드 버튼의 생성·재개 과정 예외 처리 없음.
  수정: 사용자 클릭 후에만 오디오 생성, 재개/중지 실패 시 시각 경험 유지.
- 원본: 고 DPI에서 자원 사용량 증가 가능, 초기 시계 업데이트 지연, 일부 접근성 미흡.
  수정: 렌더 픽셀 상한, 즉시 시간 갱신, 접근성 레이블·포커스·모션 감소 고려.
