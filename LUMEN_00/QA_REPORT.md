## 검증 방법 및 결과

- **정적 문법:** Node.js `node --check script.js` 통과.
- **Chromium 브라우저 기능 시험:** HTML·CSS·JS를 인라인으로 주입해 동일한 코드를 동작시켰습니다. 시험 브라우저 환경 정책상 로컬 `file://`과 임의의 시험용 HTTP(S) 주소 직접 탐색은 차단되어, 실제 GitHub Pages 배포 환경에서의 점검까지 수행한 것은 아닙니다.
- **화면 너비:** 1440×900, 390×844, 320×680 검사에서 문서 가로 넘침 없음.
- **상호작용:** 첫 씨앗 버튼, 캔버스 클릭·터치, 정원 수 증가, 기억 대화창 열기·닫기 통과.
- **다운로드:** JSON 내보내기, PNG 저장 시 브라우저 다운로드 이벤트 확인.
- **기억:** 재방문 복원, 방문 횟수 증가, 초기화 후 정원·방문 키 제거 통과.
- **이전 데이터:** `lumen_lives_v1` 픽셀 좌표 2건을 신규 정규화 좌표로 이전하는 시험 통과.
- **최대 수량:** 65회 심기 뒤 저장·표시 모두 최대 60개인 것 확인.
- **가져오기:** 유효한 v2 JSON을 가져왔을 때 저장·화면 반영 확인. 잘못된 레코드는 거부함.
- **오디오/모션:** 소리 켜기·끄기 및 고요 모드 토글 상태 확인.
- **JavaScript 예외:** 위 기능 검사의 Chromium `pageerror` 0건.

### 아직 확인이 필요한 사항

- 실제 GitHub Pages에서 호스팅 후 정적 리소스 로딩, 모바일 실기기별 터치/오디오 정책 차이.
- 수년간 저장된 예전 기록을 가진 브라우저와 화면 크기·해상도가 크게 다른 기기에서의 위치 유지.
- 화면 읽기 프로그램별 세부 탐색 경험 및 다양한 저사양 기기의 장시간 렌더링 성능.
