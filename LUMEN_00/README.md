# LUMEN — 빛의 기억 (개선판 v2.0)

> 빛은 사라지지 않습니다. 다른 모습으로 기억될 뿐.

## 사이트 소개

이 프로젝트는 클릭·터치로 빛의 씨앗을 심고, 그 씨앗이 자라 나무와 별로 남는 **인터랙티브 아트 정원**입니다. ‘관찰자 효과’는 과학적 실험이나 심리 진단이 아닌 **예술적 은유**로 사용합니다.

### 체험하기

- 화면의 빈 곳을 **클릭/터치**하면 빛을 심습니다. `첫 번째 빛 심기` 또는 하단 `빛 심기` 버튼도 사용할 수 있습니다.
- 갓 심은 씨앗은 수초 동안 자라 빛의 나무가 되고, 약 23~40초 후 나무의 밝기가 서서히 줄면서 별빛이 강해집니다.
- 최근 빛들 사이에는 은은한 별자리 선이 나타납니다.
- 시간대에 따라 배경의 은은한 색과 씨앗의 색조가 달라집니다.
- 상단 `기억의 서랍`에서 **JSON 내보내기/가져오기**, 재방문 횟수 확인, 저장 삭제를 할 수 있습니다.
- 하단 `장면 저장`에서 정원 장면만 PNG로 내려받습니다. 화면 위의 버튼이나 텍스트는 포함되지 않습니다.
- `소리 꺼짐` 버튼을 직접 눌러야 앰비언트 사운드가 켜집니다. 자동 재생하지 않습니다.
- 시스템의 움직임 줄이기 설정을 존중하며 상단 `고요 모드`를 수동으로 전환할 수 있습니다.

### 키보드 단축키

- `Space`: 화면 중심 아래쪽에 씨앗 심기 (입력 컨트롤에 포커스가 없을 때)
- `M`: 기억의 서랍 열기
- `Esc`: 기억의 서랍 닫기
- `Tab`, `Enter`, `Space`: 일반 버튼의 키보드 탐색·조작

## GitHub Pages 배포 (빌드 불필요)

ZIP을 압축 해제하면 **루트에 다음 파일 6개**가 있습니다.

```
index.html
style.css
script.js
favicon.svg
README.md
QA_REPORT.md
```

1. 압축을 풀고 위 6개 파일을 **저장소의 최상위(root)**에 업로드합니다. `index.html`은 반드시 최상위에 있어야 합니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. **Build and deployment → Source: Deploy from a branch**, **Branch: main / (root)**를 선택한 후 저장합니다.
4. GitHub Pages가 안내하는 사이트 주소를 엽니다. 사이트 주소가 바뀌면 기존 로컬 기억은 자동 이전되지 않습니다.

빌드 도구, Node.js, 외부 폰트·CDN, 외부 API 또는 API 키가 필요하지 않습니다. `index.html`을 직접 열어 시각 효과를 볼 수도 있지만, `file://` 환경에서의 로컬 저장 동작은 브라우저별로 다를 수 있으므로 배포 주소에서 확인하는 것을 권장합니다.

## 저장과 개인정보

- 정원은 **브라우저의 `localStorage`**에만 저장됩니다. 서버로 보내지 않으며 개인 식별 정보를 요구하지 않습니다.
- 저장 키: `lumen_garden_v2`, `lumen_visits_v2`, `lumen_reduced_motion_v2`.
- 기존 버전의 저장 키 `lumen_lives_v1`이 있고 신규 데이터가 없다면 처음 로드할 때 자동으로 옮깁니다. **기존 기록의 좌표가 픽셀 단위여서 기존/신규 화면 크기가 크게 달라진 경우 위치에 다소 차이가 날 수 있습니다.** 이전/새 사이트가 *동일한 origin*에 있어야 기록이 이어집니다.
- **최대 60개**의 빛을 보존합니다. 61번째 빛부터는 가장 오래된 빛을 하나씩 교체합니다.
- 기기 이동이나 브라우저 데이터 삭제에 대비해 `기억의 서랍 → 기억 내보내기 · JSON`을 이용하세요.
- `기억 가져오기 · JSON`은 현재 정원 내용을 대체하므로 확인창을 보여줍니다. 형식·데이터를 검사한 뒤 최대 60개만 불러옵니다.
- `모든 기억 지우기`는 이 작품에서 사용하는 정원·옛 정원·방문 횟수 기록을 지웁니다. 고요 모드 설정은 유지됩니다.
- 시크릿 창, 저장 공간 부족, 사이트 설정에 따라 저장이 차단될 수 있습니다. 이때는 현재 세션에만 정원이 남습니다.

## 유지관리 메모

- 성능: 입자 최대 340개, 정원 최대 60개, 동적 렌더링 최대 약 36fps. 탭이 숨겨지면 그래픽 루프와 오디오를 일시 중지합니다.
- 배경·나무는 **Canvas 2D**를 이용하며 나무 형태는 씨앗마다 미리 캔버스에 그려 재사용합니다.
- 모든 코드는 정적 파일이며 네트워크 호출을 사용하지 않습니다.
- 모바일 터치는 단일 `pointerdown`으로 처리해 원본의 터치/클릭 이중 처리를 방지했습니다.

문제 수정과 검증 범위는 `QA_REPORT.md`를 참고하세요.
