# 미감(未感) / UNFELT — 감정의 바깥 (수정판 v1.1)

**압축 해제 후 `index.html`을 더블클릭하세요.** 별도 설치, 로컬 서버, Python, npm이 필요 없습니다.

## 수정 사항

- 기존 `type="module"` 방식의 JavaScript 로딩을 제거했습니다. 기존 ZIP은 `file://`에서 모듈 실행이 차단되어 첫 화면만 나타나고 버튼이 동작하지 않을 수 있었습니다.
- HTML, CSS, JavaScript, SVG favicon을 `index.html` 하나에 통합했습니다. 파일이 누락되거나 경로가 달라져도 문제가 생기지 않습니다.
- WebGL 셰이더 초기화가 실패해도 Canvas 2D 대체 렌더링으로 이어지게 보완했습니다.
- 포스터 이미지도 실제로 렌더링 중인 캔버스를 사용합니다.

## 시작 방법

1. ZIP을 압축 해제합니다.
2. `index.html`을 Chrome, Edge, Firefox 등 브라우저에서 엽니다.
3. 첫 화면의 **이름 없는 세계에 들어가기**를 눌러 체험을 시작합니다.
4. 거리 → 무게 → 흔적 → 시간 → 감정 탄생 순으로 진행합니다.
5. 마지막의 PNG 저장 버튼을 눌러 작품을 간직합니다.

## GitHub Pages 배포

1. GitHub 저장소 최상위 경로에 `index.html`을 업로드합니다. (선택적으로 `.nojekyll`, `README.md`도 추가)
2. **Settings → Pages → Build and deployment → Deploy from a branch**.
3. **main / (root)**를 선택하고 저장합니다.
4. `https://<사용자명>.github.io/<저장소명>/`에서 열어 보세요.

## 작품 구성

- 거리: 슬라이더 조작
- 무게: 버튼 길게 누르기 / 스페이스바
- 흔적: 배경 드래그 또는 '작은 별 하나 남기기'
- 시간: 과거/미래 선택
- 탄생: 고유 감정 이름과 정의 생성, PNG 다운로드
- 소리: 상단 SOUND OFF 버튼에서 켜고 끄기

## 기술 및 개인정보

- 로컬에서 모든 코드를 실행합니다. 외부 API, CDN, 계정, 트래커가 필요 없습니다.
- 최근 결과는 사용자의 브라우저 `localStorage`에만 저장됩니다. 파일 실행 모드에서는 브라우저 보안 정책에 따라 저장이 제한될 수 있으며, 이 경우에도 체험 자체는 계속 가능합니다.
- 현대 브라우저에서 WebGL이 제한되면 2D 캔버스로 대체됩니다.
- `index.html` 하나만으로 실행되므로 파일 경로 및 서버 설정에 덜 민감합니다.
