# ◈ MIRROR · 거울 — 개선판

> 당신이 '당신'이라고 부르는 것. 읽는 동안 읽히는 경험.

7개의 철학적 경험을 담은 **완전 정적 HTML/CSS/JavaScript 사이트**입니다. React, npm, 빌드, API 키, 서버, 회원가입 없이 실행됩니다. 외부 CDN, 외부 폰트, 추적 스크립트에 의존하지 않습니다.

## 바로 실행하기

1. ZIP을 압축 해제합니다.
2. **최상위 `index.html`**을 Chrome/Edge/Safari/Firefox로 엽니다.
3. 화면을 스크롤해 7개 장을 체험합니다. 사운드는 직접 켜야 재생됩니다.

### GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
2. ZIP 내부 파일 전체(`index.html`, `styles.css`, `app.js`, `favicon.svg`, `README.md`)를 저장소 **루트**에 올립니다. ZIP 파일 자체를 올리지 않습니다.
3. GitHub 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → main / (root) → Save**를 선택합니다.
4. 게시 완료 후 `https://<사용자명>.github.io/<저장소명>/`으로 접속합니다. 기존 저장소의 폴더에도 복사할 수 있으며, 상대 경로를 사용합니다.

## 체험 안내

| 장 | 기능 | 작동 방식 |
| --- | --- | --- |
| 01 소비 | 단어 지우기 | PC에서 커서 올리기 / 모바일에서 단어 탭 / 키보드 Tab + Enter. 사라진 단어는 로컬에 남고 **흔적 초기화**로 복구 가능합니다. |
| 02 시간 | 시간과 정지 | 이 페이지 경과 시간, 80년의 가상 비유. 버튼을 누르고 5초간 정지. 큰 움직임에 다시 시작합니다. |
| 03 주의 | 기다림 | 영역에 진입하면 4.7초간 가짜 로딩. 다른 장을 보면 일시정지하고 돌아오면 계속됩니다. 네트워크 요청은 일어나지 않습니다. |
| 04 자아 | 다섯 질문 | 버튼을 5번 눌러 질문을 읽습니다. 리벳 실험은 논쟁적 해석으로 소개합니다. |
| 05 침묵 | 15초 침묵 | 장이 화면에 보이고 스크롤이 멈춘 상태에서 15초. 떠나거나 스크롤하면 초기화됩니다. |
| 06 거울 | 세션 초상화 | 경과 시간·스크롤 거리·커서 거리·클릭·멈춤·탭 이탈을 갱신합니다. 이미지 PNG 저장 또는 텍스트 복사 가능. |
| 07 끝 | 마무리 | 닫을 수 없는 브라우저 탭을 닫는 척하지 않습니다. 종료 장면에서 다시 돌아올 수 있습니다. |

우측의 작은 점으로 장을 바로 이동할 수 있습니다. 상단 진행 막대는 페이지를 기준으로 측정합니다. 마우스/터치/키보드 이용을 지원합니다. 운영체제의 **동작 줄이기(prefers-reduced-motion)** 설정을 존중합니다.

## 저장 데이터·개인정보

- 사이트 자체에는 네트워크 요청, 분석 도구, 계정, 쿠키, 방문자 식별자, 외부 전송 기능이 없습니다. 단, GitHub Pages 등 호스팅 제공자가 기본적인 접속 로그를 처리할 수 있습니다.
- **단어 소비 기록**은 현재 브라우저의 `localStorage` 키 `mirror-consumed-v2`에 **단어 인덱스 배열**로 저장됩니다. 과거 버전의 `mirror-consumed` 기록도 읽어올 수 있습니다.
- **초상화 데이터**(시간, 거리, 클릭, 멈춤, 이탈 횟수)는 현재 열린 탭의 JavaScript 메모리에서만 계산합니다. 초상화 저장/복사 버튼을 직접 눌렀을 때에만 사용자 기기에 출력됩니다.
- 단어 소비 기록 삭제는 **01장 → 흔적 초기화 → 확인**. 브라우저의 사이트 데이터 삭제로도 제거할 수 있습니다.
- 브라우저의 시크릿 모드나 로컬 저장소 차단 환경에서는 단어의 새로고침 후 유지가 제한될 수 있습니다.
- **80년의 남은 초**는 개인 수명을 추정하지 않습니다. 80 × 365.25일에서 이 세션의 경과 시간을 뺀 가상의 장치입니다.
- 리벳 실험과 자유의지에 대한 문장은 결론이 아니라 질문입니다. 준비 전위와 의식적 의도 보고 시점의 관찰이 모든 종류의 자유의지를 부정한다는 결론에는 논쟁이 있습니다.

## 원본에서 개선한 점

- `display:none`인 로딩 영역에 `IntersectionObserver`를 설치해 실험이 시작되지 않던 결함 수정: **챕터를 관찰**합니다.
- 침묵 화면 타이머를 **실제 화면 노출과 스크롤 멈춤**에 연동하고 이탈 시 리셋합니다.
- 모바일 탭·키보드로 단어가 사라지며, 영구적 흔적을 초기화할 수 있습니다.
- 단어가 사라지는 기능이 `localStorage`에 기록된다는 사실을 UI에 명시해 원본의 잘못된 '아무것도 저장하지 않음' 문구를 수정했습니다.
- 실시간 초상화 재계산, PNG 저장, 기록 복사, 접근 가능한 버튼과 상태 표시를 제공합니다.
- 부정확한 수명 숫자와 자유의지 단정 표현을 정정했습니다.
- 브라우저가 임의로 `window.close()`할 수 없는 제약에 맞게, 닫기 대신 **완결 장면**으로 변경했습니다.
- Web Audio는 버튼 클릭 후에만 시작하며, 창이 숨겨지면 조용히 만들고, 커서는 세밀 포인터 장치에서만 표시합니다.
- 캔버스 배경은 DPR과 FPS를 제한하고, 탭이 비활성일 때 애니메이션을 그리지 않습니다.

## 파일 구조

```text
index.html   페이지·텍스트·접근성 태그
styles.css   타이포그래피·레이아웃·반응형·저동작 모드
app.js       실험·캔버스·오디오·기록 처리
favicon.svg  로고
README.md    배포·사용·개인정보 설명
```

**주의:** 단순 정적 페이지이므로 실제 이용자의 기억이나 뇌 신호를 측정하지 않습니다. 이 사이트가 사용자를 '읽는다'는 표현은 스크롤과 클릭을 반영한 철학적 은유입니다.
