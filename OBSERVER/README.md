# OBSERVER — 관찰자

> 당신이 이 페이지를 보는 순간, 이 페이지도 당신을 봅니다.

정적 HTML/CSS/JavaScript만으로 작동하는 인터랙티브 명상 웹사이트입니다. 별이 탄생하고, 포인터의 움직임이 입자를 밀어내며, 짧은 사유와 이번 방문만의 서명을 만듭니다. 화면의 우주는 **시각적 은유**이며, 의식이나 양자 관측에 관한 과학적 증명을 뜻하지 않습니다.

## 바로 실행하기

`index.html`을 더블클릭하면 기본 경험을 바로 실행할 수 있습니다. `file://`에서 클립보드 권한을 거부하는 브라우저에서는 복사 기능에 제한이 있을 수 있습니다. 이미지 저장은 브라우저 내부에서 수행합니다.

## GitHub Pages에 올리기

1. 이 ZIP 압축을 풉니다.
2. **압축을 푼 폴더 안의 파일 전체** (`index.html`, `styles.css`, `main.js`, `favicon.svg`, `.nojekyll`, `README.md`)를 GitHub 저장소의 **배포 루트**에 업로드합니다. (폴더째 업로드하지 마세요.)
3. GitHub 저장소 → **Settings → Pages → Build and deployment** 에서 **Deploy from a branch**를 선택합니다.
4. Branch를 `main`, 폴더를 `/(root)`로 선택해 저장합니다.
5. 배포된 GitHub Pages 주소로 접속합니다. 루트/하위 경로 모두 상대 경로로 작동합니다.

어떤 CDN, 패키지 매니저, 빌드 도구, API, 서버 또는 로그인도 필요하지 않습니다.

## 이용 방법

- **0~2.5초**: 검은 공간의 한 점
- **2.5초**: 빅뱅 연출, 입자 우주 시작
- **4.5초**: 관찰자 제목
- **9.5초 이후**: 8.5초 간격으로 바뀌는 생각
- **첫 별 생성 후 약 3.5초** 또는 **22초**: 방문의 우주 서명이 약 6.8초간 나타납니다.
- **15번 별 생성** 또는 **60초 경과**: 최종 장면 (별을 만들지 않아도 자동으로 등장)
- 데스크톱에서 빈 화면 클릭, 모바일에서 터치, 또는 `Space`/`Enter`: 별 만들기
- **시작 장면 건너뛰기**: 도입부 없이 즉시 시작
- **MOTION**: 입자·장식의 움직임 줄이기. OS의 '동작 줄이기' 설정도 자동 적용
- **SOUND**: 사용자가 명시적으로 누를 때만 합성 앰비언트 소리 재생. 기본 무음
- 결말의 **다시 태어나기**: 새 경험 처음부터 시작
- 결말의 **이 순간을 그림으로 저장**: 서버 없이 1600×900 PNG 생성
- 결말의 **서명 복사**: 표시된 텍스트를 클립보드로 복사

## 원본에서 발견하여 개선한 점

| 구분 | 변경 사항 |
|---|---|
| 결말 진입 | 원본은 65초에 클릭 3회 이상이라는 조건이 있어 미조작 방문자에게 결말이 오지 않았습니다. 60초 무조건 진입으로 변경 |
| 연출 순서 | 첫 클릭 서명과 제목·사유 전환이 충돌하는 문제를 공통 스케줄러로 정리 |
| 성능 | 입자 전체 쌍 검사 O(n²)를 주변 9셀 공간 분할 탐색으로 교체, 입자·연결선 수 제한, 화면 크기에 따른 렌더링 프레임 조절 |
| 배경 탭 | 다른 탭에 있을 때 시뮬레이션 및 진행 시간 일시 정지, 오디오 일시 정지 |
| 모바일 | Pointer Events 통합, 터치 별 생성, 작은 화면의 글자·레이아웃·최종 장면 스크롤 지원 |
| 접근성 | 소리·움직임 제어를 접근 가능한 `<button>`으로 구현, 키보드 별 생성, 포커스 표시, ARIA 상태, OS 동작 줄이기 대응 |
| 기록 단위 | 원본의 마우스 픽셀/100을 'm'로 표현한 오류를 실제 픽셀 거리로 수정 |
| 과학 표현 | 가짜 소수점 정밀도 대신 '우주 나이 약 138억 년'이라는 추정치 표현을 사용 |
| 알림·서명 | 전 세계적으로 유일하다는 보증을 삭제하고 '이번 방문만의 서명'으로 명확히 기술 |
| 기능 | 서명 복사, PNG 카드 저장, 재시작, 도입부 건너뛰기, 저자극 모드 추가 |

## 개인정보/외부 연결

브라우저에서 발생한 마우스 움직임, 터치, 클릭 횟수는 **이 방문의 그래픽에만 사용**됩니다. 서버 전송, 외부 API 요청, 쿠키, 분석 도구, localStorage 기록이 없습니다. 재시작하거나 탭을 닫으면 방문 상태가 사라집니다.

## 파일 구성

```
index.html   # 접근성 및 화면 구조
styles.css   # 화면 연출과 반응형 스타일
main.js      # 스케줄·입자 엔진·사운드·PNG 저장
favicon.svg  # 로컬 아이콘
.nojekyll    # GitHub Pages에서 정적 파일을 있는 그대로 제공
README.md    # 설치·사용 안내
```

## 참고

이 웹사이트는 소리, 사진, 폰트, 모델 등을 외부에서 불러오지 않습니다. 일부 구형 브라우저에서 Web Audio API가 지원되지 않으면 시각 경험은 계속 작동하고 소리만 사용하지 못합니다. 정적 호스팅의 MIME 설정에 따라 `.svg` 파비콘 호환성이 달라질 수 있지만 기본 콘텐츠는 영향을 받지 않습니다.
