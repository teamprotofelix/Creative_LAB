# 당신이라는 우주 · A Universe Called You

**움직임이 별이 되고, 다시 찾아와도 같은 자리에 남는 인터랙티브 우주**입니다.

HTML·CSS·JavaScript만 사용하는 정적 웹사이트입니다. 별도 서버, npm, 외부 라이브러리, API 키, 계정 등록이 필요하지 않습니다.

## 실행

1. ZIP을 풀고 `index.html`을 더블클릭해 열면 됩니다. 최신 Chrome·Edge·Firefox 등을 권장합니다.
2. GitHub Pages 배포 시 압축 파일 자체를 올리지 말고, **압축 내부의 파일 4개**를 저장소 최상위(root)에 올리세요.
3. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`** 선택 후 저장합니다.
4. 배포되면 `https://<사용자명>.github.io/<저장소명>/` 형태로 접속합니다.

## 사용법

- **마우스 이동 / 화면 터치**: 별을 생성합니다. 가까운 시간에 생성된 별은 서로 연결됩니다.
- **스크롤**: 우주를 따라 이동하며 각 장면의 시를 읽습니다.
- **우측 하단 ♪ OFF / ON**: 앰비언트 사운드를 켜거나 끕니다. 소리는 처음부터 자동 재생되지 않습니다.
- **마지막 장면**: 별 추가, 기억 백업, 기억 가져오기, 기억 지우기를 사용할 수 있습니다.
- **기억 백업**: `aurora-constellation.json`을 다운로드합니다.
- **기억 가져오기**: 이 사이트의 JSON 백업을 읽어 기존 기억을 교체합니다. 가져오기 전에 확인 창이 표시됩니다.
- **기억 지우기**: 해당 브라우저의 별과 방문 횟수를 초기화합니다. 복원이 필요하면 먼저 백업하세요.

## 저장 및 개인정보

별의 화면상 상대 위치, 생성 시각, 크기, 방문 횟수가 브라우저의 `localStorage`에 저장됩니다. **서버로 전송되거나 다른 사용자에게 공유되지 않습니다.** 저장소가 차단된 환경에서도 페이지는 작동하지만, 방문 간 기록 보존은 되지 않을 수 있습니다. 다른 기기에서도 기록을 유지하려면 JSON 백업을 직접 옮기세요.

**중요:** 백업 JSON에는 별의 상대 좌표와 생성 시각이 들어 있습니다. 타인에게 파일을 보낼 때는 이를 고려하세요. 클라우드 동기화 기능은 포함하지 않습니다.

저장 키는 원본과 호환되는 `aurora-you-v1`입니다. 원본에서 저장한 별 기록을 읽을 수 있도록 구성했습니다. 저장 목록의 상한은 **1,200개**이며, 손상되거나 범위를 벗어난 데이터는 무시합니다.

## 변경 사항

- 이전 버전에서 **12초 후 사라지던 별자리 연결선을 보존**합니다.
- 유효하지 않은 `localStorage` 데이터, 저장소 권한 거부 등을 안전하게 처리합니다.
- 저장 작업을 일정 시간 모아 실행해 매 이동 시 전체 JSON을 다시 쓰지 않도록 했습니다.
- 별빛을 이미지 스프라이트로 캐싱하고 렌더링 해상도·주기를 제한해 브라우저 부하를 낮췄습니다.
- WebGL 실행 불가 또는 셰이더 실패 시 CSS 성운으로 대체합니다. WebGL 문맥 손실에도 대체 배경을 제공합니다.
- 시간에 따른 팔레트를 주기적으로 갱신하고, 별 개수·방문 횟수 표시를 갱신합니다.
- 모바일 포인터 이벤트, 키보드 접근 가능한 오디오 버튼, 동작 감소 설정을 지원합니다.
- JSON 내보내기/가져오기, 별 하나 남기기 버튼을 추가했습니다.
- 초기 로더가 계속 화면을 가리지 않도록 안전한 종료 효과를 적용했습니다.

## 파일 구성

- `index.html`: 화면 구성과 버튼
- `style.css`: 스타일·레이아웃·WebGL 대체 성운
- `app.js`: WebGL 셰이더·별자리·로컬 저장·오디오·동작
- `README.md`: 이 문서

## 검증 범위

Chromium에서 실제 HTML·CSS·JavaScript 코드를 주입하여 화면과 이벤트, 저장·복원(모의 저장소), JSON 백업·복원, 모바일, WebGL 미지원 대체 경로, 동작 감소 설정을 점검했습니다. JavaScript 실행 오류는 관측되지 않았습니다. 시험 환경이 로컬 HTTP/파일 URL 접근을 차단하고 WebGL을 제공하지 않아 **실제 GitHub Pages 배포 및 WebGL 셰이더 렌더링은 검증하지 못했습니다.**
