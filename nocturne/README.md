# NOCTURNE — 별의 정원 (검토·수정본)

순수 HTML/CSS/JavaScript로 동작하는 개인용 별꽃 정원입니다. 서버·API 키·빌드 과정이 필요하지 않습니다.

## 시작 및 GitHub Pages 배포

1. ZIP을 풀고 **그 안에 있는** `index.html`, `style.css`, `world.js`, `flower.js`, `audio.js`, `favicon.svg`를 GitHub 저장소의 최상위 디렉터리에 업로드합니다.
2. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**를 선택합니다.
3. Pages에서 게시된 URL로 접속합니다. `index.html`을 로컬에서 더블클릭해도 작동하도록 모듈·네트워크 의존성을 제거했습니다. 모든 리소스는 ZIP 내부에 있어 인터넷이 없어도 작동합니다.

## 사용법

- 빈 공간 누르기/클릭: 별꽃 심기. 처음에는 '첫 번째 별꽃 심기' 버튼도 사용할 수 있습니다.
- 꽃 머리 누르기/클릭: 해당 꽃의 시 보기. PC에서는 마우스 오버로도 볼 수 있습니다.
- `♫`: 브라우저 오디오 켜기/끄기 (기본값 꺼짐, 사용자의 클릭 필요).
- `↶`: 마지막 별꽃 되돌리기. `Ctrl+Z` / `Cmd+Z`도 지원.
- `⇩`: 정원 파일(`nocturne-garden-YYYY-MM-DD.json`) 다운로드.
- `⇧`: 저장된 JSON 파일 가져오기. **기존 정원이 교체됩니다.**
- `✕`: 정원 비우기 (확인 대화상자 표시).
- 30초 동안 움직임이 없으면 유성이 지나가고, 음악을 켜 둔 경우 조용한 멜로디가 납니다.

## 검토하면서 수정한 문제

1. `flower.js`의 `draw()`가 난수 생성기를 매 프레임 호출해 **잎·꽃잎 각도가 계속 바뀌고 저장 후 재현성도 무너지는 문제**를 수정했습니다. 생성 단계에서 모양을 확정하고 꽃 머리를 이미지로 캐싱합니다.
2. 기존 저장 데이터는 픽셀 좌표여서 화면을 회전하거나 PC↔모바일로 옮기면 꽃 위치가 어긋났습니다. 이제 0~1 상대 좌표로 저장하고 `v1` 로컬 저장 데이터를 읽어 `v2`로 마이그레이션합니다.
3. `touchstart`와 `click`을 각각 처리하는 구조가 터치 기기에서 중복 심기를 유발할 수 있었습니다. `pointerdown` / `pointerup` 하나로 통일하고 드래그를 제외했습니다.
4. 원래는 **꽃에 클릭해도 새 꽃이 심어졌고**, 모바일에서는 호버가 없어 시를 볼 수 없었습니다. 클릭으로 시를 열고 새 꽃을 만들지 않게 수정했습니다.
5. 음소거 상태에서 Web Audio 초기화 오류와 재개 실패가 앱을 불안정하게 하지 않도록 방어 코드를 추가했습니다. 소리는 기본 꺼짐이며 정원 렌더링과 독립적입니다.
6. 저장 내용의 수량·숫자 유효성 검사, 120송이 한도, 백업·복원, 되돌리기, 정원 초기화 확인을 추가했습니다.
7. 시간(초) 기반 애니메이션과 고해상도 캔버스 제한, 꽃 머리 이미지 캐싱, 탭 숨김 처리, 모션 감소 환경 지원을 적용했습니다.

## 파일 구성

- `index.html`: 레이아웃 및 버튼/대화상자
- `style.css`: 반응형 스타일
- `audio.js`: 선택형 Web Audio 신시사이저
- `flower.js`: 씨앗 기반 꽃 모양·시·렌더링
- `world.js`: 캔버스 우주·상호작용·저장 및 UI
- `favicon.svg`: 자체 제작 심볼

## 데이터/프라이버시

꽃은 브라우저의 `localStorage` (`nocturne.garden.v2`)에만 저장됩니다. 인터넷으로 업로드하지 않습니다. 다른 브라우저와 자동 동기화되지 않으므로 `⇩` 버튼으로 백업하세요. 시크릿 모드나 저장이 제한된 환경에서는 자동 저장이 안 될 수 있습니다.

## 기존 버전 호환성

`nocturne.garden.v1` 배열(`x`, `y`, `seed`)을 읽을 수 있습니다. 과거 자료는 당시 픽셀 좌표만 보관했으므로 **예전에 사용한 화면 크기 정보를 알 수 없어** 다른 해상도에서 첫 변환 위치까지 완벽하게 복원하는 것은 불가능합니다. 같은 크기의 창에서 첫 실행 후 `⇩`로 백업하는 것을 권장합니다.

## 점검

JavaScript 구문 검사를 한 뒤 Chromium 브라우저에서 로컬 서버로 주요 사용자 흐름을 테스트하세요. 브라우저 개발자 도구에서 `window.NOCTURNE_STATUS`로 꽃 수/캔버스/오디오 상태를 확인할 수 있습니다.
