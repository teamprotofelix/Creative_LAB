# 인지의 거울 — MIRROR OF COGNITION

움직임 · 흔적 · 호흡 · 시간 · 질문 · 기억 · 소멸 · 귀환. 웹 브라우저만으로 체험하는 여덟 장면의 인터랙티브 작품입니다.

## 설치와 GitHub Pages 배포

ZIP을 풀어 나온 **파일 4개**(`index.html`, `style.css`, `app.js`, `favicon.svg`)와 이 `README.md`를 GitHub 저장소의 배포 루트에 업로드합니다. 이 ZIP은 이미 배포 루트를 기준으로 구성되어 있습니다.

1. GitHub 저장소의 최상위 폴더에 다섯 파일을 올립니다. (서브폴더에 배포하려면 그 폴더를 Pages 설정의 배포 위치로 선택하세요.)
2. GitHub 저장소 → **Settings → Pages**로 이동합니다.
3. **Build and deployment → Source: Deploy from a branch**를 선택합니다.
4. Branch: **main**, Folder: **/(root)** → **Save**를 누릅니다.
5. Pages에 표시된 URL을 엽니다.

`index.html`을 더블 클릭해 로컬에서도 실행할 수 있습니다. 다만 일부 브라우저의 `file://` 보안 정책 또는 사생활 보호 모드에서는 localStorage 저장이 제한될 수 있습니다. 그런 경우 사이트는 실행되지만 기록이 다음 방문까지 남지 않을 수 있습니다. 완전한 환경에서 확인하려면 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000`으로 접속하세요.

빌드 도구, npm, 별도 API, 서버, 외부 글꼴, 추적 스크립트가 필요하지 않습니다. 인터넷에 연결하지 않아도 작동합니다.

## 체험 내용

| 장면 | 경험 |
|---|---|
| 01 관찰 | 관찰자의 움직임에 반응하는 빛과 궤도, 버튼으로 시작 |
| 02 흔적 | 마우스·터치·펜 궤적으로 매번 달라지는 기하학적 문양을 만들고 보관 |
| 03 호흡 | 사용자가 직접 켜고 멈추는 4초 들숨·6초 날숨 가이드 |
| 04 시간 | 경과 시간과 상호작용을 반영한 **가상** 시간을 비교 |
| 05 질문 | 두려움·시간·마음에 관한 세 질문과 답을 엮은 시 |
| 06 기억 | 시·문양·재방문 횟수 확인, TXT 저장, 기록 삭제 |
| 07 소멸 | 빛을 옅게 만들거나 복원하는 인터랙션 |
| 08 귀환 | 한 점의 빛, 같은 세션에서 다시 시작 |

모든 장면은 화면 하단의 **이전 장면 / 다음 장면** 및 데스크톱 좌측의 장면 목차로 직접 이동할 수 있습니다. 마우스 움직임이나 긴 자동 대기 없이도 전체를 볼 수 있습니다.

## 개선한 주요 문제

- 마우스 움직임 거리(400·2500px 등)에 **강제 의존**하던 진행 방식 제거: 모바일·키보드 사용자도 모든 장면에 접근 가능
- `touchstart`와 합성 `click`의 **중복 집계** 제거: 단일 Pointer Events 계열 사용
- 첫 화면에서 **5초 이상 기다려야 조작할 수 있는 구조** 제거: 즉시 시작 가능
- 강제 재생되는 **저음 오디오** 제거: 기본 OFF, 별도 버튼으로만 재생 가능, 다른 탭으로 가면 일시 정지
- 원본의 `maximum-scale=1`·`user-scalable=no` 제거: 모바일 확대 허용
- 반복 접속·리로드에서의 저장 오류 최소화: localStorage 접근 예외 처리 및 기록 삭제 제공
- 텍스트의 실제 의미를 과장하지 않도록 **심리·인지 진단이 아닌 예술적 문양과 시간 은유**임을 표시
- 강제 연출 대기 시간 제거, 호흡 시작·중지와 소멸 복구·이전 장면 기능 추가
- 탭 비활성화 때 애니메이션 중지, 고해상도 DPR 제한, 별·흔적·파문 수 제한
- `prefers-reduced-motion` 반영 및 수동 움직임 OFF 제공
- 버튼에 명시적 유형·키보드 포커스 스타일·상태 표시 등을 추가
- 모든 파일 상대 경로 사용: GitHub Pages 저장소 서브패스 호환

## 개인정보·저장 정책

- 사용자 움직임의 누적 거리와 터치 횟수는 **현재 페이지 메모리**에서만 계산합니다. 서버 전송이 없습니다.
- 방문 횟수, 마지막 방문, 저장한 문양 코드, 질문 선택·시만 **현재 브라우저의 localStorage**에 기록합니다. 원본 단일 HTML 버전의 `moc_visits`, `moc_last_visit`, `moc_symbol` 기록이 있으면 처음 실행할 때 해당 정보를 새 기록으로 가져옵니다.
- **나의 기록 저장**은 사용자의 기기로 TXT를 다운로드합니다. **기억 지우기**는 확인 후 해당 브라우저에 저장된 이 작품의 새 기록과 이전 버전의 기록까지 삭제합니다.
- 브라우저에서 저장소가 차단되면 방문 간 기억은 지속되지 않습니다.
- 문양은 이동 좌표와 난수로 만든 **창작 기호**입니다. 방문자의 실제 정체성·성격·인지 능력을 식별하거나 진단하지 않습니다.
- 가상 시간은 움직임이 있으면 더 빠르게, 고요하면 더 느리게 흐르도록 설정한 **수학적 은유**입니다. 실제 심리학적 시간 지각을 측정하지 않습니다.
- 호흡 가이드는 휴식용 인터랙션이며 의학적 조언이 아닙니다. 원하지 않으면 사용하지 않아도 됩니다.

## 기술

HTML5 · CSS3 · Vanilla JavaScript · Canvas 2D · Pointer Events · Web Audio API(선택) · localStorage

모든 기능은 정적 파일만으로 동작합니다. 별도의 자격 증명, 추적 쿠키, 분석기, 원격 API는 포함되지 않습니다.
