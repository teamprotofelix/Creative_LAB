# 당신이라는 현상 · A Phenomenon Called You

> 바라보는 자와 바라보이는 자 사이에서, 여덟 개의 장을 통과하는 조용한 우주 체험.

## 빠른 시작

1. ZIP을 압축 해제합니다.
2. `index.html`을 Chrome 또는 Edge에서 열면 됩니다. 별도 빌드·설치·서버가 필요 없습니다.
3. GitHub Pages에 게시하려면 ZIP의 **파일들을 그대로 저장소 루트**에 업로드합니다. 폴더째 한 단계 더 중첩하지 마세요.
4. GitHub 저장소의 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** 를 선택하고 저장합니다.
5. 커스텀 도메인은 GitHub Pages의 Custom domain에서 설정하고, DNS도 그에 맞춰 연결합니다.

## 여덟 개 장

| 장 | 원본의 주제 | 개선된 상호작용 |
|---|---|---|
| 01 어둠 | 누가 보고 있는가 | 밝고 선명한 인트로, 다음 장 안내 |
| 02 첫 빛 | 움직임이 별을 만든다 | 마우스·터치·키보드 빛 생성, 개수 표시 |
| 03 시간 | 머무는 시간 | 탭이 보이는 동안의 관람 시간 표시 |
| 04 기억 | 여덟 기억의 파편 | 클릭·탭·키보드 선택 및 문장 확인 |
| 05 호흡 | 4-4-4-4 순환 | 동기화된 안내와 일시정지/재개 |
| 06 관찰자 | 보는 자를 보는 눈 | 마우스/터치에 반응하는 눈동자 |
| 07 하나 | 우주와 개인의 관계 | 과학적 표현을 조심스럽게 다듬은 철학적 메시지 |
| 08 끝 | 살아 있음 | 1600×900 PNG 추억 카드 저장, 첫 장 이동 |

## 조작

- **스크롤** 또는 화면 아래 **01–08 탐색**으로 이동합니다.
- **♫ 소리 켜기**를 눌러 브라우저에서 생성한 잔잔한 소리를 켜거나 끌 수 있습니다. 기본은 음소거입니다.
- **움직임 줄이기**는 큰 시각적 연출을 줄입니다. 운영체제의 '동작 줄이기' 설정도 반영합니다.
- **첫 빛** 장은 마우스 이동·클릭, 모바일 탭·손가락 움직임, 키보드 Enter/Space에 반응합니다.
- **기억** 장의 별은 Tab으로 이동하고 Enter 또는 Space로 선택할 수 있습니다.
- **호흡** 장에서 호흡 가이드를 중지하거나 다시 시작할 수 있습니다. 몸에 불편함이 생기면 체험을 중지하세요.
- **끝** 장에서 '이 순간을 이미지로 남기기'를 누르면 PNG가 브라우저에서 생성됩니다.

## 구현과 개인정보

- 순수 HTML/CSS/JavaScript, Canvas 2D, Web Audio. 외부 패키지, CDN, 폰트, API 요청 없음.
- 사용자 이름·생년월일 입력 및 위치 권한 없음. 질문, 개인 기억, 움직임 궤적을 서버에 전송하지 않습니다.
- '기억의 파편'은 원작에 포함된 여덟 가지 문구이며, 사용자의 실제 기억을 추측하거나 수집하지 않습니다.
- 관람 시간은 탭이 비활성화되면 카운터를 일시 중지합니다. 브라우저에 방문 기록을 저장하지 않습니다.
- PNG에는 문구, 별 배경, 현재 관람 시간만 들어갑니다. 화면 스크린샷이나 개인 데이터가 아닙니다.
- 정적 배포를 위해 `.nojekyll` 포함.

## 사용상 유의사항

- 초고성능 그래픽이 아니라 CPU 기반 2D Canvas입니다. 환경에 따라 움직임의 부드러움이 달라질 수 있습니다.
- 마우스를 움직이는 장면과 오디오 기능은 브라우저 보안/미디어 정책에 따라 다르게 작동할 수 있습니다.
- **4초 들숨·4초 정지·4초 날숨·4초 정지**는 연출용 호흡 안내이며 의학적 처방이 아닙니다.
- 텍스트에 등장하는 철학적 문장과 시적 표현은 과학적 사실로 단정해서 읽지 않도록 구분했습니다.

## 파일 구성

```
index.html         메인 문서 / 8개 장
styles.css         화면·모바일·접근성 스타일
app.js             별·빛·기억·호흡·오디오·PNG 로직
favicon.svg        사이트 아이콘
.nojekyll          GitHub Pages용
README.md          이 문서
검토_개선_보고서.md    발견 문제와 개선·검증 결과
```

기존 첨부파일을 기준으로 개선했으며, 원본 내용의 완전한 역사적 복제본은 ZIP에 포함하지 않았습니다.
