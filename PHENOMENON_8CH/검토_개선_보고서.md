# 「당신이라는 현상」 원본 검토 및 개선 보고서

## 1. 검토 대상과 범위

- **검토 대상**: 사용자가 제공한 `붙여넣은 텍스트(1)(20261114-104739).txt` 속 단일 `index.html` 코드.
- 원본의 **어둠 → 첫 빛 → 시간 → 기억 → 호흡 → 관찰자 → 하나 → 끝**, 총 여덟 장을 보존했습니다.
- 단순 미관 변경이 아니라 코드 분석, 접근성 개선, 상호작용·성능·오디오 로직 수정, 배포 파일 구성과 자동화 시험을 수행했습니다.

## 2. 원본에서 발견한 문제와 조치

| 원본 문제/위험 | 근거 / 영향 | 개선 |
|---|---|---|
| 반응형 사용자 경험의 불균형 | `body {cursor:none}`, 장식적 기억 요소가 `div`+마우스 hover 중심 | 기본 시스템 포인터 유지, 기억을 키보드 초점·클릭·탭 가능한 `button`으로 변경 |
| 모바일 터치의 이상한 초기 궤적 | `mouse.x`와 `mouse.y` 초기값 -1000에서 첫 `touchmove` 거리 계산 | 첫 빛에서 인터랙션 영역의 Pointer Events로 통일, 좌표 및 동작 범위 제한 |
| 입자 무한 증가 가능성 | 마우스·터치 발생 때마다 `particles.push`에 개수 제한 없음 | 입자 수 최대 250개(모바일 110개), 화면별 렌더링 부하 제한 |
| 화면을 떠나도 계속 실행 | 애니메이션을 `requestAnimationFrame`으로 계속 예약하고 타이머를 `setInterval`로 실행 | `visibilitychange`와 `pagehide`에서 애니메이션과 오디오 정지, 복귀 시 시간 차이 보정 |
| 시간 개념의 불일치 | `Date.now()`를 사용해 창을 떠난 시간까지 ‘머문 시간’으로 계산 | 탭이 보이는 동안 갱신되는 관람 시간 표시와 명시적 안내 |
| 호흡 안내와 시각 효과의 비동기화 | CSS 16초 애니메이션과 재귀적인 `setTimeout` 텍스트 순환이 별도 실행 | 16초짜리 하나의 경과 시간으로 원과 문구 동기화, 일시정지/재개 추가 |
| 사운드 제어의 리소스 부담 | `startAudio`가 토글마다 Gain·Oscillator·LFO를 새로 생성; 종료는 비동기 stop | 최초에 오디오 그래프 한 번 생성하고 Gain을 조절, 비활성 탭에서 suspend |
| 이미지·소리·모션 제어 접근성 부족 | 커서가 사라지고 별/기억이 Tab 접근 어려움; 일부 모션 지속 | 키보드 탐색, `aria-pressed`/상태 안내, 움직임 감소 적용 |
| 외부 의존성 | Google Fonts 요청 | 외부 폰트 링크 제거. 시스템 폰트만 사용하여 오프라인 가능 |
| 기억 문구의 오해 가능성 | '당신의 기억'이라는 설명만 존재 | 모든 사용자에게 공통인 상상의 문구라고 명시 |
| 천체 원소 생성에 관한 부정확한 단정 | '모든 원자는 별이 폭발한 결과'는 초기 우주의 경원소 등을 누락 | '우리 몸의 여러 원소는 오래전 별의 내부에서 만들어졌다'로 표현 조정 |
| 배포 및 유지보수 불편 | CSS·JS가 1개 HTML에 혼재 | `index.html`, `styles.css`, `app.js` 분리, README 및 `.nojekyll` 포함 |

## 3. 추가한 기능

- 8개 장 하단 탐색과 상단 진행률.
- 빛의 인터랙션: 마우스/터치/키보드 제어, 입자 개수 표시.
- 호흡 애니메이션과 안내문 동기화 및 일시정지/재개.
- 움직임 감소 설정 및 OS 설정 반영.
- 오디오 토글 UI 및 오디오 그래프 재사용.
- 마지막 장의 **1600×900 PNG 카드** 로컬 생성·다운로드(실제 화면의 캡처 아님).
- No-JS 모드에서도 8개의 장과 본문을 읽을 수 있는 기본 가독성.

## 4. 테스트

- Chromium 헤드리스 브라우저에서 CSS/JS를 문서에 인라인 주입하여 주요 기능 자동화 시험 수행.
- 데스크톱 **1440×900**, 모바일 **390×844**, 가로 화면 **844×390**.
- 여덟 장 생성·탐색, 첫 빛의 클릭과 Enter, 기억 선택, 호흡 정지/재개, 모션 제어, 오디오 토글, PNG 다운로드 검사 **세 화면 모두 통과**.
- 수평 오버플로 없음. 자동화 검사에서 **JavaScript pageerror 0건**.
- 자동화 검사용 브라우저에서는 로컬 서버 및 `file://` 탐색이 실행 환경 정책에 의해 차단되어, 동일 HTML과 스타일·스크립트 내용을 인라인 주입해 테스트했습니다. 이 때문에 **실제 GitHub Pages 게시 및 실기기 배포 시험은 별도로 필요**합니다.

## 5. 남은 검증·제약

- 실기기 iOS Safari, Android Chrome, 보조공학기기 전체 조합에 대한 인증 수준 검증은 아직 하지 않았습니다.
- Web Audio는 브라우저의 자체 정책에 따라 클릭 이후에만 시작하며 지원 여부가 다를 수 있습니다.
- 안내된 시간은 전문 의료 정보가 아닙니다. 오디오 음량은 환경에 따라 체감이 다를 수 있으니 처음에는 기기 음량을 낮춰 테스트하세요.
- 별 움직임은 제한된 수의 Canvas 2D 객체로 구현했으며 성능은 기기 환경에 따라 달라집니다.
