# BETWEEN 개선판 검증 보고

## 원본 소스에서 발견한 문제

- 사운드를 껐을 때 기존에 생성된 앰비언트 드론의 출력 이득이 0으로 내려가지 않아 소리가 계속 남을 수 있음.
- 모바일에서 `touchstart`와 호환 마우스 이벤트가 중복 발생하면 같은 동작으로 나무가 두 그루 생성될 수 있음.
- 별의 좌표가 절대 픽셀로 저장되어 기기 화면 크기가 바뀌면 위치가 달라짐.
- `cursor:none`과 `user-scalable=no`로 인해 이용 및 접근성에 문제 발생 가능.
- 입자 수가 많고 연결 검사가 반복되어 고해상도 화면에서 성능 저하 가능.
- `localStorage` 직접 접근 중 예외가 발생하면 브라우저 설정에 따라 시작을 방해할 수 있음.
- 기억 삭제·시간 일시정지·수동 시간 조절·저자극 모드가 없음.
- 과학적 관찰자 효과를 그대로 재현한다고 읽힐 수 있는 설명.
