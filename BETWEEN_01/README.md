# 사이 · BETWEEN

> 당신이 보는 순간, 세계가 깨어납니다.

관찰, 창조, 시간, 기억을 연결하는 **GitHub Pages용 단일 화면 인터랙티브 명상 사이트**입니다. 기존 `사이 · Between` 코드를 검토해 오류를 수정하고, 화면과 상호작용을 다듬은 개선판입니다.

## 시작하기

압축을 풀고 `index.html`을 더블클릭하세요. 로컬 웹 서버 없이 실행할 수 있으며, **CDN·외부 폰트·API·빌드 도구가 필요 없습니다.** 최신 Chrome/Edge/Firefox/Safari의 Canvas 2D와 JavaScript를 사용합니다.

## 조작

| 동작 | 결과 |
| --- | --- |
| 마우스 이동 / 화면 쓸기 | 주변 입자들이 빛나며 서로 연결됩니다 |
| 빈 화면 클릭 / 터치 | 작은 프랙탈 나무가 자라고 기억의 별이 남습니다 |
| 마우스 휠 / 하단 시간 막대 | 새벽 → 아침 → 낮 → 황혼 → 밤 → 심야 이동 |
| 시간 버튼 `Ⅱ / ▷` | 8분 한 바퀴 자동 시간을 일시정지/재개 |
| 음악 버튼 `♫` | Web Audio 앰비언트 사운드 켜기/끄기 |
| 움직임 버튼 `◌` | 저자극 모드 켜기/끄기 |
| 이미지 버튼 `▧` | 현재 화면을 PNG로 저장 |
| 기억 버튼 `⌫` | 확인 후 이 브라우저에 저장된 별 삭제 |
| 안내 버튼 `?` | 사용 방법 및 데이터 안내 |

**키보드:** `Space`로 화면 중앙에 나무 심기, `←/→`로 시간 이동, `M`으로 사운드 토글, `P`로 시간 일시정지, `Esc`로 안내 닫기. 입력기나 버튼에 포커스가 있을 때는 해당 컨트롤의 키보드 동작이 우선됩니다.

## 기억과 개인정보

기억의 별은 **이 브라우저의 `localStorage`에만 저장**됩니다. 좌표는 화면 크기에 대한 0~1 상대값으로 보관되며, 각 별의 색·생성 시각과 함께 최대 **40개**까지 남습니다. 외부 서버로 전송하지 않습니다. 시크릿 모드, 브라우저 저장소 차단, 기록 삭제 등의 환경에서는 다음 방문까지 보존되지 않을 수 있습니다. `⌫` 버튼으로 언제든 삭제할 수 있습니다.

구버전 `between-memories-v1` 데이터가 있고 v2 데이터가 없는 경우, 이전 픽셀 좌표를 **현재 화면 크기 기준으로 근사 변환**합니다. 구버전에 저장 당시의 화면 크기가 없으므로 모든 별이 정확히 같은 위치로 옮겨지는 것은 아닙니다. 새 기록은 정규화 좌표로 유지됩니다.

## 주요 개선 내용

1. **소리 끄기 오류 수정:** 생성된 드론과 차임이 공유 출력 노드를 통해 모두 음소거됩니다. 자동 재생 제한을 지킵니다.
2. **모바일 중복 창조 방지:** `pointerdown`을 사용하여 터치 뒤 발생할 수 있는 합성 마우스 이벤트를 제거했습니다.
3. **반응형 기억의 별:** 화면 픽셀 대신 상대 좌표로 저장합니다. 기존 기록은 가능한 범위에서 이관합니다.
4. **성능:** 입자 수/픽셀 밀도 제한, 주사율 제한, 연결 탐색 공간 분할, 비활성 탭 렌더 중단을 적용했습니다.
5. **접근성:** 축소 동작 기본 설정을 따르며, 화면 줌 제한을 제거하고, 일반 커서/터치/키보드/명확한 버튼 상태를 지원합니다.
6. **새로운 제어:** 시간 슬라이더, 일시정지, 움직임 줄이기, 이미지 저장, 데이터 삭제, 사용법 안내.
7. **안정성:** `localStorage` 예외 처리, 잘못된 저장 데이터 검증, 화면 크기 변경 대응.
8. **실험 설명:** 관찰 효과는 시각적·철학적 은유이며 실제 양자역학 실험이 아니라는 점을 안내합니다.

## GitHub Pages 배포

1. ZIP을 압축 해제합니다.
2. 아래 파일들을 GitHub 저장소의 **루트 경로**에 업로드합니다.
3. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch**에서 `main`과 `/(root)`를 선택하고 저장합니다.
4. Pages 설정에 표시되는 주소로 방문합니다. 저장소 하위 경로에서도 상대 경로로 작동합니다.

```
index.html
style.css
main.js
favicon.svg
README.md
TEST_REPORT.md
```

이미 같은 이름의 파일이 있는 저장소에 올릴 경우 기존 파일의 백업을 권장합니다.

## 작동 원리

- 배경: 단계별 그라디언트, 호흡하는 성운, 소형 별, 화면을 순환하는 빛.
- 관찰: 마우스 주변 입자들이 반발하며 연결선을 그립니다. 입자 간 연결 탐색은 공간 격자를 사용합니다.
- 창조: 클릭 위치에 유한한 수명의 프랙탈 나무가 성장하고, 남는 별이 기록됩니다.
- 시간: 한 주기에 480초(8분)이며 휠/슬라이더 사용 중에는 자동 흐름이 잠시 멈췄다가 재개됩니다.
- 사운드: Web Audio에서 만든 사인파 기반 드론과 펜타토닉 음계 차임. 기본은 꺼짐.

## 주의

테스트는 자동화 Chromium 환경에서 소스 파일을 페이지에 직접 주입하여 진행했습니다. 브라우저 환경에서 `file://` 직접 탐색 자체가 차단되어, **실제 GitHub Pages 운영 배포와 모든 브라우저 종류에 대한 전체 검증은 아직 수행하지 않았습니다.** 자세한 결과는 `TEST_REPORT.md`에서 확인할 수 있습니다.
