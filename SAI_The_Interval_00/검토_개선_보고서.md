# 「사이 · THE INTERVAL」 검토 및 개선 보고서

## 검토 대상과 보존 범위

사용자가 제공한 Markdown 텍스트에 들어 있던 `index.html`, `style.css`, `script.js`를 원본 소스로 삼았습니다. 원본의 7개 장(입구, 호흡, 생각, 시간, 타인, 자아, 회귀), 방문할 때마다 별이 하나씩 자란다는 설정, 시간대별 색채, 합성 앰비언트 소리, 마지막의 회귀라는 철학적 구성을 유지했습니다. 원본 코드는 `original/` 아래 보존했습니다.

## 확인한 문제와 수정

| 원본의 문제·위험 | 영향 | 개선 내용 |
|---|---|---|
| `localStorage.getItem`/`setItem`를 예외 처리 없이 사용 | 비공개·저장 차단 환경에서 스크립트 실행 중단 가능 | 저장소 가용성을 검증하고, 예외 상황에는 현재 세션 메모리로 대체 |
| '처음으로'에서 페이지 `reload()` | 새 방문이 아닌데도 카운터와 별이 증가 | 새로고침 없이 첫 장으로 스크롤하도록 변경 |
| 시간 페이지에 접근한 뒤에도 생각 단어 재귀 생성 지속 | 화면 밖에서도 노드·타이머 누적 | 생각 장이 활성·가시 상태일 때만 단어 생성, 동시에 최대 9개 |
| 호흡 횟수 `elapsed/4`로 계산 | 실제 호흡을 관측한 듯 보이며 8초 사운드 리듬과 불일치 | 8초 **예시 리듬 환산**을 명시하고 활성 시간/8로 통일 |
| 스크롤 이벤트 수를 스크롤 '횟수'로 표현 | 기기·브라우저에 따라 값이 달라지는 비직관적 지표 | 누적 화면 이동 거리(뷰포트 높이 단위)로 변경 |
| 재방문마다 기존 별 좌표를 검증하지 않음 | 잘못된/비정상적으로 큰 기록이 렌더링을 방해 | 숫자·범위 검사, 최대 60개 보관, 원본 저장 키를 읽어 이전 기록 이어가기 |
| 기록을 끄거나 지울 수 없음 | 이용자의 데이터 통제 불가 | 기록 안내 대화상자, 저장 중지/재개, 삭제 기능 추가 |
| 무한 Canvas 렌더링과 고해상도 무제한 DPR | 배터리 소모 및 저사양 기기에서 과부하 가능 | 최대 30fps 시각 갱신, DPR과 픽셀 수 제한, 비활성 탭/움직임 줄이기 대응 |
| Canvas 크기를 바꿀 때 별이 새로 배치됨 | 화면 크기 변경에서 시각적 불연속 | 상대 좌표 기반 별 배치로 크기 변경 후에도 별자리 유지 |
| 호흡 원형과 오디오가 별도 타이머를 사용 | 안내와 시각/음향 표현의 위상 차이 | 4초 들숨 + 4초 날숨을 하나의 상태로 제어하고 수동 일시정지 제공 |
| 소리를 재개할 때마다 `AudioContext`와 oscillator 재생성 | 클릭 반복에 따른 불필요한 객체 생성 | 최초 클릭에만 노드를 생성하고 Gain 조절·`suspend/resume`으로 관리 |
| 외부 Google Fonts 의존 | 오프라인 사용 및 일부 내부망에서 폰트 로딩 실패 | 시스템 폰트 기반 대체와 외부 리소스 요청 제거 |
| 모바일에서 장 이동/키보드 안내가 부족 | 작은 화면, 터치·키보드 접근성 저하 | 모바일 하단 장 탐색, 포커스 표시, 버튼 설명, 접근성 대화상자 추가 |
| 최종 장에 시간을 처음 한 번만 반영 | 오래 머문 후 시간이 변경되지 않음 | 활성 시간과 이동 거리, 시를 화면 표시 중 계속 갱신 |

## 추가한 기능

- 방문 시간대별 시각 테마와 여덟 초 리듬의 선택형 호흡 안내
- 브라우저에 보관한 별의 SVG 기반 별자리와 과거 기록 마이그레이션
- 장면별 탐색·스크롤 진행 막대·키보드 포커스/스크린리더 레이블
- 활성 세션 시간·화면 이동 거리에 따라 달라지는 오리지널 짧은 시
- 시를 `.txt`로 저장, 별자리와 시를 1600×900 `.png`로 저장
- 애니메이션 감소/끄기, 로컬 기록 관리, 오디오 안전한 재사용

## 시험 내용

- JavaScript 구문: `node --check script.js` 정상.
- Chromium 렌더링: PC **1440×900**, 모바일 세로 **390×844**, 모바일 가로 **844×390**.
- 기능 검사: 일곱 장 표시/이동, 호흡 일시정지·재개, 시 텍스트/이미지 파일 다운로드, 기록 대화상자와 저장 중지/복구/삭제, 움직임 끄기, 소리 켜기/끄기, 페이지 재로딩 없는 첫 장 이동.
- 예외 검사: 저장소 접근을 막아도 오류 없이 본문과 상호작용 실행.
- 위 화면 크기에서 가로 스크롤 넘침 없음. 자동화에서 JavaScript 미처리 예외 없음.
- **검증 한계:** 실행 환경의 Chromium 정책이 임의 주소 접근을 차단했습니다. 브라우저 테스트는 파일의 HTML·CSS·JS를 메모리 문서에 주입하고 저장소를 모사하는 방식으로 수행했습니다. `file://` 로컬 로딩, 실제 GitHub Pages, iOS Safari, 모바일 실기기는 별도 검증하지 않았습니다.

## 공개 및 보안 확인

- API 키·계정 토큰·비밀번호·서버 URL 설정 없음.
- 이미지와 사운드는 브라우저 안에서 생성되며 외부 CDN·외부 폰트를 요청하지 않음.
- 저장 데이터는 `localStorage`의 방문 횟수와 별 좌표, 저장 여부 설정이며 서버 전송 코드가 없음.
- 사용자 데이터는 HTML `innerHTML`에 삽입하지 않고 `textContent`/검증된 SVG 속성으로 표현함.

## GitHub Pages 배포

ZIP 내부 루트의 `index.html`, `style.css`, `script.js`, `favicon.svg`, `.nojekyll`을 저장소 루트로 복사하면 됩니다. `original/`은 비교용 원본 백업일 뿐 실행 파일이 아닙니다. 설정에서 Pages → Deploy from a branch → main/(root)를 선택합니다.
