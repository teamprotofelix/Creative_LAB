# 사이 · THE INTERVAL

> 숨과 숨 사이, 생각과 생각 사이, 나와 너 사이, 나와 나 사이를 통과하는 일곱 장의 고요한 체험.

정적 HTML/CSS/JavaScript로 만든 독립형 명상형 웹사이트입니다. **서버, API 키, npm 빌드, CDN, 외부 폰트, 사용자 계정이 필요 없습니다.** 소리는 기기 안에서 Web Audio로 합성하며 처음에는 꺼져 있습니다.

## 시작하기

- ZIP을 풀고 `index.html`을 Chrome, Edge 또는 Safari에서 엽니다.
- 또는 이 폴더의 루트 파일을 GitHub 저장소에 업로드하고 **Settings → Pages → Deploy from a branch → main / (root)**로 설정합니다.
- GitHub Pages에서는 사이트의 `index.html`을 자동으로 시작 화면으로 읽습니다.
- 저장소가 `/my-repo/`와 같은 하위 경로에서 제공되어도 동작하도록 모든 정적 파일을 상대 경로로 연결했습니다.

## 일곱 장

| 장 | 제목 | 체험 |
|---|---|---|
| 01 | 입구 | 두 개의 원과 하나의 빛, 여정 시작 |
| 02 | 호흡 | 4초 들숨·4초 날숨으로 이루어진 8초 *예시* 호흡 리듬, 중지/재개 |
| 03 | 생각 | 지나가는 단어와 생각의 간격 |
| 04 | 시간 | **전경에서 페이지가 열린 활성 시간**과 8초 예시 주기의 호흡 환산 |
| 05 | 타인 | 방문 시 하나씩 추가되는 별자리, 누적 방문 기록 확인 |
| 06 | 자아 | 반사되는 빛과 자아에 관한 질문 |
| 07 | 회귀 | 활성 시간, 화면 이동 거리, 상황별 시, TXT/PNG 저장 |

## 조작

- 화면 우측의 01~07(모바일에서는 하단)을 눌러 장 사이를 이동합니다.
- 상단 **소리**: 낮은 음량의 앰비언트 합성음 켜기/끄기. 버튼 클릭 전에는 소리가 재생되지 않습니다.
- 상단 **움직임**: 화면의 별빛·움직이는 장식 정지/재개. OS의 '움직임 줄이기' 설정을 처음 상태에 반영합니다.
- 상단 **기록**: 방문 수와 별자리 수 확인, 이후 저장 중지, 저장 기록 삭제. **기억하지 않기**를 누르면 기존 저장 기록도 삭제됩니다.
- 호흡 장의 **호흡 안내 잠시 멈추기**: 8초 리듬 일시정지.
- 마지막 장의 **시를 글로 저장**: UTF-8 텍스트 파일 다운로드.
- 마지막 장의 **별자리 이미지 저장**: 1600×900 PNG 파일 다운로드.
- 마지막 장의 **처음으로**: 기록을 하나 더 추가하지 않고 첫 장으로 이동.

## 데이터·개인정보

- 웹사이트에는 분석 도구, 광고 SDK, 외부 요청, 인증 서버가 없습니다.
- 기본 설정에서 **이 기기의 브라우저 localStorage**에 방문 횟수와 최대 60개 별의 상대좌표만 저장합니다.
- `sai_visits` 및 `sai_stars`를 사용하는 원본의 기록이 있으면 정상 형식을 검증해 새 형식으로 읽고 이어갑니다. 브라우저·저장 위치 또는 출처(origin)가 다르면 이전 기록은 보이지 않습니다.
- 저장소 접근이 차단되면 현재 방문의 별 하나만 표시하고 사이트의 나머지 기능은 계속 동작합니다.
- '기억하지 않기'를 선택한 설정만, 이후 재방문 시 이를 존중하기 위해 로컬에 남습니다.
- 1분 중 숨을 몇 번 쉬었는지 **측정하지 않습니다**. 표시된 수는 체험 시간 ÷ 8초에 기반한 예시 추정치입니다.
- '스크롤 횟수' 대신 실제 화면 이동 거리 합계 ÷ 현재 화면 높이(장)를 보여줍니다. 브라우저에서 발생한 이동을 집계하므로 버튼을 통한 이동도 포함됩니다.
- 화면 밖 탭·앱 비활성 시간은 체험 시간에서 제외합니다.

## 파일 구성

```
index.html                 7개 장 및 접근 가능한 UI
style.css                  적응형 디자인, 움직임 감소 대응
script.js                  체험/기록/오디오/PNG 생성 로직
favicon.svg                작은 아이콘
.nojekyll                  GitHub Pages Jekyll 처리 생략
README.md                  설치 및 사용 방법
검토_개선_보고서.md           원본 분석과 변경 내역
original/                  업로드해 주신 원본에서 추출한 파일 3개 (비배포 백업)
```

**GitHub에 올릴 때 `original/`은 배포에 필요하지 않습니다.** 루트의 `index.html`, `style.css`, `script.js`, `favicon.svg`, `.nojekyll`만 있어도 실행됩니다.

## 호환성과 검증 범위

`node --check script.js` 구문 검사를 통과했습니다. Chromium에서 화면 크기 1440×900, 390×844, 844×390으로 렌더링과 주요 버튼을 시험했습니다. 시험 환경의 정책상 로컬 주소 직접 접근이 제한되어, 실제 HTML/CSS/JS를 브라우저에 삽입하고 로컬 저장소를 모사한 환경에서 인터랙션을 검사했습니다. **실제 GitHub Pages에 배포한 URL과 실기기에서는 별도 최종 시험이 필요합니다.**
