# 사이 · Between — 시간이 머무는 정원

> 당신이 없어도, 시간은 이곳을 지나갑니다.

완전한 정적 웹사이트입니다. 외부 라이브러리·서버·계정·API·웹폰트 없이 브라우저의 **HTML, CSS, JavaScript, Canvas 2D, Web Audio, localStorage**만 사용합니다.

## 체험

1. `index.html`을 열고 **정원으로 들어가기**를 누릅니다.
2. 빈 화면을 **클릭하거나 한 번 터치**하면 빛의 씨앗이 심어집니다. 키보드로는 정원 캔버스에 포커스를 놓고 `Enter` 또는 `Space`를 누르세요.
3. 사이트를 닫았다가 다시 방문해 보세요. `plantedAt`과 현재 브라우저 시간을 비교해, 열린 상태가 아니었던 기간의 성장을 계산합니다.
4. 화면 오른쪽 위 버튼으로 소리를 켜거나 끄고, 현재 캔버스를 PNG로 저장하고, 정원 기록을 JSON으로 백업·복원·삭제할 수 있습니다.
5. 명상 질문에 답하면 선택 내용이 브라우저에 보존되고 빛의 씨앗이 추가됩니다. 질문은 건너뛸 수도 있습니다.

### 성장 단계 — 심은 순간부터 흐른 실제 시간 기준

| 경과 시간 | 모습 |
|---|---|
| 심자마자 | 씨앗 |
| 20초 후 | 새싹 |
| 5분 후 | 어린 빛 |
| 1시간 후 | 자라는 빛 |
| 6시간 후 | 꽃 |
| 3일 후 | 고요한 빛 |
| 7일 후 | 오래된 별 |

*성장 단계는 브라우저 기기의 시계를 기준으로 계산합니다. 서버 시각을 검증하는 서비스가 아니므로, 기기 시계 변경은 성장 모습에 영향을 줄 수 있습니다.*

## 배포 — GitHub Pages

1. ZIP을 해제합니다.
2. `index.html`, `style.css`, `app.js`, `favicon.svg`, `README.md`, `.nojekyll`, `TEST_REPORT.md`를 **모두 GitHub 저장소 루트**에 업로드합니다. 별도 빌드나 패키지 설치가 필요하지 않습니다.
3. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch**에서 `main` / `/(root)`를 선택하고 저장합니다.
4. 생성되는 GitHub Pages 주소로 접속합니다. 프로젝트 하위경로에서도 상대 파일 경로로 동작합니다.

`index.html`을 두 번 클릭해 브라우저에서 직접 열 수도 있습니다. 일부 브라우저는 `file://`에서 저장소나 오디오를 제한할 수 있으므로 실제 배포 환경에서 확인하는 것이 좋습니다.

## 개인정보 및 저장 동작

- 저장 키: `localStorage["sai_garden_v1"]` — **기존 원본 정원과 동일한 키**를 사용합니다.
- 보관 항목: 빛의 심은 시각, 상대 위치, 빛의 색과 모양, 방문 시각, 선택한 명상 답변.
- 네트워크·서버로 자동 전송하지 않습니다. 다른 기기와 자동 동기화되지 않습니다.
- 새로운 빛은 상대 좌표(0~1)로 저장되어, 화면 크기가 바뀌어도 정원 안의 상대 위치를 유지합니다.
- 기존 원본 버전의 픽셀 좌표 기록은 읽을 수 있습니다. **기존 기록에 당시 화면 크기 정보가 없으므로** 이전 기기·창의 정확한 위치를 보장할 수는 없습니다. 최초 복원 시 현재 화면 크기 기준으로 가능한 범위에서 변환합니다.
- 지나치게 많은 씨앗으로 인한 렌더링 성능 저하를 방지하기 위해 최대 **120개 씨앗**, 최근 **200회 방문 기록**, 최근 **100개 답변**을 지원합니다. 최대치를 넘기면 기존 씨앗을 몰래 지우지 않고 새 심기를 제한합니다.
- 기록을 읽을 수 없을 경우 기존 저장값을 자동으로 덮어쓰지 않습니다. 저장 기능이 차단되어도 일시적인 정원 체험은 할 수 있습니다.
- **정원 기록 → 기록 내보내기**로 JSON 백업을 먼저 보관한 뒤, 필요 시 초기화하세요. 가져오기는 기존 기록을 *교체*하므로 확인 단계가 있습니다.

## 접근성·성능

- 모바일 터치와 데스크톱 포인터를 하나의 이벤트로 처리하여 씨앗 중복 생성을 방지합니다.
- 키보드 심기, 모달 Escape 닫기, 모달 내 포커스 순환, 버튼 이름과 상태를 지원합니다.
- `prefers-reduced-motion` 설정에서 프레임 갱신 빈도를 낮춥니다. 시각 효과가 적게 재생되어도 씨앗의 실제 성장 시간은 변하지 않습니다.
- 정원은 보이지 않는 탭에서 불필요한 렌더링과 소리를 억제하고 돌아올 때 성장 상태를 갱신합니다.
