# UNWRITTEN — 아직 쓰이지 않은 세계

> **일반적인 웹사이트가 아니라, 실시간으로 생성되는 여섯 개의 디지털 우주입니다.**
>
> HTML + CSS + 순수 JavaScript + WebGL 1.0. 서버·빌드·API 키·외부 라이브러리 **전혀 필요 없음**.

## 30초 만에 GitHub Pages로 배포하기

1. ZIP 압축을 풀어 나오는 **내용물**(`index.html`, `style.css`, `js/`, `assets/`, `.nojekyll` 등)을 GitHub 저장소 최상위(root)에 업로드합니다. ZIP 파일 자체를 업로드하지 마세요.
2. 저장소에서 **Settings → Pages**로 이동합니다.
3. **Build and deployment → Source: Deploy from a branch**를 선택합니다.
4. Branch를 `main`, 폴더를 `/(root)`로 지정하고 **Save**를 누릅니다.
5. 배포된 주소를 열면 됩니다. 프로젝트 저장소라면 일반적으로 `https://<username>.github.io/<repository>/`입니다. 사용자 페이지 저장소라면 `https://<username>.github.io/`입니다.

**로컬에서 확인**: `index.html`을 Chrome / Edge / Firefox에서 직접 열 수 있습니다. 대부분의 브라우저는 `file://`에서도 동작합니다. 화면이 정상 표시되지 않으면 아래의 로컬 서버 예시를 사용하세요.

```powershell
# Windows PowerShell — 파일이 있는 폴더에서 실행
python -m http.server 8000
# 이후 http://localhost:8000 접속
```

## 무엇을 할 수 있나요?

- **01 사건의 지평선** — 빛의 강착 원반, 소용돌이치는 성운, 중력 렌즈를 닮은 광륜
- **02 형광 정원** — 문장과 시간에 따라 달라지는 발광 꽃·줄기·반딧불
- **03 기억의 바다** — 여러 파형의 간섭, 반사광, 파문
- **04 가능성의 도시** — 생성형 실루엣 건축물, 반짝이는 창문, 붉은 미래의 일몰
- **05 무한의 단면** — Julia 집합 기반 프랙털. 마우스 휠로 연속 확대·축소
- **06 빛의 편지** — 여러 층의 살아 있는 오로라와 밤하늘
- **문장 입력** — 텍스트를 결정론적 숫자 씨앗(seed)으로 변환하여 각 세계의 무늬·배치를 변화
- **마우스 / 터치** — 클릭하면 파문과 빛 입자, 드래그하면 잠시 이어지는 별자리
- **자동 탐험** — 일정 시간마다 자동으로 차원 이동
- **사운드** — 사용자 클릭 후 Web Audio API로 직접 합성한 앰비언트 소리. 기본 무음
- **작품 저장** — 현재 장면을 UI가 없는 1600×900 PNG 아트 포스터로 내보내기
- **보관함** — 최대 12개의 세계 설정을 해당 브라우저의 localStorage에 보관, 즉시 복귀
- **세계 공유** — URL에 차원/씨앗/문장이 포함되어 같은 세계의 *설정*을 다시 열 수 있습니다. 시간에 따라 애니메이션 프레임은 달라집니다.

## 키보드 명령어

| 키 | 기능 |
|---|---|
| `1` ~ `6` | 차원 선택 |
| `Space` | 다음 차원 |
| `R` | 랜덤 세계 |
| `S` | PNG 이미지 다운로드 |
| `G` | 보관함 |
| `M` | 소리 On/Off |
| `H` 또는 `?` | 도움말 |
| `Esc` | 팝업 닫기 / 자동 탐험 종료 |

## 설계 및 보안

- 전 구성 요소를 **정적 파일**로 실행합니다. 백엔드 필요 없음.
- 외부 CDN, 이미지, 폰트, 분석 스크립트, 광고 SDK, 네트워크 호출이 없습니다.
- **API 키, 비밀번호, 토큰, 개인정보 예시 값이 없습니다.**
- 입력한 문장은 브라우저 내에서만 처리합니다. 세계 링크를 공유하는 경우 **문장이 주소(URL)에 포함**되므로 민감한 문장은 입력하거나 공유하지 마세요.
- 보관함만 `localStorage`에 저장하고, 저장된 정보는 다른 기기로 전송되지 않습니다.
- WebGL이 지원되지 않으면 별도로 구현한 Canvas 2D 실시간 렌더러로 자동 전환합니다. 이 경우 일부 고급 셰이더 효과는 간소화됩니다.
- 모바일·데스크톱 반응형이며, 모션 감소 OS 설정 시 애니메이션 속도가 감소합니다.
- UI 원어: 한국어. 영어는 전시 작품의 분위기를 위한 레이블입니다.

## 수정하고 싶다면

- **문구와 세계의 순서**: `js/app.js` 맨 위의 `SCENES` 배열
- **색상과 배치**: `style.css`의 `:root` 및 컴포넌트 CSS
- **세계의 수학적 그림**: `js/engine.js` 내부 `threshold`, `garden`, `ocean`, `city`, `fractal`, `aurora` GLSL 함수
- **속도**: `js/app.js`의 `render`에서 최대 프레임률(기본 데스크톱 45 FPS, 모바일 또는 프랙털 30 FPS)

## 알려진 제약

1. GPU 성능과 브라우저의 WebGL 지원에 따라 프레임률이 다를 수 있습니다.
2. 문장의 의미를 AI가 해석하는 기능은 없습니다. 문장으로부터 재현 가능한 숫자를 만들고, 그 숫자로 그림을 바꿉니다.
3. 단순 코드만으로 무한히 다른 종류의 객체를 그리는 것은 아닙니다. 여섯 종류의 알고리즘이 각기 다른 변주를 수행합니다.
4. 링크를 통해 동일한 설정을 불러오더라도 시간에 따라 움직이는 장면의 **정확히 같은 프레임**을 재현하지는 않습니다.
