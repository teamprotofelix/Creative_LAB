# 당신이라는 현상 · PHENOMENON

> 이 페이지는 당신의 시간을 요구합니다. 서두르지 않아도 됩니다.

원본 「당신이라는 현상」을 검토하고 안정성·접근성·성능·모바일 사용성을 보완한 정적 사이트입니다. **GitHub Pages에서 별도 빌드 없이 사용할 수 있습니다.**

## 구성

```text
index.html           여섯 장의 콘텐츠와 접근 가능한 인터페이스
styles.css           스타일·반응형 레이아웃·움직임 감소 대응
app.js               별빛·호흡·추정 시간·생명·이름·사운드·PNG 저장
favicon.svg          자체 제작 SVG 파비콘
.nojekyll            GitHub Pages Jekyll 처리 생략
README.md            이 문서
검토_개선_보고서.md     원본의 문제와 개선 사항, 검증 범위
```

## 경험 방법

1. **들어가며** — 느리게 맥동하는 작은 구체를 만나세요.
2. **호흡** — 4초 들숨, 6초 날숨의 안내를 바라보고, 필요하면 '호흡 일시정지'를 누르세요. 억지로 호흡을 맞출 필요는 없습니다.
3. **시간** — 출생 날짜를 선택하고 '시간 펼치기'를 누르면 여러 추정치가 나타납니다. 이는 의료·건강 측정값이 아닙니다.
4. **생명** — 빈 공간을 터치하거나 클릭해 나선을 심으세요. '중앙에 빛 심기'와 '정원 비우기'도 사용할 수 있습니다.
5. **이름과 우주** — 한글, 영어, 단어를 입력해 빛으로 된 글씨를 만나세요. '이름 흩뜨리기'로 되돌릴 수 있습니다.
6. **끝** — 마지막 문장을 감상한 뒤 '이 순간을 이미지로 남기기'를 눌러 기기에 PNG로 저장할 수 있습니다.

상단에서 **움직임 켜기/끄기** 및 **사운드 켜기/끄기**를 설정할 수 있습니다. 왼쪽(모바일에서는 하단)의 번호를 누르면 각 장으로 이동합니다. 사운드는 **처음부터 꺼져 있으며** 직접 선택한 경우에만 Web Audio로 생성됩니다.

## 설치 및 배포

1. 이 ZIP을 **압축 해제**하세요.
2. 압축을 푼 파일들(`index.html`, `styles.css`, `app.js` 등)을 GitHub 저장소의 **루트 폴더**에 업로드하세요. 파일들을 별도 하위 폴더에 넣지 마세요.
3. 저장소에서 **Settings → Pages → Build and deployment → Deploy from a branch**를 선택하고 `main` / `/ (root)`를 지정하세요.
4. 배포가 끝난 뒤 제공되는 GitHub Pages 주소에 접속하세요. 이미 Pages가 설정된 저장소라면 main에 파일이 반영될 때 자동으로 갱신될 수 있습니다.

내부망 또는 로컬에서도 `index.html`을 Chrome 등 브라우저에서 열 수 있도록 설계했습니다. 파일을 분리했지만 모두 상대 경로로 연결되어 있습니다.

## 성능·접근성·개인정보

- **외부 종속성 0개:** 외부 폰트·CDN·API·분석 스크립트가 없습니다. 운영 시에도 사용자 데이터 요청을 보내지 않습니다.
- **계산 정보 비저장:** 입력한 생년월일과 이름은 메모리에서만 처리하며 `localStorage`, 쿠키 또는 서버에 저장하지 않습니다. PNG를 저장하면 사용자가 입력한 이름이 이미지 안에 포함될 수 있습니다.
- **과학적 가정의 한계:** 추정 심박수 72회/분, 호흡수 16회/분, 눈 깜박임 15회/분, 지구 공전 365.2422일/회, 달 항성공전 27.3217일/회를 가정합니다. 개인의 실제 생체 수치를 측정하지 않습니다.
- **움직임 절약:** 운영체제의 '움직임 줄이기' 설정을 최초값으로 반영하고 수동 전환도 가능합니다. 화면이 백그라운드로 가면 캔버스 루프가 정지합니다.
- **키보드 조작:** 6개 장 이동, 빛 심기, 입력, 저장, 사운드 설정 모두 버튼·링크로 작동합니다.
- **세로/가로 화면:** 다양한 화면 크기를 지원합니다. 작은 화면은 콘텐츠를 세로로 스크롤해 확인합니다.
- **자체 생성 아트:** 별·나선·이름 글자·다운로드 PNG가 모두 Canvas 2D 기반으로 생성됩니다.

## 사용 환경

최신 Chromium 계열 브라우저의 PC 1440×900, 모바일 390×844, 가로 844×390 뷰포트에서 기능 시험했습니다. 브라우저 테스트는 화면 크기/터치 입력을 *에뮬레이션*한 것이며 실제 스마트폰 기종별 성능을 보장하지 않습니다. Safari/Firefox 및 배포 후 GitHub Pages 서비스에 대해서는 별도의 현장 확인이 필요합니다.

## 수정 파일

디자인은 `styles.css`, 문구와 구조는 `index.html`, 동작과 계산은 `app.js`에서 수정할 수 있습니다. API 키, 서버 환경변수, 패키지 설치 과정이 필요하지 않습니다.
