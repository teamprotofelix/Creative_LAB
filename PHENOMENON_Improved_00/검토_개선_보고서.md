# 「당신이라는 현상」 원본 검토 및 개선 보고서

검토 대상: 사용자가 제공한 붙여넣기 원본 `index.html` 코드 및 `README.md` 설명. 원본은 여섯 장의 느린 경험으로 설계되어 있으며, 별 배경·호흡·시간 계산·빛 나선·별빛 이름·마무리·앰비언트 소리의 조합을 핵심 컨셉으로 삼습니다.

## 구현 주요 사항

- 기존 6장 동선과 우주적·명상적 콘셉트를 유지하되 장 이동 메뉴, 스크롤 진행률, 모바일 하단 내비게이션 추가
- 여섯 장의 제목·안내가 가려지지 않도록 반응형 패딩 및 세로 스크롤 보정
- 별빛, 궤도, 나선, 이름 입자를 모두 외부 이미지 파일 없이 Canvas/CSS로 렌더링
- 페이지 비활성 시 반복 그리기 중단, 모바일 고해상도 캔버스 배율 제한, 오브젝트 최대 수 제한
- 10초 호흡 안내는 화면에 해당 장이 보이고, 자동 효과가 활성화된 동안에만 횟수를 증가시킴
- 사용자 입력 문자열은 HTML로 주입하지 않고 Canvas `fillText`에만 사용, 입력 한글 조합 상태 대응
- 테마 파비콘과 `.nojekyll`, 현장 안내 문서 포함

## 알려진 제한과 배포 후 확인 사항

1. 화면에서 보이는 생명은 시각적 나선이며 실제 생물학적 생명이나 과학적 시뮬레이터는 아닙니다.
2. 숫자는 평균치에 기반한 **가상 추정 모델**입니다. 임상·의료·개인 건강 판단에 활용할 수 없습니다.
3. 페이지의 카운터·입력 내용은 새로고침 시 초기화됩니다. 사용자의 데이터를 저장하지 않는 설계 의도입니다.
4. 장치 성능에 따라 입자 밀도·부드러움이 달라질 수 있습니다.
5. Safari/Firefox 실브라우저, 실제 Android/iOS 장치, GitHub Pages 실제 운영 배포는 아직 시험하지 않았습니다.
6. ZIP은 GitHub 저장소 루트에 풀어 올리는 구조이며, 기존 파일이 있는 저장소에서는 업로드 전에 덮어쓸 파일을 확인해야 합니다.

**결론:** 기존의 여섯 가지 경험은 유지하면서 입력 검증, 실제 조작, 내부망 사용, 렌더링 제어, 개인정보 안내 및 문서화를 강화했습니다. 이번 개선판은 GitHub Pages용 정적 파일로 바로 업로드할 수 있도록 정리되어 있습니다.
