# 변경 내역 — 2.0

원본: 사용자가 제공한 `the site that knows you` HTML 코드 및 README.

## 수정한 결함

| 원본 문제 | 개선 내용 |
|---|---|
| 고요함(passive path) 분기에서 `generateSignature()`를 호출하지 않아 **초상화가 비어 있음** | 모든 종료 경로에서 하나의 `reveal()` 상태 전환으로 초상화를 생성합니다. |
| `runSequence()`의 긴 비동기 대기와 고정 연출로 결과에 도달하는 데 지나치게 오래 걸림 | 사용자 시작 → 관찰 → 즉시 공개 가능한 결과의 3단계로 단순화하고, 30초 자동 완료를 넣었습니다. |
| 재시작 시 `location.reload()` 호출 | 전역 이벤트 리스너를 늘리지 않고 관찰 데이터·출력을 초기화하는 인페이지 재시작을 구현했습니다. |
| `mousedown`, `touchstart`를 각각 사용하고 터치 및 포인터 통계가 일관되지 않음 | Pointer Events로 입력을 통합하고, 버튼의 조작은 관찰 통계에서 제외합니다. |
| 100픽셀 정사각형 구역·원시 거리로 화면 크기에 따라 탐색 통계가 크게 달라짐 | 5×4 정규화 구역과 화면 크기 정규화 이동 거리로 판정을 계산합니다. |
| 일부 원형 판정의 우선순위가 불균형함 | 11종 원형의 순서·조건을 재정의하고, 0클릭·1클릭·다클릭 핵심 경로를 검사했습니다. |
| 관찰 기간 바깥의 행동도 분석 데이터에 포함 | 시작 버튼으로 명시적으로 시작한 뒤 `observing` 상태일 때만 행동을 기록하고 결과 확정 시 스냅샷을 만듭니다. |
| 멈춤이 오직 다음 움직임이 있을 때만 기록됨 | 관찰 프레임에서 휴지 상태를 확인하고, 종료 시 마지막 멈춤도 확정합니다. |
| SVG 문자열만 화면에 삽입하고 다운로드할 수 없음 | 안전한 SVG DOM 생성 및 SVG/1600×1600 PNG 내보내기를 추가했습니다. |
| 클릭 시 지속되는 Web Audio 드론에 끄기 기능이 없고 탭 비활성화 시에도 작동 | 기본 무음, 명시적 켜기/끄기, 백그라운드 자동 일시 중지 및 종료 시 자원 정리를 구현했습니다. |
| 외부 Google Fonts로 네트워크 요청이 발생하지만 개인정보 설명이 모호함 | 외부 폰트를 제거하고 시스템 폰트를 사용하여 행동 관련 네트워크 요청을 없앴습니다. GitHub Pages의 기본 접속 기록은 별개로 설명합니다. |
| 우클릭 메뉴 강제 비활성화, 키보드·모션 감소 배려 부족 | 우클릭 메뉴 제한 제거, 키보드 입력·동작 감소·상태 안내 지원. |
| 매 프레임 Canvas에 수많은 그라디언트를 생성하고 백그라운드에서 계속 갱신 | 글로우 이미지 재사용, 별·입자 수 상한, DPR/모바일 프레임 제한, 비활성화 시 렌더링 중지. |

## 개선된 연출

- 한국어/영어 전환 가능한 이야기와 원형 설명
- 사용자 궤적이 실제로 연결된 1200×1200 SVG 원본 초상화
- 선택한 원형에 따른 빛의 색상, 움직임·멈춤에 따른 별자리 구조
- 고요한 방문자를 위한 전용 우주 및 해설
- 모바일 반응형 레이아웃과 관찰 진행률, 시각적 통계

## 검증

- `node --check assets/app.js` 문법 검사
- `tests/smoke.cjs` (일반/모바일 설정 및 움직임 감소 설정의 4조합) 기능 테스트
- HTML 중복 ID 확인, 내부 리소스 존재 확인, 외부 네트워크 API·저장소 호출 정적 점검

실제 Chromium을 이용한 시각적 자동 테스트는 실행 환경의 브라우저 내비게이션 정책에서 차단되어 완료하지 못했습니다. 따라서 실제 브라우저 호환성과 시각적 배치는 별도 확인이 권장됩니다.
