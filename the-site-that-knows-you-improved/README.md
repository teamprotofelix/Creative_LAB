# the site that knows you — 개선판 2.0

> 당신의 움직임, 클릭, 멈춤으로 단 한 번의 별자리를 만듭니다.
>
> **이것은 성격 진단이 아닌 인터랙티브 예술 작품입니다.** 방문자의 행동을 의미 있는 문장과 이미지로 해석하는 창작 경험입니다.

## 바로 시작하기

1. ZIP 파일을 압축 해제합니다.
2. `index.html`, `assets/`, `.nojekyll`, `README.md` 등을 **그대로** GitHub 저장소의 최상위 경로에 업로드합니다.
3. GitHub 저장소 **Settings → Pages → Build and deployment**에서 `Deploy from a branch`를 선택합니다.
4. `main` 브랜치와 `/(root)` 폴더를 선택하고 저장합니다.
5. 배포된 주소 `https://사용자명.github.io/저장소명/`에 접속합니다.

`index.html` 파일을 더블클릭해 로컬 브라우저로 열어도 사용할 수 있습니다. **빌드, npm, CDN, 서버 코드, API 키가 필요 없습니다.** GitHub Pages 하위 경로에서도 동작하도록 상대 경로를 사용합니다.

## 사용법

- **시작하기**: 화면 중앙의 시작 버튼을 클릭하거나 누릅니다. 시작 버튼은 클릭 통계에 포함되지 않습니다.
- **관찰**: 마우스를 움직이거나 화면을 터치하여 궤적을 남기고, 클릭/탭으로 빛의 파동을 생성합니다. 키보드로 관찰 영역에 포커스하고 `Space`/`Enter`를 누를 수도 있습니다.
- **고요함**: 아무것도 하지 않아도 됩니다. 약 30초 후 고요함에 맞는 별자리 초상화가 생성됩니다.
- **언제든 결과 보기**: 하단의 `내 별자리 보기` 버튼으로 바로 결과를 볼 수 있습니다.
- **초상화 다운로드**: 결과 화면의 `SVG로 간직하기` 또는 `PNG 저장`을 사용합니다. SVG는 해상도에 독립적이고 PNG는 1600×1600으로 저장됩니다.
- **다시 시작**: 결과 화면에서 `다시 만날까요?`를 누르면 기록이 초기화되고 새로운 작품이 생성됩니다. 전체 페이지를 새로고침할 필요가 없습니다.
- **언어**: 오른쪽 상단 `EN` / `한국어` 버튼으로 언어를 바꿉니다.
- **사운드**: 초기값은 꺼짐입니다. 오른쪽 상단에서 **명시적으로** 켜야 은은한 앰비언트 음향과 클릭 음이 재생됩니다.

## 11가지 예술적 원형

`The Stillness`, `The Minimalist`, `The Player`, `The Seeker`, `The Dreamer`, `The Philosopher`, `The Runner`, `The Observer`, `The Homebody`, `The Witness`, `The Wanderer`.

원형은 방문 중 관찰된 **상대적인 이동 거리**, 5×4 화면 영역의 탐색 범위, 클릭 횟수, 이동 속도, 멈춤 횟수, 방향 변화를 이용하는 간단한 창작 규칙으로 고릅니다. 분류 결과는 실제 성격·감정·지능을 판정하거나 추측하는 심리 도구가 아닙니다.

초상화는 현재 세션의 화면 크기에 독립적인 정규화된 이동 좌표와 세션 임의 시드를 이용해 SVG로 생성합니다. 고요한 경우에도 독립적인 별자리 문양이 생성됩니다.

## 개인정보와 보안

- 방문자의 마우스·터치 좌표, 통계, 결과는 **현재 브라우저 메모리에서만 처리**됩니다.
- `fetch`, `XMLHttpRequest`, 분석 도구, 광고 SDK, 계정 로그인, `localStorage`, `sessionStorage`, 쿠키 저장을 사용하지 않습니다.
- API 키·비밀 토큰·외부 폰트·외부 CDN이 포함되어 있지 않습니다.
- SVG/PNG 저장 시 로컬 브라우저에서 파일을 생성합니다. 외부 서버로 업로드하지 않습니다.
- 브라우저를 닫거나 새로고침하면 이 경험의 데이터는 사라집니다. 다운로드한 파일은 사용자가 직접 보관합니다.
- GitHub Pages 접속 자체의 HTTP 요청과 GitHub 측 인프라 로그는 별개입니다. 이 프로그램은 행동 데이터를 전송하지 않습니다.

## 성능 / 접근성

- 모바일과 일반 화면을 통합한 **Pointer Events** 방식으로 입력을 처리합니다.
- 장치 해상도에 따라 Canvas의 픽셀 비율을 제한하고, 모바일에서 별·입자 수와 렌더링 빈도를 줄입니다.
- 입자 수가 한없이 증가하지 않도록 제한합니다.
- 탭이 보이지 않는 동안 애니메이션을 멈추고, 사운드도 일시 중지합니다.
- `prefers-reduced-motion` 설정을 존중합니다.
- 키보드 조작, 명확한 버튼 레이블, 언어 설정, 상태 알림을 제공합니다.

## 개발 및 검사

Node.js가 있으면 다음 명령으로 JS 문법과 핵심 상태 전환을 검사할 수 있습니다. 이 테스트는 DOM 모의 환경에서 동작하며 **브라우저의 실제 화면 렌더링 검사는 대체하지 않습니다.**

```bash
node --check assets/app.js
node tests/smoke.cjs
node tests/smoke.cjs --mobile
node tests/smoke.cjs --reduced
node tests/smoke.cjs --mobile --reduced
```

핵심 기능 점검 항목: 시작, 입력 반영, 결과 전환, 움직임 없음, 한 번 클릭, 여러 번 클릭, 언어 전환, 리셋, 자동 완료, SVG/PNG 저장 콜백. 실제 출력 파일은 Chrome·Edge·Safari 등에서 추가로 확인하기를 권장합니다.

### 알려진 한계

- 분류는 제작자가 설계한 창작 규칙입니다. 행동에 대한 과학적 판단이 아닙니다.
- 모바일 터치로는 마우스만큼 정밀한 이동 궤적이 남지 않을 수 있습니다.
- 브라우저 또는 OS 정책에 따라 Web Audio와 PNG 다운로드가 제한될 수 있습니다. 사운드는 선택 기능이며 SVG 다운로드를 대안으로 제공합니다.
