# 거울 · MIRROR (개선판 v2.0)

> 당신이 보는 것은, 당신이 만드는 것입니다.

단 한 줄의 서버 코드도 필요 없는 인터랙티브 예술 사이트입니다. 화면을 움직이면 Gray–Scott 반응-확산 패턴이 나타나고, 마우스나 손가락의 궤적이 남습니다. **침묵 → 탄생 → 시간 → 멈춤 → 거울 → 기억 → 귀환**, 총 7장으로 이루어져 있습니다.

## 바로 실행 / GitHub Pages 배포

1. ZIP 압축을 해제합니다.
2. `index.html` 파일을 Chrome, Edge, Safari 또는 Firefox에서 실행하면 로컬에서 체험할 수 있습니다.
3. GitHub 저장소 루트에 `index.html`, `style.css`, `main.js`, `favicon.svg`, `README.md` 다섯 파일을 업로드합니다.
4. 저장소 `Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save`를 선택합니다.
5. 사이트를 열어 모바일과 데스크톱에서 테스트합니다.

상대경로만 사용하므로 리포지토리 하위 경로(`user.github.io/repo/`)와 사용자 지정 도메인 모두 지원합니다. `npm`, 빌드, API 키, 서버, CDN, 외부 폰트가 필요하지 않습니다. 배포 시 GitHub Pages가 `HTTPS`를 제공합니다.

## 조작

- 화면 위에서 커서를 움직이거나 손가락으로 터치/드래그하여 생명을 피우고 자신의 흔적을 남깁니다.
- 페이지 아래의 **이전 / 다음 장면**, 장면 점 표시로 언제든 7장 사이를 이동합니다.
- PC에서는 `←` / `→` 키로 장면 이동, **탄생** 장면에서 `Space`로 씨앗을 심을 수 있습니다. `Tab` 키와 `Enter` 키로도 버튼을 사용할 수 있습니다.
- **멈춤** 장면에서는 **9초 동안 상호작용하지 않으면** 원형 게이지가 채워집니다. 언제든 다음 장면으로 넘어갈 수 있습니다.
- **거울** 장면에서는 PNG로 현재 장면을 저장하거나, 흔적을 선택적으로 브라우저에 기억시킬 수 있습니다.
- **기억** 장면에서 현재 브라우저의 방문 횟수를 확인하고, 이전에 저장한 흔적을 황금색으로 겹쳐 볼 수 있습니다.
- 우측 상단 설정에서 애니메이션 줄이기, 기억 지우기를 할 수 있습니다.

## 개인정보와 저장 범위

**외부 API/분석 서버로 아무 데이터도 전송하지 않습니다.** 기본적으로 현재 브라우저에는 방문 횟수(`mirror.visits.v2`)만 남습니다. 사용자가 **이 흔적 기억하기** 버튼을 누를 때에만 최대 약 1,000개로 압축된 0~1 정규화 좌표와 저장 날짜가 `localStorage`에 기록됩니다(`mirror.saved-trail.v2`). 애니메이션 줄이기 설정은 `mirror.reduced-motion.v2`에 저장됩니다. 설정이나 기억 장면에서 방문 기록과 저장한 흔적을 삭제할 수 있습니다. 비공개 창·브라우저 데이터 삭제·저장소 제한이 있는 환경에서는 기억이 남지 않을 수 있습니다.

기존 원본의 `mirror.visits.v1` 방문 횟수가 있으면 개선판이 이를 받아 다음 횟수로 사용하며, 방문자 전체의 순위나 서버 기반 기록으로 표시하지 않습니다.

## 과학/표현 유의사항

- 반응-확산은 시뮬레이션입니다. 실제 생명이나 뇌 활동의 측정이 아닙니다.
- **심박 72회/분, 세포 70만 개/초**는 사용자 측정값이 아니라 원본에서 가져온 **예시 속도**입니다. 특히 세포 값은 보편적 생물학 사실로 제시하지 않습니다.
- 지구 공전 속도 약 **29.78 km/s**와 진공 속 광속 약 **299,792.458 km/s**는 참고용 물리 상수·평균값이며, 실제 사용자의 이동 거리를 의미하지 않습니다.
- 카운터는 사이트가 **전경에서 표시된 경과시간**을 사용합니다. 이는 위 값들에 임의의 속도를 곱한 시각화이며 정밀 측정 도구가 아닙니다.

```text

```

## 점검 기준

`node --check main.js`로 JavaScript 구문을 확인하고, 브라우저에서 장면 전환·터치·기억 저장·새로고침·삭제·화면 크기 변경·PNG 생성·고요 게이지·저동작 모드의 정상 동작을 확인할 수 있습니다.

이 작품에는 상업적 분석 기능, 실제 신체 측정 기능, 인공지능 기반 프로파일링 기능이 없습니다. 방문자의 정체를 판단하는 서비스도 아닙니다.
