# ENGRAM · 관찰자의 귀환

당신이 움직인 흔적을 별자리로 만들고, 마지막에 남긴 단어와 함께 브라우저에 보존하는 정적 웹사이트입니다.

## 실행과 배포

- `index.html` 파일을 더블클릭하면 최신 브라우저에서 실행됩니다. `README.md`는 설명서입니다.
- GitHub 저장소 **최상위에** `index.html`, `README.md` 두 파일을 업로드합니다. ZIP 자체를 업로드하는 것이 아닙니다.
- GitHub 저장소의 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** 를 선택합니다.
- npm, 서버 측 API, API 키, 외부 라이브러리, 폰트 다운로드가 필요 없습니다.

## 사용 방법

1. **관찰 시작하기**를 누릅니다.
2. 20초 동안 마우스를 움직이거나 손가락으로 화면을 그립니다. **지금 별자리 만들기**를 누르면 조기에 다음 장면으로 진행합니다.
3. 이동 거리, 멈춤 횟수, 관찰 시간 기준 평균 속도를 바탕으로 창작 문장이 표시됩니다. **심리 또는 성격 진단이 아닙니다.**
4. **단어 하나 남기기**를 눌러 단어를 적고 저장합니다.
5. **기억 보관소**에서 저장된 단어와 궤적을 확인하고 다시 볼 수 있습니다. JSON 백업, 가져오기, 전체 삭제를 지원합니다.
6. 음악은 자동 재생되지 않으며, 화면 상단 **소리 끔**을 눌러 켜거나 끌 수 있습니다.

## 개인정보 및 저장

- 기록은 `localStorage`의 `engram.garden.v2`에만 저장되며 외부 서버로 전송되지 않습니다.
- 방문 횟수와 최근 **8개의 별자리 기록**을 저장합니다. 개별 기록당 최대 160개의 경로 점과 16개의 머무름 지점을 남깁니다.
- JSON 백업 파일에는 단어, 움직임 좌표, 기록 시각이 포함되므로 공유에 주의하세요.
- 브라우저 저장소를 차단하거나 비공개 모드를 사용하면 기록이 유지되지 않을 수 있습니다. 백업 기능을 권장합니다.
- 오래된 ENGRAM 데모가 같은 브라우저에 남긴 `engram_word`는 처음 실행 시 가져올 수 있습니다(경로가 없는 과거 기록으로 표시).

## 기술 및 호환성

- 하나의 HTML 파일에 CSS와 JavaScript를 모두 내장했습니다.
- Canvas 2D 시각화. Canvas를 사용할 수 없어도 버튼과 텍스트 체험은 계속됩니다.
- Web Audio API 기반 생성 사운드. 미지원 또는 오류일 경우 무음으로 계속합니다.
- `prefers-reduced-motion` 대응: 장시간 프레임 애니메이션 대신 정지 배경을 보여줍니다.
- 모바일 터치, 데스크톱, 키보드 및 화면 크기 변화에 대응합니다.
- 의존성, 광고, 분석 스크립트 없음.

## 주의

본 체험은 움직임을 시적으로 해석한 예술 프로젝트입니다. 수치가 사용자의 심리, 성격, 능력, 의학적 상태를 의미하지 않습니다.
