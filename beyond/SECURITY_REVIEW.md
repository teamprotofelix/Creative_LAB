# 공개 배포용 보안 검토 — BEYOND

검토 대상: 이 ZIP에 포함된 정적 사이트 전체. 개인 서버·비공개 저장소와 연결되지 않는 독립형 코드입니다.

## 검사 결과

- 비밀키, API 토큰, 비밀번호, 인증서 개인키, 환경변수 파일: **포함되지 않음**
- 외부 CDN·웹폰트·JavaScript 라이브러리·분석 스크립트: **포함되지 않음**
- 외부 URL로 사용자 입력을 보내는 요청(`fetch`, XHR, `sendBeacon`): **없음**
- 개인정보나 계정 정보를 미리 심어둔 코드: **없음**
- 사용자가 입력한 내용: **브라우저 안에서만 처리**. 사용자가 직접 저장한 질문은 같은 브라우저의 `localStorage`에 보관됩니다.
- PNG·SVG·JSON 생성: **브라우저 내부에서 처리**, 외부 서버에 업로드하지 않음
- Service Worker: **동일 출처의 정적 파일만 캐시**

## 주의사항

- 노트에 저장한 내용은 브라우저의 일반 저장소에 남아 있으며 암호화되지 않습니다. 민감한 개인정보·업무상 비밀 내용은 입력하지 않는 편이 안전합니다.
- 사용자 기기에서 실행되는 JavaScript 특성상 사용자는 개발자 도구에서 코드를 확인·수정할 수 있습니다.
- GitHub Pages를 Public 저장소에 게시하면 사이트 소스 전체가 누구에게나 공개됩니다.
- 본 검토는 이 ZIP의 소스에 대한 정적 점검과 일부 브라우저 기능 테스트이며 침투 테스트나 운영 배포 검증을 뜻하지 않습니다.

## 배포 권장

그대로 정적 호스팅하고 비공개 API 키·토큰·개인 데이터 파일을 추가하지 마세요. 이 사이트는 그러한 값이 없어도 모든 핵심 기능을 실행하도록 설계되었습니다.
