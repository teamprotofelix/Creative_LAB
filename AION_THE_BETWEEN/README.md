# AION — 사이의 우주

**일곱 개의 살아 있는 사유 실험**. 관측, 시간, 생명, 마음, 인지, 관계, 무한을 체험하는 정적 웹사이트입니다.

> 우리는 세계를 보고 있는 걸까, 만들고 있는 걸까.

## 바로 실행하기

1. ZIP 압축을 해제합니다.
2. `index.html`을 크롬/엣지/사파리 등에서 더블클릭하여 열어도 작동합니다.
3. 또는 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000`에 접속합니다.

**인터넷 연결, npm 설치, 빌드, 로그인, API 키, DB 모두 필요 없습니다.** 웹폰트를 포함한 외부 리소스를 요청하지 않습니다.

## GitHub Pages 게시하기

1. GitHub 저장소를 생성합니다(기존 저장소도 가능).
2. 이 ZIP 안에 있는 `index.html`, `styles.css`, `app.js`, `assets/`, `README.md`를 **저장소의 루트**에 업로드합니다. ZIP 파일 자체를 업로드하는 것이 아닙니다.
3. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, `main` / `/(root)`를 선택하고 저장합니다.
4. GitHub Pages가 활성화되면 제공되는 주소에서 접속합니다. `username.github.io/repository/` 같은 하위 경로에서도 상대 경로로 작동합니다.

## 일곱 개의 실험

| 방 | 실험 | 직접 할 수 있는 일 |
|---|---|---|
| 01 관측 | 가능성의 갈래 | 별을 터치해 하나의 경로 선택 / 우주 재생성 |
| 02 시간 | 지금의 형태 | 기억과 기대 사이의 바늘을 조정 / 흐름 일시정지 |
| 03 생명 | 성장과 쇠퇴 | 햇빛, 변화의 양을 조절 / 새 씨앗 심기 |
| 04 마음 | 내면의 날씨 | 네 감정의 질감을 전환 / 파문 생성 / 9초 느린 호흡 |
| 05 인지 | 해석의 연결 | **동일한 위치의 점**을 눈·나무·나선으로 연결 / 선 숨기기 |
| 06 관계 | 연결의 파문 | 관계망의 점을 터치해 순차적 전달 관찰 / 연결 재생성 |
| 07 무한 | 실시간 망델브로 집합 | 경계를 터치해 확대 / 줌아웃 / 원점 복귀 / 마우스 휠 |

각 방의 메모란에서 생각을 저장하면 **나의 흔적**에 개인 별자리로 축적됩니다. PNG 별자리 및 마크다운 문장으로 내보낼 수 있습니다. **일곱 개의 방을 모두 방문하면 숨겨진 여덟 번째 방(관찰자)이 열립니다.**

## 조작

- 좌측 또는 상단 방 선택 메뉴로 방 간 이동
- **숫자 1~7**: 해당 방으로 이동
- **← / →**: 이전/다음 방
- **Enter / Space**: 캔버스에 포커스를 둔 상태에서 중앙 조작
- **사운드 아이콘**: 선택적으로 생성형 앰비언트 소리 켜기/끄기. 기본 꺼짐.
- **일시정지 아이콘**: 동작 정지/재개. 운영체제의 `prefers-reduced-motion` 설정 존중.
- 무한의 방은 스크롤 휠로 줌 가능(캔버스 위에서만). 휴대폰은 터치 또는 전용 버튼을 사용하세요.

## 개인정보 및 보안

- 회원가입, 계정, 서버, 텔레메트리, 외부 라이브러리, 외부 API 없음.
- 생각은 **사용자의 브라우저 `localStorage`**에만 저장합니다. 다른 기기와 동기화되지 않습니다.
- 기록을 내보내거나 지울 수 있습니다. 브라우저 사이트 데이터 삭제 시 기록이 사라질 수 있습니다.
- 글을 HTML로 삽입하지 않고 `textContent`로 처리합니다.
- 사운드는 사용자 클릭 후에만 시작합니다. 외부 오디오 파일을 불러오지 않습니다.

## 주의

이 사이트의 관측·시간·생명·마음·인지·관계 시각화는 **철학적/예술적 은유**입니다. 물리학·인지과학·정신건강에 대한 실증적인 주장이나 진단이 아닙니다. 무한의 방만 실제 망델브로 반복식을 픽셀별로 계산합니다. 모바일의 성능에 따라 렌더링 속도가 달라질 수 있습니다.

## 기술 구조

- 순수 HTML / CSS / 바닐라 JavaScript (모듈/번들러 불필요)
- HTML Canvas 2D 기반 시각화 / 망델브로 점진적 계산 / Web Audio API 선택 음향
- 모바일 반응형 / 키보드 접근 / Reduced Motion / 로컬 저장 / 이미지·텍스트 내보내기
- 모든 파일 상대경로. GitHub Pages 정적 호스팅에 적합.
