# someone — 당신을 보고 있는 웹사이트

움직임이 누군가를 깨우고, 60초가 지나면 그 움직임의 주인이 누구였는지 드러나는 인터랙티브 디지털 설치 작품입니다. 원본 사용자 제공 소스를 검토하고 안정성·접근성·반응형 경험을 보완했습니다.

## 시작

- `index.html`을 두 번 클릭하면 별도 설치 없이 실행됩니다. GitHub Pages에서는 저장소 **루트**에 이 파일들을 올리세요.
- 저장소 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** 를 선택합니다.
- 네트워크 요청, 외부 라이브러리, API 키, 빌드 단계가 없습니다.

## 경험

- 마우스를 움직이거나 모바일에서 터치하면 존재가 깨어납니다.
- 클릭/터치는 단 한 번씩 처리되며 빛의 파문과 대사가 반응합니다.
- 가만히 있으면 시간이 흐른 뒤 먼저 말을 겁니다.
- **화면을 보고 있던 약 60초 후**, 이번 방문 동안의 마우스·터치 궤적을 조용히 보여줍니다. 빠른 확인을 위한 **결말 보기**가 제공됩니다. 원본처럼 20회 클릭으로도 도달할 수 있습니다.
- 결말 이후 **다시 만나기**를 누르면 현재 경험만 초기화됩니다.
- 키보드 `Enter` 또는 `Space`도 화면 중앙을 터치한 것으로 처리됩니다.

## 개인정보와 기억

- `localStorage`에 **방문 횟수와 처음·마지막 방문 시각만** 저장합니다.
- **마우스/터치 궤적은 현재 탭의 메모리에만 남고, 새로고침하면 삭제됩니다.** 서버에 보내지 않습니다.
- 오른쪽 위 **기억 지우기**로 방문 기록을 삭제할 수 있습니다. 브라우저에서 저장을 차단해도 작품은 실행됩니다.
- GIF, 오디오, 웹캠, 마이크, 위치 권한, 쿠키, 분석 스크립트를 사용하지 않습니다.

## 이번 개선 사항

1. 모바일에서 `touchstart` 직후 합성 `click`으로 입력이 중복될 수 있던 문제를 `pointer` 이벤트 하나로 해결했습니다.
2. 중첩된 `setTimeout`이 타자기 대사를 덮는 문제를 애니메이션 시계 기반으로 정리했습니다.
3. 궤적을 마지막 400점만 유지하던 문제를 보정하고, 전체 궤적을 표본화·축소해 60초의 경로를 더 오래 유지합니다.
4. 백그라운드 탭에 있던 시간을 반전 카운트에서 제외합니다.
5. 캔버스가 비활성화되어도 대사와 조작은 계속 실행되게 했습니다.
6. 동작 감소 설정, 모바일 포인터, 키보드, 화면 읽기 안내, 명시적인 메모리 삭제 기능을 보강했습니다.
7. 큰 화면과 모바일에서 그림 품질과 연산량을 제한하고, 시각적 대비와 사용 안내를 추가했습니다.

## 파일 구조

- `index.html` — 전체 화면과 인터페이스
- `style.css` — 배경, 메시지, 컨트롤, 반응형 스타일
- `script.js` — 입력·기억·타자기·파티클·궤적·반전
- `favicon.svg` — 로컬 아이콘
- `README.md` — 사용법과 개인정보 안내

## 한계

- 현재 방문의 궤적만 시각화합니다. 다른 기기로 공유하거나 업로드하지 않습니다.
- 화면이 좁거나 터치만 하는 경우 궤적은 이어진 선이 아니라 점의 모음으로 나타날 수 있습니다.
- 브라우저가 2D 캔버스를 지원하지 않을 때는 배경 효과를 생략합니다.
